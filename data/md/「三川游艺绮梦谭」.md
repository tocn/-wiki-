### 活动说明

- 活动期间，将陆续解锁「秋津羽球二重梦」、「小狐狸的白日梦」、「不思议分身幻梦」各阶段玩法。
- 「秋津羽球二重梦」玩法中，旅行者需要回击羽球妖怪打来的羽球，在各种条件下击败羽球妖怪。
- 「小狐狸的白日梦」玩法中，旅行者可以切换白日梦的形态，改变地形地貌、规避危险，引导小狐狸收集油豆腐并抵达拉面摊。
- 「不思议分身幻梦」玩法中，旅行者需要灵活运用不可思议的分身机制，解开各种谜题，寻找通路前往终点。
- 完成挑战后，可获得「游艺印章」。累计获取指定数量的「游艺印章」即可获得「长柄武器·且住亭御咄」、 原石 、 智识之冕 、活动专属武器精炼材料等奖励。

### 不思议分身幻梦

| | |
| --- | --- |
| 不思议分身幻梦 | 在「不思议分身幻梦」挑战中，旅行者需要在三个回合内抵达终点。每个回合中，角色的行动都将被不倒貉貉记录，下一回合开始时，不倒貉貉将模仿该角色在上一回合的行动。运用这一机制，即可解开许多机关与谜题，开启抵达终点的道路… |
| 不思议分身幻梦·压力桥梁 | 角色或模仿角色的不倒貉貉持续处于某个颜色的压力机关上时，可以开启对应颜色的桥梁。角色或不倒貉貉离开压力机关时，对应的桥梁将立刻消失… |
| 不思议分身幻梦·观察全局 | 在观察全局的模式下，可以移动镜头，调整镜头视距，俯瞰整个挑战区域，更有效地对行动作出分析。 完成一个回合的行动后，还可以在该模式下通过不倒貉貉的模仿，重看之前的行动。 |
| 不思议分身幻梦·花之门扉 | 挑战中存在飘浮的花之锁匙，角色或不倒貉貉靠近后，可以将其收集，用以开启对应的花之门扉。 |

| 秋津羽球二重梦 | 在「秋津羽球二重梦」玩法中，旅行者需要回击羽球妖怪打来的羽球，将羽球妖怪击败！ |
| 秋津羽球二重梦·活力值 | 被羽球或弹幕命中时，角色将损失活力值； 可以通过移动或闪避躲开； 活力值为零时不会失败，但以此状态完成本局挑战，将无法获取部分奖励。 |
| 秋津羽球二重梦·回击技巧 | 两个重要的技巧可以提升回击的伤害—— 完美回击：把握时机，找到好的回击距离和回击角度，即可打出完美回击。 蓄力回击：通过长按进行蓄力回击，可以打出更为强力的回击，应对某些特殊的来球，但在蓄力期间，角色的移动速度将大幅降低。 |
| 秋津羽球二重梦·击球绝技 | 通过回击对羽球妖怪造成伤害可以积累羽球热情。羽球热情达到满值后将施放击球绝技：此状态下无法进行蓄力回击，但回击范围大幅提升，每次回击均视为完美回击。 |
| 秋津羽球二重梦·强力球 | 对手大力击出的羽球，需要使用长按蓄力的蓄力击球才能回击。 |
| 秋津羽球二重梦·高抛球 | 飞行抛物线较为陡峭的羽球，落点可被预测（越接近落地时落点越明显），需要在其下落过程中进行回击。 |
| 秋津羽球二重梦·弧线球 | 以特定弧线轨迹飞行的羽球，需要预判其飞行轨迹才能接住！ |
| 秋津羽球二重梦·魔王球 | 最强的羽球！飞行抛物线较为陡峭，落点可被预测（越接近落地时落点越明显），需要在其下落过程中使用蓄力回击。 |

## 活动内容

**三川游艺绮梦谭**
由八重堂牵头，借助你与派蒙的声名再次举办的「三川花祭」。此次祭典力求以人的想象，辅以妖的变化，在现代构建出最新、最妙的「游艺」，招徕各地的人类与妖怪共飨盛宴…
