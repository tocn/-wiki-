## 基本信息

### 活动时间

### 参与条件

冒险等阶≥20级
完成魔神任务：序章·第三幕「巨龙与自由之歌」

### 活动说明

- 活动开始后的前六天，每天更新两个派蒙推荐的留影点。
- 旅行者需要前往指定留影点，用「派蒙的留影机」按特定要求记录下各类画片。
- 活动期间，在每个留影点首次完成留影后，可以在活动界面领取奖励。

## 玩法教学

| |
| --- |
| 旅行者需要装备「派蒙的留影机」，与留影点或角色交互后进入留影模式。 留影分为留影点位调整阶段，和可以移动以及施放技能的留影阶段。 |
| 在留影点位调整阶段，旅行者首先需要选择一个留影机位设置，并可以在此设置的基础上继续调整留影的位置和角度。 每个留影点设置了三个留影机位，每个留影机位有着独特的画幅比例。 确认留影设置后，进入留影阶段。 |
| 在留影阶段，当旅行者使用「派蒙的留影机」拍摄画片时，画片完成时的角度将由之前所调整的留影设置决定。 三个留影机位会同时拍摄画片。 |
| 若开启镜头跟随功能，当旅行者移动或进行动作时，各个镜头会在一定范围内追逐旅行者移动。 |
