### 活动说明

- 活动期间，将陆续解锁「飞迸湍流大作战」、「吼吼小狐巡天记」、「幽思闪念旋步舞」、「哐哐当当雀雀球」各阶段玩法。
- 「飞迸湍流大作战」玩法中，旅行者需要驱动造型特别的水炮，打击空中飘浮的标靶，完成限时射击挑战。
- 「吼吼小狐巡天记」玩法中，旅行者需要操纵新式玩具「吼吼小狐」在「琉形蜃境」各地巡游，挑战独特的竞速试炼。
- 「幽思闪念旋步舞」玩法中，旅行者可以通过击败敌人积累「锐意」来获得「锐势焦点」效果，更快地完成挑战。
- 「哐哐当当雀雀球」玩法中，旅行者需要依次投出若干枚雀雀球，尽可能获取更高得分以完成挑战。
- 完成各个玩法，可获得「趣意斑晶」，累计收集指定数量的「趣意斑晶」可以邀请「绮思晚星· 莱依拉 (冰)」。
- 活动期间，旅行者可以探索「琉形蜃境」，开启礼券密盒、妙趣宝箱，完成奇乐挑战，收集「欢兴礼券」。累计收集指定数量的「欢兴礼券」即可获取凯亚衣装「 帆影游风 」。

※ 凯亚衣装「帆影游风」将会在3.8版本结束后上架角色装扮商城，售价为1680创世结晶。

## 玩法教学

玩法教学一览

| | |
| --- | --- |
| 飞迸湍流大作战 | 以棘冠鳄为灵感制作的游乐设施，可以发射安全的娱乐用水元素弹药。 水炮发射时，将消耗后备弹药量，弹药耗尽后，将耗费一定的时间，自动进行装填。游玩过程中，也可以在合适的时机进行手动装填。 通过调整「设置」界面下「控制」中，瞄准模式下的「灵敏度」，可以改善水炮的操纵性。 |
| 游乐项目中存在多种标靶球：普普通通球、小小优势球、四处捣乱球、连锁殉爆球、超限火力球、强劲对手球和弹药多多球。 在关卡详情中，可以查看每种标靶球的特殊效果。 |
| 在一定时间内连续命中标靶球可以积累连击数，维持较高的连击数是获取大量得分的关键… |
| 击破「普普通通球」和「小小优势球」可以获取得分； 击破「连锁殉爆球」后将发生爆炸，对周围的其他标靶球造成伤害。 |
| 击破「四处捣乱球」后，将损失一定得分，并终止当前连击数。 |
| 击破「超限火力球」进入「超限火力」状态后，「鳄鳄炮炮」将获得以下效果： 一定时间内获得无限后备弹药； 发射的弹药命中标靶球时，将造成更大范围的伤害； 命中四处捣乱球时，将不受该球造成的负面效果影响。 |
| 「强劲对手球」是以特殊材料制成的标靶球，有着极强的韧性，需要多次命中后才能将其击破。 每次命中该球时都能获取少量分数，击破该球后能够获取大量得分。 |
| 收到自爆指令的标靶球将在一段时间后自爆，且不计入得分。 |
| 吼吼小狐巡天记 | 在「吼吼小狐巡天记」挑战中，旅行者需要操纵吼吼小狐在限定时间内抵达终点，并尽可能收集更多「冒险币」。 抵达终点时剩余时间越多，收集的「冒险币」越多，挑战结束时获得的评分就越高。 |
| 挑战中存在「脏脏霰果」与会发射「干扰波」的「干扰晶球」。若吼吼小狐被「脏脏霰果」或「干扰波」命中，则会使得挑战的剩余时间减少，从而导致最终得分降低。 |
| 幽思闪念旋步舞 | 挑战开始前，可以根据不同舞台的特性，调整上阵队伍的阵容。挑战过程中，击败敌人可以积累「锐意」。当「锐意」积累到一定程度后，将获得「锐势焦点」效果。 |
| 「锐势焦点」效果将持续一定时间，为角色提供强大的战斗助力。充分利用「锐势焦点」，即可更高效地击败敌人，更快地完成挑战。 |
| 哐哐当当雀雀球 | 在「哐哐当当雀雀球」玩法中，旅行者需要依次投出若干枚雀雀球。尽可能使所有雀雀球停留在高分区，达成目标分数，即可赢得对应奖励。 停留在红框内可获得4分，黄框可获得2分，蓝框内可获得1分。 若雀雀球在多条框线上停下，则会按较高得分计算。 |
| 每次投球前，可以左右移动雀雀球，调整投球的起始位置。 |
| 把握时机，按住投球按钮以锁定投球方向，并进入投球的蓄力过程。松开投球键，即可将雀雀球以对应的方向和力度投出。 一旦锁定投球方向，将无法取消投球准备。 |
| 如果所有雀雀球停止移动时，有任意一球处于发球区内，此次投球将被视为无效，需要重投当前雀雀球。 |
| 陷入困境时，可以运用两种雀雀球的能力改善局势—— 贴贴雀雀球： 投出该球后，该球将与触碰到的第一个雀雀球贴在一起，带着它共同移动。移动结束时，将解除该效果。 华丽雀雀球：投出该球后，该球首次停止移动时，能够吸引自身周围一定范围内的其他雀雀球。 |

…时至今日，我仍受困于那场噩梦之中，眼前的一切都仿佛回到了，回到了那片战场，火光焚照天际，如影扭曲的魔物，支离破碎的已看不出形状的躯体，哀嚎在自喉中淌出之前就落入了无声的黑暗。还有…啊，还有将我从漆黑犬兽獠牙之下救出的友人，在战场上，弓刀自他失力的手中落下，身躯逐渐沉入污秽的泥沼之中，半张着嘴的脸朝向我，朝向我…

…我曾侥幸从那场战斗中生还，不，有什么好侥幸呢，是我失去了信心，放弃了手中的十文字枪，丢下了共同对抗灾厄大敌的士卒，如丧神智般逃离了战场。此番作为，愧对将军大人的信任，亦辜负先祖流传至今的声名…事到如今已没有脸面回到八酝。我逃离了战场，但我真的逃离了吗，至那之后，我每日都会梦见凄惨的战场，那些失血泛白的面孔，梦见友人隐入漆黑泥淖前如游丝般呼唤我的名字…往往，只能依靠「蜃楼玉匣」中蜃气所构虚影，才可求得片刻安宁。

…真是可笑，这「屋楼玉匣」还是作为八酝守受召远讨之前，母亲自朦云神社请来，本想减免我在战场上所受伤痛。那时我还说，「我承袭『喜多院』之名，怎会因区区伤痛使用此物。」想起此事让人汗颜无地。若是让曾为巫女的母亲看到现在这副模样…

…我已经受够了在外流亡，备受折磨的日子了。今日我，今日我终于能够回到此处，啊，我在无数次噩梦中梦见，唯恐避之不及，却又是我无比期冀能返回之处。啊…我的双臂已无法像年轻时那样挥枪自如，但这一次，我一定能挽救我的友人，定能…清除污秽，这一次我一定会跟随将军大人…直到，直到最后一刻。

——喜多院秀家
