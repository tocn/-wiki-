怀揣慈悲庇世之心，挥舞威慑十方之刃，以示世人，这是「演武传心」最初的意旨。
但时移世迁，今时不同往日，现在的「演武传心」有了些新变化…

## 基本信息

### 活动时间

2023/02/09 10:00 ~ 2023/02/20 03:59

### 参与条件

冒险等阶≥30级
且完成魔神任务「离岛逃离计划」
※ 完成雷电将军传说任务「天下人之章 第二幕」后体验更佳。
※ 活动期间，如果没有完成雷电将军传说任务「天下人之章 第二幕」，可在活动界面通过「快速体验」参与活动。

### 活动说明

- 活动开启后，每日将解锁一场比试，总共6场。
- 每场比试有普通，困难和大师3个难度，成功通关困难难度后才可解锁大师难度。
- 对阵期间，旅行者将无法施放元素战技和元素爆发，并获得新的战斗技能「格挡」和「锐意剑技」。

## 玩法教学

| |
| --- |
| 与旅行者对阵的每位武者都拥有不同的剑技，包括战斗中频繁使用的普通剑技，和较少使用但极为强大的「奥义」。可以在界面中查看对手特性，提前了解对阵策略将提升战胜对方的概率。 |
| 对阵期间，旅行者将无法施放元素战技和元素爆发，并获得新的战斗技能：「格挡」和「锐意剑技」。施放「格挡」期间，旅行者将举起武器摆出防御架势：受到的伤害大幅降低。「格挡」拥有一定的冷却时间。 |
| 为了应对不同的武者，旅行者将会使用不同的「锐意剑技」。普通攻击、重击命中对手，或成功进行「格挡」时，都可以积累「锐气」，「锐气」也将随时间推进少量积累，「锐气」达到满值后可以主动释放「锐意剑技」，「锐意剑技」最多可积累2次施放次数。 |
| 把握时机，在对阵武者发起进攻的瞬间施放「格挡」，将完全减免本次受到的伤害，同时重置「格挡」的冷却时间。且「完美格挡」对手的普通剑技将积攒更多的「锐气」。 |
| 每位武者施放「奥义」前，该武者的武器上将有强光闪烁。「完美格挡」对手的「奥义」时，将使出强力反击，同时积攒大量「锐气」。在合适的时机释放「锐意剑技」，取得胜利吧！ |
