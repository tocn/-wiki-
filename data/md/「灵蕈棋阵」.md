亲爱的旅行者，「灵蕈棋阵」活动即将开启~

## 基本信息

### 活动时间

### 参与条件

冒险等阶≥30级
完成魔神任务「迫近的客星」
※ 完成魔神任务「虚空鼓动，劫火高扬」后参与活动体验更佳。
※ 活动期间，如果没有完成魔神任务「虚空鼓动，劫火高扬」可在活动界面通过「快速体验」参与活动。

### 活动说明

- 活动开始后，每天会解锁一个新的棋阵关卡，总共7个正式关卡。
- 旅行者需要指挥「小小灵蕈」击败所有「棋阵机关」才可获取关卡胜利。
- 在战斗挑战中，通过消耗「妙妙灵冻」，可以指挥「小小灵蕈」释放强大的战技。「妙妙灵冻」的数量会随着时间逐渐恢复，或通过拾取场地中的「喝彩加护」直接获取。

## 玩法教学

| |
| --- |
| 在「灵覃棋阵」中，驯兽师需要指挥「小小灵蕈」击败所有「棋阵机关」。 我方的「小小灵蕈」将自行选择最近的「棋阵机关」发起进攻，通过白色指示线，可以确认每个「小小灵蕈」的交战目标。 同时，对方的「棋阵机关」也将对最近的「小小灵蕈」发起进攻，对方的交战目标将以红色指示线标明。 |
| 点击「小小灵蕈」的头像，使用数字键，或直接点击场上的「小小灵蕈」，均可切换当前指挥的蕈兽。 |
| 点击场地中的某个位置，或是对方的「棋阵机关」，即可指挥「小小灵蕈」移动至该位置，或对该「棋阵机关」发起进攻。 |
| 通过消耗「妙妙灵冻」，可以指挥「小小灵蕈」施放强大的战技。「妙妙灵冻」的数量将随时间恢复。 此外，拾取场地中的「喝彩加护」可以获得额外的「妙妙灵冻」。 |
| 部分战技需要确定目标，才能完成施放。 |
