### 活动说明

- 活动开启后的首日、第3日、第5日，将开放2个新的「闲畅游艺」和1个「破邪游艺」挑战。玩家需要完成对应阶段在「闲畅游艺」中所有「乐玩」难度的挑战后，可解锁对应的「破邪游艺」挑战。
- 完成「闲畅游艺」和「破邪游艺」中的指定任务，即可获得原石、活动专属武器 东花坊时雨 、 试胆会的票券 、大英雄的经验、精锻用魔矿和摩拉奖励，「试胆会的票券」可在活动商店中兑换 若狭的藁末 、智识之冕、武器突破素材、天赋培养素材等奖励。
- 完成「秋津森夜试胆会」系列任务后可获得原石、摆设 「试胆会的高彩谐趣」 和大英雄的经验等奖励。
- 活动结束后，「试胆会的票券」将会消失，请旅行者及时兑换奖励。

## 游艺要点

| | |
| --- | --- |
| 秋津游艺·规则 | 在「秋津游艺」中，挑战开始时，需要主动发球，将弹板上的「术球」向前方击出。 「术球」碰撞弹板后将被反弹，若碰撞时弹板正在移动，「术球」的反弹方向也会发生对应改变。 |
| 开始挑战前，可以在准备界面选择「游艺要策」，为挑战提供高效的增益。部分「游艺要策」需要通过特定关卡后解锁，且通过「破邪游艺」中的关卡后，可以增强部分「游艺要策」的效果。 |
| 根据当前操作弹板角色的元素种类，弹板将附着对应的元素，对「术球」施加相同的元素附着。 在「秋津游艺」中，当前场上的角色的元素种类为火、水、冰、雷时，将为弹板赋予相应的元素附着。 |
| 当场上剩余的游艺方块小于一定数量，且成功击球时，弹板将向前发射火焰弹。当火焰弹命中游艺方块后，将造成一定的伤害，利用这一特性，可以击碎难以命中的游艺方块。 |
| 在「秋津游艺」的「闲畅游艺」玩法中，单人游戏状态下，可以进行联机匹配挑战。多人游戏状态下，可以邀请队伍中的一名玩家共同进行挑战。「破邪游艺」玩法仅能进行单人挑战。 |
| 秋津游艺·积分与连击 | 利用「术球」对游艺方块造成伤害，可以获得积分。完成挑战时剩余时间越多、达成的连击数越多，还能获得更高的额外积分。 |
| 连续对游艺方块造成伤害，即可累计连击数。损失场上的最后一枚「术球」时，连击数将重置。 |
| 秋津游艺·爆轰球 | 「术球」与弹板发生超载反应后，将附加破坏效果「爆轰」：命中游艺方块时，将发生爆炸，对一定范围内的游艺方块造成伤害。 |
| 秋津游艺·馈电球 | 「术球」与弹板发生感电反应后，将附加破坏效果「馈电」：命中游艺方块时，将发生爆炸，将对一定范围内的游艺方块施加雷元素附着。 |
| 秋津游艺·凝冻球 | 「术球」与弹板发生冻结反应后，将暂时停留在弹板上，此时弹板仍可以移动。冻结时间结束后，「术球」将自动向前击出，也可以选择时机，主动击球。 |
| 秋津游艺·爆轰 | 「术球」与游艺方块发生超载反应时，将触发破坏效果「爆轰」：对一定范围内的游艺方块造成伤害。 |
| 秋津游艺·凝冻 | 「术球」与游艺方块发生冻结反应时，将触发破坏效果「凝冻」：与该游艺方块相连的所有同类型游艺方块将被冻结。「术球」再次撞击被冻结的方块时，将直接击碎该方块与所有相连的被冻结的方块。 |
| 秋津游艺·馈电 | 「术球」与游艺方块发生感电反应后，将触发破坏效果「馈电」：在命中的游艺方块位置释放电弧，对一定范围内的游艺方块造成伤害。 |
| 秋津游艺·锐化 | 「术球」与游艺方块发生超导反应时，将触发破坏效果「锐化」：命中游艺方块时不再发生反弹，而是继续沿原路径飞行，直接击碎路径上的游艺方块。「术球」与场地边界碰撞后，此破坏效果立即结束。 |
| 秋津游艺·蒸灼 | 「术球」与游艺方块发生蒸发反应时，将触发破坏效果「蒸灼 」：对命中的游艺方块造成更高伤害。 |
| 秋津游艺·熔解 | 「术球」与游艺方块发生融化反应时，将触发破坏效果「熔解 」：对命中的游艺方块造成更高伤害。 |
| 秋津游艺·百炼难度 | 百炼难度下，场地内将不断生成新的游艺方块。在限定时间内尽可能获得更高的积分吧！ |
| 秋津游艺·备球数量 | 「百炼难度」的「闲畅游艺」和「破邪游艺」挑战中，将新增备球数量限制。当场上的最后一枚「术球」飞越场地的下边界时，即被视为损失，并减少备球数量。 备球数量为零时，将导致挑战失败。 |
| 胡言乱语雷法师 | 坏坏方块王「胡言乱语雷法师」可以召唤一圈雷元素方块保护自身，雷元素方块将随着弹板的移动而转动，或许可以利用这一特性，让「术球」在对方和雷元素方块之间连续反弹，造成大量伤害… |
| 走火入魔老剑客 | 坏坏方块王「走火入魔老剑客」受到「术球」的攻击后，将进入防御状态：「术球」命中「走火入魔老剑客」的本体后，将被加速反弹回来… |

## 游艺本则

### 游艺要策

| | | |
| --- | --- | --- |
| 特装连续球 | Lv.1 | 单人挑战中，场上的「术球」总数小于3时，连击数每增加30，下次成功击球时，将向前方随机方向发射1颗额外的「术球」。 双人挑战中，场上的「术球」上限条件为4，连击数要求提升为50。 |
| 弹性防御墙 | Lv.1 | 单人挑战时，连击数每增加30，将在场地的下边界创造一堵防御墙，「术球」碰撞防御墙后将会反弹。防御墙持续存在6秒； 双人挑战中，创造防御墙的连击数要求提升为60。 |
| 粉碎性惊喜 | Lv.3 | 连击数每增加30，下次击碎游艺方块时，将产生「嘉奖花球」。用弹板接取「嘉奖花球」，将获得150积分。 |
| 相对长宽高 | Lv.1 | 切换角色后，将增加弹板的宽度，持续10秒。 |
| 迅捷飞去来 | Lv.1 | 角色的移动速度提升20%。 |
| 疾速穿连法 | Lv.3 | 连击数每增加30，将额外获得120积分，下次成功击球时，「术球」的飞行速度提升20%。此飞行速度提升的效果至多叠加3层。 |
| 同时弹着法 | Lv.2 | 场上剩余游艺方块数量小于10时，成功击球后，弹板将向前方发射10枚强化焰火弹，强化焰火弹命中游艺方块时将造成更高的伤害。此效果每4秒至多触发1次。 |
