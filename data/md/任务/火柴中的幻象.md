## 任务剧情

- 派蒙：咦…在这种地方还有个屋子？
- 颤抖的声音：好冷…好冷啊…
- 派蒙：咦，是屋子里有人吗…我们快去看看吧？

开门

- 颤抖的声音：好冷…好冷啊…
- 派蒙：奇怪，这里面根本没有人…
- 派蒙：不过，如果冷的话，就应该把房子漏风的地方堵起来吧…

点燃火堆时

: : 用火元素点燃火堆

- 颤抖的声音：火、火也没有用…还是觉得冷…
- 派蒙：看来还是得把洞堵上才行！

: : 用2个臻冰造物·立方将房屋两侧的洞堵起来

尚未点燃火堆时

- 派蒙：对了，现在再把火点起来吧！

: : 用火元素点燃火堆

- 派蒙：这下总算能暖和起来了！
- 颤抖的声音：啊…暖和起来了，从前…从前这个时候…
- 颤抖的声音：外婆会说，来吧，找一张椅子，坐到桌边吧…
- 派蒙：是、是要在桌子边再造一把椅子的意思吗？

获取「临时蓝图」

: : 在桌子另一边凝造臻冰造物·座椅

- 颤抖的声音：外婆说，坐下，孩子…

: : 火堆熄灭

- 颤抖的声音：！
- 颤抖的声音：啊，好黑，没有了…什么都没有了…
- 派蒙：奇怪，火堆灭了，这里的东西也都不见了…
- 派蒙：是不是得重新点火？

: : 用火元素重新点燃火堆

- 颤抖的声音：外婆…外婆！外婆说，孩子，今年的礼物…藏在了屋顶…
- 颤抖的声音：把礼物拿到这里，我们一起打开它！我们一起打开它！
- 派蒙：礼、礼物？总觉得有些怪怪的，但是我们到屋顶上看看吧。

---

- 派蒙：这个盒子就是…那个声音里说的礼物？

获取「临时蓝图」

: : 在桌子上凝造臻冰造物·礼物盒

一段时间未拆除礼物盒时

- 派蒙：嗯…什么事都没发生，啊，难道是要我们把盒子拆开的意思吗？

: : 拆除臻冰造物·礼物盒

- 颤抖的声音：真好，是外婆送给我的礼物…只有外婆…
- 颤抖的声音：只有外婆会对我这么好…

: : 火堆再次熄灭

- 颤抖的声音：呜…火、火又灭了，好冷，好冷，得再点燃它…

: : 用火元素重新点燃火堆

- 颤抖的声音：好暖和，好温暖…你是来带我走的吗…
- 颤抖的声音：你要带我去…更温暖的地方吗？

: : 跟随仙灵

- 平静的声音：啊…谢谢你…终于…
- 平静的声音：我再也不会…再也不会感到寒冷了…
