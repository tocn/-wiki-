本页面统筹七圣召唤常规模式卡牌变更、新增记录。

## 5.8版本

### 新增

1. 新增角色牌3张：鹿野院平藏、蓝砚、贪食匿叶龙山王
2. 新增天赋牌3张：奇想天开捕物帐、舞袂翩兮扬玉霓、饕噬尽吞
3. 新增装备牌2张：失冕的宝冠、异想零落的圆舞
4. 新增支援牌4张：墨色酒馆、星轨王城、森林的祝福、预言女神的礼物
5. 新增事件牌2张：收获时间、很棒，哥们。

### 调整

1. 角色牌「愚人众·霜役人」的初始最大生命值由10点调整为11点。
2. 调整了角色牌「玛薇卡」施放元素战技所需元素骰：由2个火元素骰调整为3个火元素骰。
3. 调整了角色牌「卡齐娜」天赋牌「夜域赐礼·团结炉心」的效果：每回合效果可触发次数由2次调整为1次。
4. 调整了角色牌「基尼奇」元素战技所造成的伤害：由2点草元素伤害调整为1点草元素伤害。
5. 调整了角色牌「艾梅莉埃」天赋牌「茉洁香迹」所需元素骰：由1个草元素骰调整为2个草元素骰。
6. 调整了角色牌「阿蕾奇诺」天赋牌「所有的仇与债皆由我偿…」所需元素骰：由2个火元素骰调整为1个火元素骰。
7. 调整了角色牌「愚人众·霜役人」元素爆发所造成的伤害：由4点冰元素伤害调整为5点冰元素伤害。
8. 调整了角色牌「茜特菈莉」天赋牌「五重天的寒雨」所需元素骰：由1个冰元素骰调整为2个冰元素骰。
9. 调整了事件牌「赦免宣告」所需元素骰和效果：所需元素骰由0个元素骰调整为1个同色元素骰；效果调整为“治疗目标角色2点。目标角色免疫冻结、眩晕、石化等无法使用技能的效果，并且该角色为「出战角色」时不会因效果而切换，持续2个回合”。

## 5.7版本

### 新增

1. 新增角色牌3张：茜特菈莉、玛薇卡、恰斯卡
2. 新增天赋牌3张：五重天的寒雨、「人之名」解放、子弹的戏法
3. 新增装备牌4张：船坞长剑、诸圣的礼冠、烬城勇者绘卷、呀！呀！
4. 新增事件牌5张：为「死」而战、火与战争、飞行队出击！、健身的成果、丰稔之赐

### 调整

1. 调整了角色牌「卡齐娜」施放特技「转转冲击」所需的元素骰：由1个任意元素骰调整为1个岩元素骰；
2. 调整了角色牌「钟离」天赋牌「炊金馔玉」的效果：其“岩元素伤害+1”效果增加了“每回合至多3次”的限制；
3. 角色牌「阿贝多」的初始最大生命值由10点调整为12点；
4. 角色牌「那维莱特」、「北斗」、「坎蒂丝」、「白术」、「丘丘水行游侠」的初始最大生命值由10点调整为11点；
5. 调整了角色牌「丘丘水行游侠」元素爆发造成的伤害：由3点水元素伤害调整为4点水元素伤害；
6. 调整了角色牌「雷电将军」元素爆发，以及其天赋牌「万千的愿望」所需的元素骰：由4个雷元素骰调整为3个雷元素骰

## 5.6版本

### 调整

2. 调整了元素爆发的状态「永世流沔」的伤害：效果调整为“由3点水元素伤害调整为2点水元素伤害”
3. 调整了事件牌「元素共鸣：蔓生之草」的效果：效果调整为“现在「妮露」生成的「丰穰之核」也能触发该事件牌的效果。”

4. 新增支援牌1张：「烟谜主」
5. 新增事件牌2张：以极限之名、奇瑰之汤

### 调整

1. 调整了角色牌「希格雯、珊瑚宫心海、温迪、甘雨、胡桃、钟离、诺艾尔、琴」的初始最大生命值：由10点调整为12点；
2. 调整了事件牌「元素共鸣：强能之雷」的效果：效果调整为“我方出战角色和下一名充能未满的角色获得1点充能”；
3. 调整了事件牌「元素共鸣：迅捷之风」的效果：效果调整为“我方下次执行「切换角色」行动时：将此次切换视为「快速行动」而非「战斗行动」，并且少花费1个元素骰。我方下次触发扩散反应时对目标以外的所有敌方角色造成的伤害+1”；
4. 调整了事件牌「元素共鸣：蔓生之草」的效果：效果调整为“若我方场上存在燃烧烈焰/草原核/激化领域，则对对方出战角色造成1点火元素伤害/水元素伤害/雷元素伤害”；
5. 调整了事件牌「元素共鸣：坚定之岩」的效果：效果调整为“为我方出战角色提供3点护盾”。

2. 新增天赋牌2张：破夜的明焰、夜域赐礼·波涛顶底

5. 新增事件牌3张：归火圣夜巡礼、燃素充盈、咚咚嘭嘭

### 调整

1. 调整了角色牌「愚人众·藏镜仕女」元素战技的伤害：由2点水元素伤害调整为3点水元素伤害；
2. 调整了角色牌「琴」元素爆发召唤物「蒲公英领域」的效果：可用次数由2调整为3；
3. 调整了角色牌「珊瑚宫心海」元素战技召唤物「化海月」的效果：其可用次数现在可叠加，最多叠加到4；
4. 调整了角色牌「八重神子」元素战技的效果：增加了效果“如果场上原本已存在杀生樱，则额外使其造成的伤害+1。（最多+1）”
5. 调整了角色牌「深渊使徒·激流」元素战技的伤害：由2点水元素伤害调整为1点水元素伤害；
6. 调整了角色牌「久岐忍」天赋牌「割舍软弱之心」所需元素骰：由3个雷元素骰调整为4个雷元素骰；
7. 调整了角色牌「罗莎莉亚」元素战技的效果：“…生成2层洞察破绽”调整为“…生成1层洞察破绽”；
8. 调整了角色牌「罗莎莉亚」元素爆发召唤物「极寒的冰枪」的效果：“…生成1层洞察破绽”调整为“…生成2层洞察破绽”。

## 5.1版本

### 新增

1. 新增角色牌3张：千织、深渊咏者·紫电、镀金旅团·叶轮舞者
2. 新增天赋牌3张：落染五色、侵雷重闪、灵蛇旋嘶
3. 新增装备牌3张：便携动力锯、指挥的礼帽、嵴锋龙
4. 新增支援牌1张：特佩利舞台
5. 新增事件牌2张：镀金旅团的茶歇、龙龙饼干

### 调整

1. 重新设计了角色牌「镀金旅团·炽沙叙事人」（旅行者可以前往查看官方发布的《5.1版本「七圣召唤」更新说明》，或在版本更新后进入游戏内查看改动后的效果）；
2. 调整了角色牌「阿佩普的绿洲守望者」被动技能的效果：战斗开始时生成的唤醒眷属由6张调整为5张；召唤4个增殖生命体后生成的护盾由2点调整为1点；
3. 调整了角色牌「丽莎」普通攻击的效果：现在普通攻击即可使得敌方出战角色附属引雷（不再需要进行重击）；
4. 调整了角色牌「丽莎」状态「引雷」的效果：现在“所附属角色受到苍雷或蔷薇雷光的伤害时”，即可触发“移除此状态，每层「引雷」使此伤害+1。”效果（原效果仅可由苍雷伤害触发）。

## 5.0版本

### 新增

1. 新增角色牌3张：菲米尼、闲云、丘丘水行游侠
2. 新增天赋牌3张：梦晓与决意之刻、知是留云僊、轻盈水沫
3. 新增装备牌3张：异色猎刀鳐、匿叶龙、鳍游龙
4. 新增支援牌2张：圣火竞技场、阿伽娅
5. 新增事件牌2张：赦免宣告、龙伙伴的聚餐

### 调整

1. 调整了角色牌赛诺天赋牌落羽的裁择的效果：“使用秘仪·律渊渡魂造成的伤害+2。（每回合1次）”调整为：“使用秘仪·律渊渡魂造成的伤害+1。（每回合至多2次)”；
2. 调整了角色牌吞星之鲸元素战技的效果：效果“造成1点水元素伤害，此角色每有3点无尽食欲提供的额外最大生命，此伤害+1（最多+4）”中，“最多+4”调整为“最多+3”；
3. 调整了角色牌吞星之鲸出战状态「深噬之域」的效果：“获得最大生命值”效果从立即生效调整为在回合结束时生效；
4. 调整了装备牌勘探钻机的效果：“所附属角色受到伤害时”触发的伤害抵消效果的每回合触发次数调整：由“每回合2次”调整为“每回合1次”；
5. 调整了「生命之契」的效果：现在生命之契可以抵消“获得最大生命值”效果附带的治疗效果。
