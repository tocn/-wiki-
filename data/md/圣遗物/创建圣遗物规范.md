```

|四件套效果=

|获取途径=

```

## 属性填写规范

- 在“=”后方根据下方规范填写内容。

### 简单的属性

```
|名称=
|最低稀有度=
|最高稀有度=
|两件套效果=
|四件套效果=
|TAG=
|实装版本=
|时之沙=
|死之羽=
|理之冠=
|生之花=
|空之杯=
|生之花描述=
|生之花故事=
|死之羽描述=
|死之羽故事=
|时之沙描述=
|时之沙故事=
|空之杯描述=
|空之杯故事=
|理之冠描述=
|理之冠故事=
```

- 以上属性的填写按照游戏中的数据即可，需要注意以下几点。
- 稀有度的填写使用纯数字，如“4”、“5”。
- 时之沙、死之羽、理之冠、生之花、空之杯属性填写套装对应的部位名称。
- 描述为背包中查看的简单介绍，故事为点击右下角故事进去查看的详细文字。
- wiki没有自动换行，需要换行请使用<br>标签。
- TAG的请勿擅自填写，需要经过攻略组组长确认。

### 较复杂的属性

```
|角色推荐=
```

- 使用模板填写，模板格式： {{角色推荐|角色图标|推荐原因}}
- 角色图标模板格式： {{图标/角色|角色名|角色星级}}
- 填写方式举例： {{角色推荐|{{图标/角色|珊瑚宫心海|5}}|外形、效果均契合心海。}}
- 角色图标内可放置多个角色。

```
|获取方式=
|获取途径=
```

- 获取途径填写简略的文字，方便其他地方调用。
- 获取方式使用模板填写： {{圣遗物套装/获取途径|途径类型|具体内容}}
- 是的没有看错，获取方式用的模板是获取途径（笑）。
- 途径类型选项：NPC、探索奖励、精英怪物、BOSS、副本、深渊。

```
|提示=
```

- 提示为与圣遗物有关的小提示，可省略。
