| 战前的小憩 | |
| --- | --- |
| 类型 | 赠礼套装、室内 |
| 风格 | 挪德卡莱 |
| 实装版本 | 月之五 |
| 偏好角色 |
| 洞天仙力 | 480 |
| 所需摆设 | 1 室内矮桌-「独有价值」 1 室内柜台-「正式拜访」 1 「连枝蔚蓝」 1 室内书架-「闲暇品读」 1 「扭扭蘑菇」 2 「致友人」 1 「静夜的密谈」 |
| 介绍 | 功能齐全的集体休息室，参考了皮拉米达城的房间布局，还原了执灯士战前小憩的场景。经验丰富的执灯士深知，与狂猎的战争漫长且艰难，必须在条件允许时尽可能休息，以保持最佳战斗状态。此外，布置得当的休息室，还能让执灯士们在战前增进彼此熟悉的程度——在战场上，与熟悉的同伴并肩作战比陌生人更能带来信赖与默契。也因此，休息室的建设历来受到执灯长们的重视。 |
