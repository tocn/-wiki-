## 基础操作

| |
| --- |
| - 该板块旨在为打点人提供最基础的打点操作流程。 - 简而言之，一次打点流程可以归纳为如下步骤： 1. #开启工具箱 2. #激活打点工具 3. #地图点位操作 4. #编辑点位信息（可选） 5. #上传所需文件（可选） |
| - 但在开始之前，需要先大致区分一下大地图的各板块，方便后续的具体区域指示： 大地图一共按左右分为了两个板块，分别为侧边栏（左侧白底窗口）和大地图区域（右侧显示地图的窗口），其各自包含的功能见下： - 红框（左侧）：侧边栏 - 橙框（红框右上）：搜索栏——用于打开打点工具or搜索点位，但激活打点工具时无法搜索点位 - 黄框（红框内部，中下）：二级目录——用于筛选点位、查看点位信息和控制台 - 蓝框（右侧）：大地图区域 - 绿框（蓝框右上）：地图分层选择（默认为地表G层） - 紫色（蓝框右下）：**打点工具箱**.如无特殊说明，下文将统一简称为“工具箱” |

### 开启工具箱

| |
| --- |
| - 迅速连点三次侧边栏右上方搜索框的输入区域，可打开工具箱。 - 工具箱打开后将会在地图区域的右下角显示。 |

### 激活打点工具

| |
| --- |
| - 开启工具箱后，先从侧边栏的点位列表中，选择一个点位，被选中点位将会呈底部高亮显示。 - 然后找到位于地图界面右下角的工具箱。单击任意工具后，若对应工具左侧出现 取消 按钮，就代表已经激活了对应的功能： - 如果想退出该功能，可以直接切换成其他功能或直接单击上述的 取消 按钮；如果需要退出整个打点模式，则直接点击位于最下面的“坐标关闭”中的“关闭”按钮即可。 - 由于布局的关系，虽然“坐标”和“关闭”这俩按钮确实凑得是有点近了，但它们真的是不同的功能。 |

### 地图点位操作

#### 新增点位

| |
| --- |
| - 先从侧边栏的点位列表中，通过鼠标左键单击来选择一个你需要新增的点位的类型（一次可以在多个点位间切换，但打点时只能打你最新选中的那个点位），被选中点位会以底部高亮的方式显示； - 然后单击右下角的工具箱中，顺数下来第五个的“绘制标记”按钮以进入“新增点位”模式，如单击后按钮左侧出现 取消 按钮则为成功进入； - 选中点位并激活“绘制标记”模式后，将鼠标挪回地图区域，应该会发现鼠标指针处生成了一个跟随鼠标指针尖部移动的点位图标，下方附跟随提示“单击放置标记”； - 回看到地图区域右上角，确认并选择该点位的实际所在的图层位置。工具默认的打点层为G层，也就是地表层。如你需要新增的点位在非地表区域，请先确认这个点位对应游戏内的图层，再在右上角选择对应的区域后再进行打点操作。通常情况下，Bx层代表地下，Ax层代表空中。另外由于Wiki内的地图限制问题，分层顺序、各层的底图等不一定和游戏内一致，请自行区分； - 选择完对应分层并找到该点位的对应位置后，以鼠标指针的点击位置，点位的下尖为准定位该点位的位置，单击鼠标左键后挪开鼠标，应该会有一个点位留在点击位置上（请注意和绘制标记的提示区分开）； - 此时回到侧边栏并切换至“控制台”区域，观察会发现“控制台”区域里有两个板块有变化：「变动点位」和「当前种类点位列表」。变动点位显示的是本次打点模式开始至今你操作过的所有点位，包含了具体执行了什么操作、被操作的点位ID、坐标以及该点位由谁创建的信息；而当前种类点位列表则显示你当前选中的点位类型的所有点位，列表中被操作的点位会根据操作的不同以不同的颜色高亮显示，此处操作为“新增”，显示在列表最后，且为“绿色高亮”； - 如本次打点未完成，请重复上述步骤；如已完成，则在摘要处填写有关本次操作的具体内容，如 添加甜甜花 ，或可以简单一点就写一句 新增点位 甚至是 new/add 。具体要写什么没有具体格式或要求，但至少建议你最少写出这次改动你要干什么，因为管理员只能看到代码变更，无法看到你实际干了什么。填写完摘要后单击保存。通常情况下，保存成功后浏览器会跳出弹窗提示，浏览器上方也会跳出类似“保存XXX数据成功！”的提示，随后自动刷新页面。但如用户为初次尝试打点，则在提交时可能会遇到浏览器黑屏同时无法操作的情况。需注意，此时不是你的浏览器卡了，而是你的本次操作正在等待管理员审核，因此请及时私聊地图审核管理员进行确认： --- 若用户在“原神酒馆鱼塘”审核群中，则可直接在群内@或私聊 Xiaojie-急事要事请私聊； 如不在审核群中，则可单击本链接以私聊地图审核管理员； **重要：如果你是来自洛克王国世界BWIKI的同学，请自行联系自己Wiki的审核，上述链接仅能解决原神Wiki内的审核问题； 或者如果有洛王Wiki的管理看到的话也可以在洛王BWiki交流群内 @爱弥斯是种好文明 来联系我修改，感谢理解** --- - 但理论上**建议每隔一段时间提交一次，否则容易发生页面卡顿，或新用户短时间提交大量编辑导致被WIki判定为页面破坏等情况，最终导致点位提交失败。** - 如果想退出打点模式，点击“绘制标记”旁的“取消”按钮即可；**如果要关闭整个工具箱，请先退出打点模式，再关工具箱，否则你会获得一个点位随宠跟着你满世界放生点位！** |

#### 删除点位

| |
| --- |
| - 前两步操作一致，先从左侧的点位列表中，通过鼠标左键单击来选择你想要删除的点位的点位类型（比如想删某个甜甜花，则在点位类型中选中甜甜花这个类）。 - 然后点击打点工具箱中的“删除图层”按钮以进入删除模式（顺数下来第四个的橡皮擦） - 将鼠标移至你想要删除的点位上，单击鼠标左键，此时点位消失。 - 回到左侧的点位列表，打开“控制台”，其中会出现刚才删除的点位（本次操作中的删除点位会在“当前点位列表”中以红色高亮样式显示，且上方“变动点位”中的操作关键字为“删除”） - **请注意，由于本次操作为敏感操作，因此一旦出现 少量多次或大批量 的删除操作，且该操作进入了审核列表，则必须填写具体删除内容摘要，并联系地图审核管理员处理。若三天后未联系一律视为破坏性编辑，将直接拒绝申请。**。 - 如本次删除操作未完成，请重复上述步骤**（在移动地图期间建议先临时关闭删除模式）**；如已完成，则在摘要处填写有关本次操作的具体内容，如 删除甜甜花 ，或可以简单一点就写一句 删除/del 。具体要写什么没有具体格式或要求，但至少建议你最少写出这次改动你要干什么。通常情况下，保存成功后浏览器会跳出弹窗提示，浏览器上方也会跳出类似“保存XXX数据成功！”的提示，随后自动刷新页面。但如用户为初次尝试打点，则在提交时可能会遇到浏览器黑屏同时无法操作的情况。需注意，此时不是你的浏览器卡了，而是你的本次操作正在等待管理员审核，因此请及时私聊地图审核管理员进行确认： --- - 若用户在鱼塘审核群中，则可直接在群内私聊 Xiaojie-急事要事请私聊说明； - 如不在审核群中，请单击本链接以私聊地图审核管理员。由于B站设定，对方未回复前仅能发送一条消息，因此请务必一次性说明清楚情况，如“XX地XX位置的XX点位多余”等。； --- - 为防止出现**误触导致误删点位**的情况出现，建议在完成一次删除操作完成后，先单击橡皮擦左侧的“完成”按钮以关闭“删除模式”，再在需要时重新进入该模式。 - 如果想退出删除模式，点击“删除图层”左侧的“完成”按钮即可；如想关闭打点工具箱，请务必先退出删除模式，否则在拖动时将可能遇到鼠标专员吃点位回扣导致误删点位的情况。 --- - 如果误删了点位但还没保存，可以直接刷新浏览器页面，重新进入打点模式进行操作；如已保存，请及时报备给管理员处理，如果有记录的话建议带上点位类型，如“不小心误删了一个普通宝箱”。没有也行，管理员可以查看历史记录恢复处理，请不必担心。 |

#### 移动点位

| |
| --- |
| - 首先从左侧的点位列表中，通过鼠标左键单击来选择你想要移动的点位的点位类型（比如想挪动某个甜甜花，则在点位类型中选中甜甜花这个类）。 - 然后点击打点工具箱中的“拖拽”按钮以进入移动模式（顺数下来第二个图标） - 将鼠标左键放至想要移动的点位上，**长按**鼠标左键，直接将点位拖动至你想要挪动到的位置，然后松开左键（动图不播放可以点开）。 - 回到左侧的点位列表，切换至「控制台」，会发现控制台里出现了刚才被移动的点位（本次操作中被移动的点位会以黄色高亮样式显示，且操作关键字为修改） - 在摘要处填写有关本次操作的具体内容，如 移动甜甜花 ，并单击保存，保存成功后浏览器会跳出弹窗提示。如遇浏览器黑屏无法操作，则代表本次操作正在等待管理员审核，此时请私聊审核管理员进行确认。 - 完成操作后，为防止出现误触导致移动正确点位的情况出现，最好在完成一次添加操作后临时“取消操作”，需要时再打开/切换至其他功能。 - 如果想退出打点模式，点击“拖曳”按钮左侧的“完成”按钮即可。 |

### 上传所需文件

- 通常来说，为了更好地填充点位信息内容，编辑者可以通过在点位信息页面内上传图片甚至是视频来提供额外信息。通常可以在此处上传的文件有图片、Gif和视频。

#### 上传图片

- 上传图片通常来说可以直接在编辑页面内上传，但考虑到有时候会出现一些预料之外的情况，所以附加一种最泛用的“上车补票”法。

- 编辑页面内上传（仅限PC）
- 特殊：宝箱类图片上传
- 上车补票

| |

### 注意事项

- 该板块旨在举例说明一些在打点过程中容易出现的问题。

#### 关于设备问题

| |
| --- |
| - 所有操作均建议使用PC端进行打点操作，手机端因为手指的宽度问题，打点位置很难一次摁准，同时也存在出现拖动屏幕导致误触等情况的可能性。 |

#### 关于删除点位

| |
| --- |
| - 删除点位虽然不会删除对应的点位详细信息页面，但是也会使原本点位的有内容的页面无法通过正常途径查看，所以建议非必要不删除点位。 - 故而，当发现多余点位时候，若该点位可以用于其它区域（比如多出来的宝箱、怪物等），可先将该点位挪至地图边缘，待日后需要时通过**移动**操作将该点位移至所需位置： - 比如愚人众先遣队的多余点位可以预先挪至一个离主区域很远的空旷地区，同时在点位信息页面写好备注，注明该点位为多余点位，待日后地图更新/怪物营地调整后，再将这个多出来的点挪至新的点位。 |

#### 编辑多类点位保存时的注意事项

| |
| --- |
| - 由于本教程初稿于2023年完成，当时用的还是Map3.0，打点流程与现版本有所不同，所以当初写有这个条目： - 老版本地图一次只能保存当前选中的那一类点位，所以单次打点期间可以保存多次。 - 新版本（4.0）地图一次会保存本次操作中所有状态发生了改变的（特指增删改）的点位，但是保存成功后会刷新页面。 - 所以保存的话建议**分区域**打，自己心里划一个小区域，打完马上保存，防止崩溃/保存不上的情况发生导致一天白干。 |

#### 操作失误打入空点位

| |
| --- |
| - 理论上现在在用Map4.0的小可爱们也遇不到了，因为会跳提示： - 但是还是大概说一下怎么个事： - 老地图可以先开打点模式再去选择点位，这样打出来的会是一个空白点位，没有图标，没有点位信息，什么都没有，也没法保存，解决办法就是先选点位类型，再开打点模式。同时这也是上面每次都一定要强调“被选中点位会有底部高亮”的原因。 - 现在没了这个BUG，只有没上传图标的点位才会出现这个情况。但这种还是可以先打，后面抽空喊管理或者干脆自己上传一个图标，之后就能正常显示了。 |

#### 地图组图片命名规则

| |
| --- |
| - 原则上来说，个人建议在上传图片的时候遵照一个通用的规则，如果你是从QQ直接拖出来的图片，会显示为一串乱码名；如果你通过游戏内截图等方式，后续找图片或者更新上传也不太方便，所以建议根据上传图片的需要，花一点点时间修改为统一的格式，也方便对图片后续的管理： 如果新建的目标页面是宝箱分类下的任意点位：由于模板的关系，该分类的所有点位都会默认创建一个独属于该点位的待上传图片，其固定的命名格式为：宝箱类型-宝箱ID。例如： ``` 普通的宝箱-sampleId 奇馈宝箱-sampleId2 水上的木盒子-sampleId3 ``` --- 另外，虽然与本条目无关，但**奇馈宝箱**的点位信息页面内额外有一个待填写项目，为**图纸名字=**，如果有记录的话可以填写该项，没有的话就算了相信后人智慧。若图纸本身携带有一个单框 「」 ，则也要一并填写，如奇馈宝箱rzbhgxzcog： ``` {{宝箱 |id=rzbhgxzcog |大区域= |小区域= |类型=奇馈宝箱 |提示= |视频教程= |视频分P= |图纸名字=「霜影月华」 }} ``` --- 如果是需要自行上传到点位信息内的图片（如具体位置说明，解密流程方法等信息），则可以**以点位的ID命名，如有多图则可以考虑“后加数字”或“以文字区分”**。例如华丽的宝箱-1aalleml72l和世界任务-1ne1n6lg0ye的点位信息页面： ``` [[File:华丽的宝箱-1aalleml72l-提示.png]] ---------------------------------------- [[File:1ne1n6lg0ye接取.png|600px]]<br> [[File:1ne1n6lg0ye-1.png|600px]]<br> [[File:1ne1n6lg0ye-2.png|600px]]<br> [[File:1ne1n6lg0ye-3.png|600px]]<br> [[File:1ne1n6lg0ye-4.png|600px]]<br> ``` |
