攻略正文------------

写此贴的目的(重要!!!!):
①给还挣扎在提瓦特大陆上未满命的女仆厨们以及有未满命女仆并跃跃欲试的米友一些帮助
②为之后的女仆攻略做准备

数据提供:
命座
普攻倍率
小技能倍率
大招倍率

注意:
①为了体现出当前命座与六命座的差距，所以参照对象都是六命座
②为了使盾破的伤害更能体现出命座的区别，所以下面计算伤害都是以15S(一个大招持续时间)为基准的，且只记录一次盾破的伤害

攻略核心思想:
①因为女仆6命与非六命最大的区别就在于防御力的转化率不同，所以为了规避这个问题带来的计算复杂性，设总防御力是总攻击力(开大招前)的m倍
②为了计算盾破伤害对总伤害的影响所以计算15s的总伤，所以下面公式中\*7是因为15s可以打7轮普攻(可参考《女仆(诺艾尔)杂谈----普攻与重击如何选择》)，+4是因为盾破的倍率是400％。

开始计算(仅以大招LV11，小技能LV12，普攻LV10讨论,注意因为是计算15S的伤害，所以C 是一个攻击流程的倍率:156+145+171+224 = 696，重击情况不考虑，原因请参考合集中另外一篇攻略《女仆(诺艾尔)杂谈----普攻与重击如何选择》):

伤害计算公式(不考虑元素反应和抗性):
S = [(7C+4)) \* (at + mZat)]\* A \* B + Dmat \* A \* B
Dmat \* A \* B是小技能伤害(非盾破)
S:最终伤害 atk:总攻击 C:技能倍率 A:暴击收益 Z:防御力转换率 B:额外增伤(包括元素增伤，其它增伤) D:小技能的倍率(非盾破)

公式整理(暂时不带入技能倍率数值，为了计算出通用公式):
S = [(7C+4)) \* (at + mZat)]\* A \* B + Dmat\*A\*B
AB是不受命座影响的，所以A\*B看成一个整体E
S = [(7C+4)) \* (at + mZat)]\* E + DmatE

```
=(7Cat + 4at + 7mZCat + 4mZat + Dmat) * E
=(7mZCat + 4mZat + 7Cat + 4at + Dmat) * E
=[(7ZC +D + 4Z)m + (7C + 4)]at * E
```

4，5，6命伤害公式: [(7ZC +D + 4Z)m + (7C + 4)]at \* E
0，1，2，3命伤害公式:[(7ZC +D + Z)m + 7C]at \* E(因为少了盾破伤害所以直接把4拿掉就好了)

分类讨论:(下面将4~6命归为高命座，0~3命归为低命座)
代入各技能倍率:
S高 =[(7ZC +D + 4Z)m + (7C + 4)]at \* E

```
=[(7*6.96Z + 2.4 + 4Z)m +7 * 6.96 + 4]at * E
=[(52.72Z + 2.4)m + 52.72]at * E
```

S低 =[(7ZC +D + Z)m + 7C]at \* E

```
=[(7*6.96Z +2.04 + Z)m +7 * 6.96]at * E
=[(49.72Z + 2.04)m + 48.72] at * E
```

6命座(大招转换率1.26):
S6 =[(52.72 \* 1.26+ 2.4)m + 52.72]at \* E

```
=(68.8272m+ 52.72) * at * E
≈(68.83m + 52.72) * at * E
```

{为了方便看所以分析的时候不纠结这个，表格中计算不会存在这个问题}

5命座(大招转换率0.76):
S5 = [(52.72 \* 0.76 + 2.4)m + 52.72]at \* E

```
=(42.4672m + 52.72) * at * E
≈(42.47m + 52.72) * at * E
```

4命座(大招转换率0.64)
S4 =[(52.72 \* 0.64 + 2.4)m + 52.72]at \* E

```
=(36.1408m + 52.72) * at *E
≈(36.14m + 52.72) * at *E
```

0~3命座(大招转换率0.64)
S3 =[(49.72 \* 0.64+ 2.04)m + 48.72]at \* E

```
=(33.8608m + 48.72) * at *E
≈(33.86m + 48.72) * at *E
```

S6/S5 = [(68.83m + 52.72) \* at \* E]/ [(66.83m + 52.72) \* at \* E]

```
=(68.83m + 52.72)/ (42.47m + 52.72)
```

S6/S4 = [(68.83m + 52.72) \* at \* E]/[ (36.14m + 52.72) \* at \*E]

```
=(68.83m + 52.72)/( 36.14m + 52.72)
```

S6/S低=[(68.83m + 52.72) \* at \* E]/ [(49.72 \* 0.64+ 2.04)m + 48.72]at \* E]

```
=(68.83m + 52.72)/ (33.86m + 48.72)
```
