## 角色定位

安柏的定位是偏速切的输出角色。安柏的元素爆发为特殊的每1秒/3次攻击一次火元素附着的计时/计数器，2秒内可施加6~7次火元素附着，具有短时间内超强的挂火能力，并且兔兔伯爵可以被元素附着配合风系角色染色扩散，使得安柏可以辅助冰系角色打融化、水系角色打蒸发等的打法。此外，安柏6命后施放元素爆发可以给全队提供一定移速与攻击力加成。

| 冬极白星 | 冬极白星是安柏的输出向毕业武器，副属性提供暴击率，武器特效提供元素战技与元素爆发增伤，契合安柏的主要输出手段。安柏可以通过普攻、重击、元素战技、元素爆发为武器特效叠层获得「白夜极星」效果，获得高额攻击力加成。 |
| 若水 最初的大魔术 猎人之径 | 若水副属性提供高额暴击伤害，武器特效的增伤需要靠近敌人触发，输出能力仅次于冬极白星。 最初的大魔术副属性提供暴击伤害，武器特效在通常的双火队中提供32%的攻击力加成，武器特效还常驻提供重击加成，收益较高。 猎人之径副属性提供高额暴击率，武器特效提供常驻元素伤害加成的同时还提供精通转重击增伤，对于需要叠一些元素精通的安柏来说武器特效可以在一定程度上提升重击伤害。 |
| 飞雷之弦振 天空之翼 | 飞雷之弦振暴击伤害加成与最初的大魔术相同，但武器特效的普攻增伤无用，攻击力加成也比双火最初的大魔术提供的少。 天空之翼提供高基础攻击力弥补安柏自身基础攻击力低的缺点，副属性与武器特效提供较多双暴，武器特效还额外提供一点物理伤害。 |
| 测距规 静谧之曲 | 测距规在绑定持续治疗位时期望为四星最高，武器特效可提供攻击力加成与高额元素伤害加成。 静谧之曲的上限低于测距规，但武器特效触发较简单，只需受到一次治疗即可，提供的增伤对于安柏的所有伤害均有效。 |
| 绝弦 | 绝弦副属性提供元素精通可以提升安柏触发的增幅反应伤害，武器特效满精时提供高额元素战技与元素爆发增伤。 |
| 黑岩战弓 | 黑岩战弓副属性提供高额暴击伤害，虽然武器特效满层提供高额攻击力，但对单攻坚时难以触发。 |
| 烈阳之嗣 | 烈阳之嗣基础攻击力较高，副属性提供暴击率，武器特效提供了高额的对单重击加成，适用于蓄力箭输出流安柏。 |
| 试作澹月 | 试作澹月适用于怪物有弱点的情形，命中弱点后可获得高额攻击力加成，对安柏的所有伤害均有提升，收益较高，但当怪物无弱点时武器特效则沦为白板。 |
