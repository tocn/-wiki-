#### 开始计算

因为3和7的最小公倍数为21，所以为了计算方便后面计算的伤害是21S的总伤害

分类讨论(仅以LV10比较):

1、二命以下
伤害计算公式(不考虑元素反应和抗性):
S= (at \* m) \* A \* B
S:最终伤害 at:总攻击 m:技能倍率 A暴击收益 B额外增伤(包括元素增伤，其它增伤)

#### 公式整理

S = [at\* A \* B] \*m
因为[at \* A \* B]是不会因为普攻或者重击改变的，所以可以把[at \* A \* B]看成一个整体C
S = C \* m

普攻倍率(一个流程3s，21s可以打7个流程)
单个攻击流程倍率：
156+145+171+224=696
每秒倍率:
696\*7/21=232
S普 = 232C

重击倍率(一个流程7s，21s可以打3个流程)
单个重击流程倍率:
100\*9+179=1079
每秒倍率:
1079\*3/21≈154.14
S重=154.14C

S普 / S重=232C/154.14C≈1.505

综上:2命以下女仆使用普攻的最终伤害是使用重击伤害的1.505倍(同时也说明普攻每秒的倍率是重击每秒的倍率的1.505倍)

2、二命及以上

伤害计算公式(不考虑元素反应和抗性):
S = (at \* m) \* A \* (1 + b)
S:最终伤害 at:总攻击 m:技能倍率 A:暴击收益 b:额外增伤(包括元素增伤，其它增伤)
S = [at \* A] \* m \* (1+b)
因为[at \* A]是不会因为普攻或者重击改变的，所以可以把
[at \* A]看成一个整体C
S = C \* m \* (1+b)

设重击的倍率为n，则普攻的倍率为1.5n(由分类一得出结论，且为了方便计算省去0.005)
S普 = C \* 1.5n \* (1+b)
S重= C \* n \* (1+b+0.15) = C \* n \* (1+b) + 0.15n \* C
S普/ S重 = C \* 1.5n \* (1+b) / [C \* n \* (1+b) + 0.15n \* C]

```
=1.5 * (1+b)/ [ (1+b) + 0.15]
```

设y=S普/S重,b=0.01x得(为了使表格更直观，所以设0.01x)
y = 1.5 (1+ 0.01x)/[1+0.01x + 0.15]

```
=1.5(1+0.01x+0.15-0.15)/ [1+0.01x + 0.15]
=[1.5(1+0.01x+0.15)-0.225] / [1+0.01x + 0.15]
=1.5-0.225/[1+0.01x+0.15]
=1.5-22.5/[100+x+15]
```

## 总结论

①二命以下女仆普攻每秒最终伤害大约是重击每秒最终伤害的1.5倍（技能LV1~LV10都是如此）

②二命及以上女仆普攻每秒最终伤害大约是重击每秒最终伤害的1.31~1.43倍（额外伤害加成取值范围1~200，LV1~LV10都是如此，因为倍率差不多都在1.5，参考分类讨论2可以得出结论）

③普攻21s可以打28下，重击21s可以打30下，回血次数相差并不是很明显

## 楼主建议

从数据可以很明显看出普攻与重击的差距，且两者造成伤害的速率相差不了多少的，所以重击也不存在回血快的优势，重击的优势在于打击面比较大，所以挣扎在提瓦特大陆的女仆厨们，不要再重击拉，多走位尽量保证怪都在自己前方，输出会高非常多。੭ ᐕ)੭\*⁾⁾
