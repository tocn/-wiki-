原神从开服以来，对刻晴的争议一直很大，刮痧，免疫，刻师傅，牛杂师傅，最弱五星等等一堆黑称，都殷实了有很大一部分玩家觉得刻晴输出低下，雷元素系列反应伤害低下等等问题。刻晴真爱党也不甘示弱，刷出最好的圣遗物，配上最好的武器，去挑战各种大世界boss证实刻晴伤害不低，低是因为你的圣遗物不行，武器不行。但是此举治标不治本，所有角色在拥有五件+8/+9圣遗物的情况下均能打出不俗的伤害数值，所以双方的口水战一直也没用停过。
贴主最初被刻晴吸引的不是外貌颜值，而是她那惊人的重击攻速。在原神中，很少会出现增加攻速的属性，目前1.4版本已知的，也仅有重云的元素战技（E）；武器天空之脊的被动，还不能随精炼等级提升而增加；雷泽的元素爆发，天空之刃精炼词条。而且刻晴的重击伤害数值在单手剑角色中应该是数一数二的，高攻速高倍率造就了重击流刻晴的可玩性。但是重击流刻晴无法避免的一个问题就是体力消耗，刻晴的重击消耗为一次25体力，在目前只开了两国的情况下，收集完双瞳的旅行者体力上限也仅有240，甚至无法支撑10个重击的体力消耗，在1.4现有的圣遗物基础上，重击流刻晴只能选择染血骑士4件套作为圣遗物套装，并且由于染血骑士2件套的效果，大部分旅行者默认染血刻晴是走物理流，但是贴主在最近的一次直播帮别人打深渊的时候，有幸体验到了一次火刻晴，从而萌生了染色刻晴的流派基础思路。
目前，大部分角色只能给自己的武器附魔。已知能给其他角色武器附魔的只有重云和6命班尼特。而6命班尼特造价过高，而且会限制住班尼特辅助的通用性，从而造就了6命班尼特稀少的现象，那就先从染冰刻晴开始。
```

```
重云给刻晴提供染色对配置的唯一要求就是有祭礼大剑，精炼越高越好，能有效减少刻晴附魔冰元素的空档期，从而保证输出。在介绍玩法前，先简单介绍下染色刻晴需要什么样的圣遗物，武器需要使用什么。
```

1.圣遗物，没啥好说的，为了尽可能的压缩刻晴的输出空档，染血4永远滴神。
圣遗物属性方面需要根据携带的武器来调整，在下面的武器一列中提及。
2.武器，目前已知的，刻晴用的比较多的武器有匣里（攻击），行纪黑剑（暴击率），在没有五星单手剑的情况下，这两种武器是旅行者们给刻晴携带最多的武器。五星武器的话，目前已知的单手剑中都比较适合刻晴，肯定会有人质疑为什么我会觉得天空剑也适合刻晴，后续会谈到。
1.匣里：匣里对染色刻晴的适用性并不是很好，但是估计大部分使用刻晴的旅行者都升级了匣里，所以也提一嘴。匣里最适合的是物理刻晴和火刻晴，以及自己染色自己的雷刻晴。但是在收益方面，雷>火>物理（脑测，根据附魔时间做出的判断，不触发元素反应）。圣遗物配置方面的话，匣里的副词条是百分比攻击力，为了追求输出的稳定性，圣遗物我们选择暴击头，副词条：暴击率>=暴击伤害>攻击力>元素充能。
元素精通需要单独拿出来讲，需要涉及到队伍配合等等其他问题。
2.黑剑：黑剑的被动和副属性在4星武器中简直完美契合染色重击流刻晴。高贵的暴击属性，已经对精炼提升重击伤害的效果，在高精的情况下绝对不亚于五星武器。
圣遗物方面选择暴击伤害头，
副词条：双爆>攻击力>元素充。
3.天空之刃（充能）：我们首先来看一下天空之刃的面板，副词条充能效率，在实战属性当中几乎是刻晴不需要的属性，但是，精炼词条对于刻晴来说，几乎是完美属性。以精1 为例，精炼词条提供4%的暴击率，释放元素爆发时，能提供10%的攻速和移速，并且会普攻和重击命中时会附带20%攻击力的白字伤害，持续时间，12秒，刻晴元素爆发的CD也是12秒。此时，再看之前的元素充能副词条，是不是就顺眼许多了？讲了这么多，再说说这把武器的适用性：物理>冰>其他。
最契合物理大家应该都明白，天空之刃的精炼词条白字也能吃到物理伤害加成，冰雷超导减物理防御加成，能暴击，攻速越快，收益越高。
但是这里为什么用其他来代替而单独把冰拎出来说，首先，重云附魔冰元素即使时精5 的祭礼大剑，也是有空档期的，而不考虑队伍中的其他角色的情况下，此时只能打出冰雷超导的元素反应，而上面提到的天空之刃精炼白字效果能吃到超导减抗的收益，虽然空档期会很小，但是蚊子腿再细也是肉。所以单独拎出来。
4.风鹰剑（物理）：这没什么好说的，使用风鹰剑的话就只能玩物理刻晴了，其他染色属性的收益甚至不如黑剑，毕竟相比起来会少一条武器的副属性，损失太大不值得。
5.盾剑（攻击）：极高的攻击面板，以及提供超高的护盾强效，不搭配钟离的话，会有点难受，对输出伤害的数值影响不大，但是搭配钟离的话基本会处在一个安逸的输出环境下，有效减少闪避体力消耗，从而提高整体输出。
适用性：普遍适用，基本不会相差太多。
6.绿剑（暴击率）：纯粹的面板剑，44.1%的暴击率和精炼词条让圣遗物属性搭配变得极为容易。但是高精收益看上去不是很好，所以精1是最具有性价比的。（贴主染血本泡了两个月，圣遗物属性究极难配，折磨的生不如死，一把绿剑解决所有问题。）
适用性：均适用。
仔细看到这里的读者可能会发现，我在上面的圣遗物属性中只提到了头的属性，但是丝毫没有提杯子应该带什么，有人会说了，这还用提，肯定用什么色带什么杯子。确实，道理是这个道理。但是不是每个人能刷出每个属性的极品属性杯。所以综合考虑上述武器，杯子选用攻击杯较为合适。
为什么选择用攻击杯，让我来讲一讲攻击杯的好处：
1.无论是雷刻晴，物理刻晴，冰刻晴这三种比较容易获得的属性，攻击杯都能吃到加成。
2.考虑到不是所有的刻晴玩家都拥有五星武器的超高面板，选用攻击杯弥补面板也是个不错的选择。
3.在针对同一层不同间的深渊时（举例：某层深渊第一间上半有火之讨债人，第二间上半有冰莹术士，第三间上半有遗迹守卫），不用为了属性克制而频繁切出去重新打前面的关卡。
4.成本低，如果有刻晴玩家看到我的帖子之后选择了染色刻晴，但是并没有合适的染血圣遗物，那么就需要去重新刷圣遗物，重新刷一套合适的圣遗物有多花功夫就不用我多说了吧，如果还去追求属性杯，那么培养成本将会大大提升。仅考虑三种最容易得到的玩法，就需要准备物理杯，雷伤杯，冰伤杯，等于一个角色要准备7件圣遗物，培养成本太高，即使是一二线55级以上的旅行者，也不能保证自己的仓库中有足够优秀的属性杯供染色刻晴挑选。
说完好处肯定要说坏处，其实也没什么坏处：
1.在不考虑杯子副词条的情况下，输出数值肯定没有对应的属性杯高。
2.攻击力稀释，攻击力太高造成的收益就会降低。影响最大的是火刻晴，因为需要班尼特的大招来提供火附魔，而班尼特大招自带超高攻击力增幅，攻击杯带来的提升收益就会大打折扣，如果有旅行者尝试火刻晴的话，最好还是准备一个火伤杯。

以下是贴主自行测试的数据，不够精准大家看个大概就好了
E：附魔空档期约为1s（CD:7.5s）
Q：无敌帧大约为2s(CD:12s)
QEE/EEQ爆发约为3s
1级A：223.6%（每级提升33.9%）
1级A1+A蓄：33%+88.6%（每级提升5.3%+26.3%）
1级爆E（E+A1+A蓄）：174% （每级提升12%）
1级E：222.6% （每级提升：16.8%反色）
1级Q：419.8% （每级提升47.2%）
设E技能等级为a，Q技能等级为b
则QEE/EEQ爆发伤害每秒平均倍率计算公式为：
DPS=【222.6%+419.8%+16.8%a+47.2%b】/3（该公式不考虑一切加成，仅为实际伤害基础值，即未受到任何加成之前的数值）
A蓄（A1+重击）约为1s
DPS=【121.6%+31.6%a】/1
体力值回复：约为25点/s（体力值上限240点）
染色刻晴输出手法：
A1+A蓄，由于刻晴机制的原因，每次蓄力重击之前都会进行一次普攻，也就是第一段普通攻击，简称A1。所以染色刻晴的输出手法为A1+A蓄。E和Q技能主要为增伤挂元素提供增益BUFF的手段。（ps：为什么刻晴能走物理流，给各位普及一下，刻晴的E是可以通过非位移的手段来主动引爆，即E1+A1+A蓄引爆E技能的雷楔，从而取消E2的武器附魔，达到打出超导反应并且不附魔的物理流收益。）

刻晴的Q技能在60级突破之后拥有被动技能2，会在释放Q技能之后为刻晴提供暴击率和元素充能，被动技能2配合天空之刃的精炼词条能有效缓解天空刻晴的暴击率属性压力，这也是我比较喜欢天空之刃的原因之一。

输出手法大致就说这么多，也没什么需要注意的细节，只不过从传统刻晴的以EQ为主要输出，普攻重击为辅助输出转变成了以普攻重击输出为主，EQ为辅而已罢了。

```
配队思路，上面在讲圣遗物属性的时候有说到元素精通属性要单独拿出来说就是因为配队问题。配队主要分为仅附魔队和附魔反应队。
```

仅附魔队主要以减少怪物抗性为增伤手段，那么队伍中除了刻晴和附魔挂件之外，就需要一个风属性的角色带风4套提供减抗或者钟离的护盾减抗。附魔反应队则需要根据染色刻晴的附魔属性来搭配其他元素从而打出高额元素反应输出（刻晴：我也想成为火属性.jpg）。主要还是根据需要应对的怪物阵容来做出选择，单独说哪些哪些阵容强没有意义。

```
最后在备注一点，刻晴越高命，染色的收益就会越低，虽然能玩，但是某些命座的增伤会被浪费掉，有些不值得，但是不代表不能玩，只不过命座的加成几乎没有了。顺便提一嘴，如果后续开放其他国家的神瞳等级提升也能带来体力值上限提升的话，染色刻晴直接起飞。
