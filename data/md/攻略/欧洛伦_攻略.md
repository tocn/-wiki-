夜翳的通感 角色突破等级1解锁

描述
队伍中的附近的角色触发「夜魂迸发」后，欧洛伦将获得40点夜魂值。施放元素战技后的15秒内，队伍中其他角色的元素类型为水元素或雷元素的攻击命中敌人时，欧洛伦将获得5点夜魂值，该效果每0.3秒至多触发一次，在持续期间内至多触发10次。
欧洛伦的夜魂值上限为80点。

此外，附近的敌人受到感电或月感电反应的伤害或队伍中附近的其他角色造成的具有夜魂性质的伤害时，若欧洛伦拥有至少10点夜魂值，欧洛伦将消耗10点夜魂值，进入夜魂加持状态，并触发「显象超感」效果：基于欧洛伦攻击力的160%，对周围至多4名敌人造成具有夜魂性质的雷元素伤害。上述效果每1.8秒至多触发一次。

**夜魂加持·欧洛伦**
欧洛伦的夜魂加持状态持续至多6秒。

灵相的触媒 角色突破等级4解锁

描述
元素战技暝色缒索中的宿灵球命中敌人后，欧洛伦将获得「灵相之印」效果，持续15秒。

**灵相之印**
队伍中附近的当前场上角色普攻、重击或下落攻击命中敌人后，将为该角色恢复3点元素能量；若欧洛伦处于队伍后台，还会为欧洛伦恢复3点元素能量。该效果每1秒至多触发一次，在持续期间内至多触发3次。

夜域赐礼·流雾跃影

描述
在纳塔存在燃素机制的区域时，能够进行夜魂传递·欧洛伦。当前场上角色位于空中时，切换欧洛伦登场时触发：欧洛伦将高高腾跃而起。自己的队伍每10秒可以触发一次夜魂传递。

长按瞄准时，欧洛伦会进入「灵觉」状态，处于这种状态下时，欧洛伦可以与「灵谜涂鸦」和「灵谜纹」交互，提取其中的信息与力量，这些物件的交互规则沿袭暝视龙的交互规则。

此外，长按跳跃时，欧洛伦将消耗75点体力腾跃而起；在纳塔存在燃素机制的区域时，欧洛伦会优先消耗5点燃素，腾跃至更高的高度。
位于空中时，欧洛伦可以长按普通攻击，消耗燃素或体力进行瞄准。

注：欧洛伦在空中瞄准状态下每秒消耗2.5点燃素或20点体力，持续期间内视为进入夜魂加持状态。[set-1 1]

## 角色定位

欧洛伦是一名雷元素后台输出兼辅助角色，辅助能力包括：

- 元素爆发的「超音灵眼」较优秀的嘲讽机制
- 元素战技配合天赋「灵相的触媒」的「灵相之印」为场上角色回能
- 由于可以进入夜魂加持状态，在可以触发雷元素相关反应的队伍中触发 烬城勇者绘卷 四件套（简称“勇者套”）的满层增伤
- 第六命座在欧洛伦触发固有天赋「夜翳的通感「的「显象超感」后为场上角色加攻

其中烬城勇者绘卷四件套的增伤是欧洛伦的**核心辅助能力**，配队时应优先围绕该能力展开，而元素爆发与天赋的「显象超感」属于欧洛伦的**核心输出技能**，其中「显象超感」需要欧洛伦进入夜魂加持状态后触发，为无类型攻击（不属于元素战技、元素爆发等任意类型）。
欧洛伦进入夜魂加持状态的条件较为特殊，其条件为：欧洛伦拥有至少10点夜魂值的前提下，附近敌人受到感电或*月感电 月感电*反应伤害，或**其他队友**造成夜魂性质伤害。
欧洛伦夜魂值变动的途径包括：

- 队内角色触发「夜魂迸发」后**获得40点**；
- 施放元素战技后15秒内**其他队友**水元素或雷元素攻击命中敌人**获得5点**，每0.3秒至多1次，每轮至多10次；
- 进入夜魂加持状态后每次触发「显象超感」效果**消耗10点**，每1.8秒至多一次。

由以上分析可知，欧洛伦需要在水雷感电、*月感电 月感电*以及纳塔夜魂体系（包括纳塔主C队伍如瓦雷莎/玛薇卡超载体系、基尼奇燃烧体系、恰斯卡混伤等乃至编入茜特菈莉、希诺宁、伊安珊等纳塔辅助队友的各类队伍）中才能进入夜魂加持状态，才能最大化自身的辅助能力与输出能力。符合以上条件的情况下，欧洛伦即使全程处于后台，也能持续进入夜魂加持状态并触发「显象超感」效果，从而可以触发「烬城勇者绘卷」四件套的增伤，因此在高金队伍中，除非欧洛伦装备「终末嗟叹之诗」等武器需要触发武器特效，否则欧洛伦可以全程不上场（纯后台玩法）；低金队伍中需要欧洛伦元素爆发的输出能力补充伤害，仍需要欧洛伦上场。总而言之，相比于另一名雷元素后台输出角色菲谢尔，欧洛伦对单输出能力更弱而对群能力更强。
欧洛伦的元素爆发持续时间短，并不适合作为超绽放触发器，且在搭配草元素队友而无纳塔夜魂队友时难以进入夜魂加持状态，故本篇不作详细说明。

| 终末嗟叹之诗 | 「终末嗟叹之诗」副属性的高额元素充能效率可解放欧洛伦的充能压力（四命及以上欧洛伦部分配队充能溢出），武器特效为自身提供元素精通，欧洛伦可以通过元素战技与元素爆发触发武器特效的「千年的大乐章·别离之歌」效果，为全队提供攻击力与元素精通，为全队总伤的贡献可高于欧洛伦使用任意输出向武器带来的单人伤害提升。单雷队中将充能词条换成攻击词条后，在元素精通带来的感电反应伤害加成下，伤害期望甚至可以超越猎人之径，对于四命以下欧洛伦收益更高。不适用于纯后台玩法的欧洛伦（不切出欧洛伦上场施放元素爆发就无法叠层）。 |
| 西风猎弓 | 「西风猎弓」作为**单雷**欧洛伦的**毕业武器之一**，副属性提供高额元素充能效率，武器特效在装备者前台暴击后产球，降低全队充能需求。 |
| 最初的大魔术 天空之翼 冬极白星 黎明破晓之史 | 「最初的大魔术」为提供暴击伤害与攻击力的面板武器，双雷时可作为输出向毕业武器，单雷时推荐度大幅下调。 「天空之翼」基础攻击力高，提供暴击率与暴击伤害，还有小范围物理伤害倍率。 「冬极白星」基础攻击力较高，副属性提供高额暴击率，武器特效提供元素战技与元素爆发增伤，契合欧洛伦的主要输出手段，武器特效还额外提供攻击力加成，仅凭借元素战技与元素爆发的2层白夜极星就可略胜「若水」，若穿插普攻多叠一层后可更高。欧洛伦的元素爆发没有快照机制（不锁面板），因此元素爆发本身叠的白夜极星的攻击力加成就可以增幅元素爆发伤害。不适用于纯后台玩法的欧洛伦（不切出欧洛伦上场施放元素爆发就无法叠层）。 「黎明破晓之史」基础攻击力高，副属性提供暴击伤害，武器特效提供高额元素战技与元素爆发增伤。 |
| 若水 | 「若水」副属性提供极高暴击伤害，武器特效提供一定增伤，要求欧洛伦靠近敌人。伤害期望为「冬极白星」下的第一档。由于欧洛伦已有烬城勇者绘卷四件套的高额增伤，搭配芙宁娜等增伤辅助时建议采用攻击杯。 |
| 猎人之径 飞雷之弦振 | 「猎人之径」为提供暴击率与元素增伤的面板武器。 「飞雷之弦振」为提供暴击伤害与攻击力加成的面板武器。 |
| 星鹫赤羽 霜结的誓金枝 测距规 | 「星鹫赤羽」的副属性提供高额暴击伤害，武器特效无条件提供一定元素爆发增伤。武器特效的攻击力加成无法触发。 「霜结的誓金枝」仅作为副属性提供高额暴击伤害的面板武器。 「测距规」在四星武器中上限最高但触发条件苛刻，对于长期处于后台的欧洛伦而言通常绑定持续群体治疗角色（或在搭配 芙宁娜 时持续触发其天赋）才能叠满武器特效，满精炼叠满后可超越精一「星鹫赤羽」；单次治疗的情况下推荐度下调至「星静谧之曲」的水平。 |
| 暗巷猎手 碎链 | 「暗巷猎手」副属性提供攻击力，武器特效提供高额后台全增伤，是欧洛伦的四星毕业武器之一。 「碎链」副属性与武器特效提供高额攻击力加成，在单雷队或搭配另一名雷元素角色为纳塔角色的双雷队中还可提供少量元素精通。 |
| 阿莫斯之弓 | 「阿莫斯之弓」作为副属性提供高额攻击力的面板武器。 |
| 虹蛇的雨弦 静谧之曲 曚云之月 苍翠猎弓 | 「虹蛇的雨弦」副属性提供较高元素充能效率，武器特效对于常驻后台的欧洛伦可以提供高额攻击力加成，在无四命或单雷队中优先级上升；有四命双雷队中换3个充能词条的情况下伤害表现与本栏武器处于同一水平。 「静谧之曲」副属性提供攻击力，武器特效在绑定治疗角色的情况下可获得增伤，持续8秒，故在治疗角色不能为后台角色治疗的情况下覆盖率有限。 「曚云之月」副属性提供攻击力，武器特效提供高额元素爆发增伤，但欧洛伦本身元素爆发占比不高，武器特效的收益有限。 「苍翠猎弓」副属性提供暴击率，武器特效提供少量额外伤害。 |
| 落霞 绝弦 | 「落霞」副属性提供元素充能效率，武器特效提供增伤，若将充能词条全部换攻击词条配平后期望与全队240能量的「曚云之月」接近。 「绝弦」武器特效提供高额元素战技与元素爆发增伤，副属性的元素精通仅在部分配队中存在足够的收益。 |
