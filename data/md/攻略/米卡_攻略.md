星霜的流旋

描述
利用手弩攻击敌人，并为队伍中附近的所有角色赋予灵风状态。处于灵风状态下的角色处于场上时，攻击速度将获得提升。
依据点按、长按，以不同的方式产生效果。

**点按**
快速发射能够穿透敌人的霜流矢，对触及的敌人造成冰元素伤害。

**长按**
进行瞄准，并对一名瞄准锁定的敌人发射冰星信标，造成冰元素伤害。冰星信标命中后，将升空爆裂，向周围至多3名其他敌人发射冰星破片，造成冰元素伤害。

速射牵制 角色突破等级1解锁

描述
在下列情况下，星霜的流旋的灵风状态将获得侦明效果强化，使角色处于场上时，造成的物理伤害提升10%：

- 霜流矢命中超过1名敌人时，每额外命中1名敌人就产生1层侦明效果；
- 冰星破片命中敌人时，将产生1层侦明效果。每枚冰星破片只能触发1次。

灵风状态的侦明效果至多叠加3层，在持续期间内重复施放星霜的流旋时，将移除原有的灵风状态与其侦明效果。

地貌测绘 角色突破等级4解锁

描述
同时处于苍翎的颂愿的鹰翎状态与星霜的流旋的灵风状态下的当前场上角色，在攻击造成暴击时，灵风状态将产生1层突破天赋「速射牵制」的侦明效果。在一次灵风状态的持续期间内，通过这种方式至多产生1层侦明效果。
此外，灵风状态下侦明效果叠加层数上限提升1层。
需要解锁突破天赋「速射牵制」。

## 角色定位

米卡的定位是冰元素增伤兼治疗辅助角色，核心技能是元素战技与元素爆发，元素战技赋予的灵风状态可联动天赋「速射牵制」、「地貌测绘」的侦明效果强化以及第二命座、第六命座，每层侦明效果为场上角色提供10%物理伤害加成，灵风状态本身可为场上角色提供高额攻速加成，元素爆发可提供单次全队治疗+持续单体治疗（鹰翎），零命时每2.5秒一次（共6次），可与芙宁娜的气氛值产生联动。米卡多数情况下在物理队中就业，少数情况下与攻速收益较高的非物伤角色组队（如莱欧斯利、流浪者等）。

### 角色技能解析

米卡元素战技为天赋「速射牵制」产生的侦明效果层数取决于元素战技命中的敌人数量，实战中元素战技点按或长按取决于目标的站位，若目标在一条线上，可以选择点按元素战技发射可以穿透敌人的霜流矢，若目标较分散，则可以选择长按元素战技发射冰星信标，利用冰星信标命中后升空爆裂产生的冰星破片命中敌人，但无论是霜流矢还是冰星破片命中范围均较小。点按元素战技的霜流矢以前方0.4米为中心，影响范围2.5米；长按元素战技的冰星破片影响范围10米。需要注意的是，长按元素战技发射的冰星破片数量取决于附近的敌人数量，若附近没有其他敌人（对单）则不会发射冰星破片。米卡对单时点按元素战技即可（相比于长按所花费的时间更短），因为未解锁二命时无论是点按还是长按元素战技在对单时天赋「速射牵制」都无法提供侦明效果，只能通过天赋「地貌测绘」同时利用元素战技的灵风与元素爆发的鹰翎提供1层侦明效果。非满命米卡至多叠加4层侦明效果，对应的是元素战技至多叠加3层+天赋「地貌测绘」1层。
米卡的命座影响如下：

- 第一命座配合3级元素战技的15%攻速加成可将鹰翎的总治疗数提升至7次
- 第二命座使米卡无论点按还是长按元素战技都能额外获得一层侦明效果（不超过层数上限的情况下），解锁二命后米卡对单时元素战技也能提供1层侦明效果（配合天赋「地貌测绘」共2层）
- 第四命座大幅降低米卡的充能需求，每轮元素爆发至多回复15点元素能量
- 第五命座可将攻速加成上限从22%提升至25%，同时配合第一命座在元素战技等级13级时可将鹰翎的回复间隔降低至2秒，每轮总治疗数提升至8次
- 第六命座可以提升场上角色物理伤害的暴击伤害，同时提升一层侦明效果叠加层数的上限（最高5层）

| 沙中伟贤的对答 | 沙中伟贤的对答副属性生命值可提高元素爆发治疗量，特效提供回能降低充能压力。武器特效的回能冷却时间为10秒，而米卡元素爆发的鹰翎持续时间长达15秒，大部分队伍每轮循环可触发两次武器特效，该武器满精时可使四命及以上米卡基本不需要额外元素充能效率词条。 |
| 香韵奏者 | 香韵奏者武器特效可在米卡治疗队友后为受治疗队友提供攻击力加成，但该武器不提供充能，充能需求较大，更适合米卡拥有第四命座且队内有其他冰元素角色帮助米卡充能的情况，或是队内已有其他治疗位而米卡放弃天赋「地貌测绘」10%物伤加成情况。 |
| 西风长枪 | 西风长枪满级副属性为30.6%元素充能效率，武器特效提供无色能量微粒，需要堆高暴击率触发，适合**需要米卡帮助队友充能**的情形（如优菈、芙宁娜队），同时也可以降低米卡自身的充能压力。米卡的元素爆发没有伤害，元素战技在对群时有多段伤害但在对单时只有单段伤害，因此米卡装备该武器时需堆相当高暴击率，且可能需要穿插普攻暴击以触发武器特效，即使如此，装备西风长枪对于优菈等极度缺能的队友来说依旧十分值得（米卡自身所需要的圣遗物词条较少，且生命值只影响米卡的治疗量，故米卡有充分空间堆叠暴击率）。 |
| 薙草之稻光 | 薙草之稻光副属性与武器特效都提供高额元素充能效率，极大降低米卡的充能压力。 |
| 公义的酬报 | 公义的酬报副属性提供生命值，可提升米卡的治疗量，但数值低于沙中伟贤的对答；武器特效在米卡受到一次治疗后可为米卡回能，虽冷却时间短于米卡元素爆发鹰翎状态的持续时间，但米卡通常不会特意改变队伍流程获得第二轮回能，总体而言作为沙中伟贤的对答的下位替代。 |
| 喜多院十文字 | 喜多院十文字副属性元素精通无用，但武器特效可提供回能，要求先施放元素爆发，后施放元素战技。作为锻造武器成本相对较低。 |
| 试作星镰 「渔获」 | 提供较高元素充能效率的面板武器。 |
