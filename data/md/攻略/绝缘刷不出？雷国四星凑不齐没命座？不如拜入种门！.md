## 雷电将军超绽放玩法介绍

### 雷神为什么适合种门？

她的元素战技可以后台攻击，而且是范围攻击，触发地上的草原核非常方便。雷神叠精通就可以打出高额超绽放伤害。

### 大部分攻略都让雷神刷绝缘套走输出流，如果玩种门会不会影响到我将来的资源规划？

**长不看的结论：不会，不亏。**

绝缘套雷神对萌新并不友好，雷神虽然强力，但她在0命和1命的时候终究不是个主C。雷神的技能偏向辅助，在雷国里担任的角色是给其他三位缺充能的角色充电，也就是一个有点输出的充电宝。雷国比较重要的是另外三位四星的练度，但大部分初入坑的萌新连这三个人都不一定凑得齐，何况国家队非常吃香菱行秋的练度和命座，低命的雷国未必比超绽放雷神来的好。

绽放下限高但上限基本上锁死，但下限高意味着非常适合资源不太多的新人，可以用少量资源获取高额收益。超绽放雷神基本上只吃雷神一个人的精通和等级，不吃天赋等级，其余角色的资源不需要给太多，只要保证能奶住全队不死并且能做到持续挂元素，基本上就没有问题了。

正是因为超绽放对资源消耗需求少，基本上是不会影响到将来的资源规划。雷神在后期用处较多，早早将等级拉起来并非坏事，而且绽放流给了雷神应对很多情况和怪物的能力，天上飞的都能打，也不怕雷抗高或者雷免疫的怪。如今草元素角色和草系反应在如今的游戏机制中十分活跃，能搭配精通雷神玩绽放的队友在将来未必就用不上，拉起来的精通圣遗物也可以给其他适合草元素反应的角色玩，如久岐忍。以我个人来看，种门绝对不亏，而且非常适合萌新。

### 种门的优点？

超绽放雷神非常省心，耗费的资源相比起绝缘套的雷神也少很多，下限非常高。另外，超绽放的伤害虽然是单体，但自动追踪是一个不可多得的攻击能力，还是比较适合没什么手法的新人和老咸鱼的。

### 种门的缺点？

不太适合草抗高的敌人。而且上限基本上是锁死的，除非有草神2命。

### 种门的玩法？

雷神堆**精通**，队伍里需要至少一个水系角色和一个草系角色来生成草原核。

前期能获得的草元素角色不多，最常见的是主角，另外就是上一期池子里面有的瑶瑶，还有一个是深渊4-3通关就送的柯莱。水系角色可以选择芭芭拉，如果有行秋那就是最好的。

简短的配队推荐（后面会再提到）展开/折叠

比较推荐的配队是雷神+草主+行秋+瑶瑶，这个主要是考虑到没有纳西妲需要用**双草**来压住水元素，更具体的萌新可能看不懂，但大致就是行秋水太多了，需要多来点草元素。如果用芭芭拉，也比较推荐用双草，因为芭芭拉是个法师大概会长时间站场，挂水比较多，而且前期草主一个人挂草挂不过来，大招开不出，最好是能有两个草元素角色互补。柯莱可以代替草主，但是要通关深渊4-3获得，在那之前还是得先往须弥跑一趟了。低配队个人认为瑶瑶比较重要，放元素战技就可以做到脱手挂草，只不过对单情况下上草频率实在太低还是需要另外一个草角色补元素的。~~（谢谢我，拖延侠，3.3我还真没法写瑶瑶，拖到3.4正好把瑶瑶放进去了）~~

高配队理想的是雷神+草神+心海+行秋或夜兰，草神站场。比较推荐行秋，因为行秋有抗打断和减伤，对手残人士更友好些，不过夜兰输出高些，可以根据自己配队情况选择。当然，有这么高配的队伍，也不一定非要玩超绽放雷神啦。

## 超绽放流雷电将军培养推荐

**有一点需要大家注意，等级对种子的伤害影响非常大，所以雷神的等级是越高越好。**

### 武器推荐

超绽放雷神的武器**有且仅有**三个选择，都是四星。五星武器和三星武器中都没有元素精通副词条的武器。推荐尽早推图到须弥去做一部分森林书。
元素精通对整个队伍的伤害至关重要，所以如果雷神没有精通武器，就没法玩这个配队了。

| | |
| --- | --- |
| 匣里灭辰 | 祈愿获得的四星武器，给的元素精通是最多的，无论前期还是后期都是最优秀的选择。 |
| 贯月矢 | 锻造获得的武器，需要做一部分森林书，之后可以在梦中的桓那兰那，梦之树前面和NPC用“你与兰那罗的故事”道具交换锻造图纸。不需要全部做完森林书就可以获得，如果抽不出匣里灭辰，非常推荐先往须弥跑一趟拿这个图纸，并不费力。缺点是胚子需要两个异梦溶媒和北陆的胚子去转换，对于老咸鱼来说可能不算什么，但对于萌新来说两个异梦溶媒可能算得上是巨资。另外一个方法就是肝梦之树到24级，这个难度同样也不小…… 这个武器白值高精通低，有匣里灭辰之后就可以换掉了。 |
| 喜多院十文字 | 锻造获得的武器，这个是稻妻的。需要在八酝岛做完任务才能获得的图纸，这个系列任务非常长，还费劲，有不少跑起来令人头疼的解谜。当然，它的充能能力很强，比较适合托马云堇等需要充能的角色，就是需要高精炼。对于精通雷神来说，不太适合前期冲着它去肝稻妻，太累人了。同为锻造武器，比起贯月矢它要更费劲。当然，给雷神开清籁岛打雷音同样费劲。 贯月矢和十文字打造哪一个就看玩家个人取舍了，这两把武器的白值和精通数值是相同的。 |

## 超绽放流雷电将军配队推荐

**注意：**这里的低配和高配指的是角色的星级，和练度无关，当然练度肯定是越高越好。

### 低星配队

| | | | |
| --- | --- | --- | --- |
| 雷电将军 | 行秋 | 旅行者/草 | 瑶瑶 |

轮流站场即可，哪里亮了点哪里。
行秋的水太多了，一定要双草保证草原核的生成效率。行秋可以换夜兰，但是因为失去行秋的减伤和抗打断对手部乘区要求高一些。草主和瑶瑶保证挂草频率，同时瑶瑶提供了生存能力和战技启动的后台挂草能力。**瑶瑶在低配队伍里是非常重要的角色。**
草主可以换柯莱，但比起草主，柯莱范围小一些。
行秋前期可能会开不出大招，不过飞天御剑再搭配上学士2+流放者2以及一个充能沙，不管怎么说都能在很大程度上缓解充能压力，如果有幸能抽到祭礼剑或者西风剑就更好了。总之就是疯狂叠充能，也就还好。
草主的萌新开荒培养推荐可以去草主页面看看。

| | | | |
| --- | --- | --- | --- |
| 雷电将军 | 芭芭拉 | 旅行者/草 | 瑶瑶 |

**芭芭拉站场，一定要保证充足量的水元素。**
这个配队中**只能芭芭拉站场**，不然会造成水元素不够，但是同时因为芭芭拉站场，加上水环也可以给怪物施加水，单草元素角色同样会造成草原核生成效率低下。所以如果没有行秋或夜兰，用芭芭拉来施加水元素的话，一定一定要用双草，不然草原核会少很多。
同样的，草主可以换柯莱。

### 高星配队

| | | | |
| --- | --- | --- | --- |
| 雷电将军 | 纳西妲 | 珊瑚宫心海 | 行秋 |

**纳西妲站场，不然可能会造成草元素不够的情况。**
行秋可以换夜兰，但不太推荐，因为纳西妲身板脆，行秋的减伤和抗打断比较适合需要长时间站场的纳西妲，可以有效保护她，也可以减轻手部乘区的压力。
推荐纳西妲使用 深林的记忆 四件套，她的战技覆盖率高一些，很适合这个套装。如果心海的治疗量足够，可以考虑给心海用 教官 套，但覆盖率可能没那么高，不过120精通的提升总归是挺不少的。

其他高星配队，各位可以试一试，这些是我试了好多个小时测试出来的草原核相对充足的配队。
很多其他配队虽然看上去理论很美好，但是实际上草原核生成效率极度低下，输出也不尽人意。如果各位旅行者有测试出来草原核效率很高的队伍也可以评论区回复。
另外，我有艾尔海森的号没雷神，有雷神的号没艾尔海森，暂时没法测艾尔海森和雷神的搭配如何。但是个人认为海哥更适合搭个久岐忍，如果搭雷神可能生存能力不足。
