描述

描述

暗中支援的黯色 角色突破等级4解锁

描述
施放终命的圣礼时，基于自身暴击率可被二次转化的部分的15%，提高附近的队伍中所有角色（不包括罗莎莉亚自己）的暴击率不可被二次转化，持续10秒。通过这种方式获得的暴击率提升，无法超过15%。

夜行

描述
在夜间（18时至6时），队伍中自己的角色获得迅行效果：移动速度提高10%。
该效果在秘境、征讨领域、深境螺旋中无效，迅行效果无法叠加。

## 角色定位

罗莎莉亚的定位是冰元素辅助兼后台输出角色，其核心技能是元素爆发「终命的圣礼」的后台范围挂冰以及天赋「暗中支援的黯色」为队友提供的暴击率加成。罗莎莉亚的核心命座是二命和六命，二命可以延长元素爆发后台挂冰的时间，六命可以降低元素爆发命中敌人的物理抗性，使满命罗莎莉亚成为一些物理队中的优秀辅助。罗莎莉亚的后台挂冰可以用来辅助保持双冰共鸣效果以及冻结（如 神里绫华 永冻队）或超导（如 优菈 物理队）效果，也有少数情况在融化队（如 阿蕾奇诺 队）就业承担后台挂冰职能。
罗莎莉亚的厨力向配装以罗莎莉亚主打融化输出为主，可参考第二栏融化输出配装。

| 赤沙之杖 | 赤沙之杖是融化流罗莎莉亚的五星毕业武器，副属性提供高额暴击率的同时武器特效还自带精通转攻击，在队里有精通拐的情况下提供的攻击力十分可观。 |
| 断浪长鳍 「渔获」 | 「渔获」提供元素爆发暴击率与增伤，在「罗香万班」的融化队中，是配平充能后融化期望最接近赤沙之杖的武器。断浪长鳍同理，武器特效提供元素爆发增伤，有高精的情况下输出能力很强，风系辅助选择装备讨龙英杰谭的砂糖会比零命枫原万叶的提升更大，圣遗物可以选择 饰金之梦 四件套，如使用绝缘之旗印、未竟的遐思等四件套且装备增伤武器时，则可以考虑元素精通主属性的「空之杯」。 |
| 峡湾长歌 | 峡湾长歌作为纪行武器，副属性提供暴击率，在提高辅助能力的同时保证自身输出，且在三色队伍中满精提供240的精通，期望较高。 |
| 薙草之稻光 | 薙草之稻光提供高额充能的同时还能提供一些攻击力加成，适合搭配 绝缘之旗印 4件套使用，武器特效可将元素充能效率转化为攻击力。由于罗莎莉亚的充能压力一般不大，薙草之稻光的充能转攻击给罗莎莉亚带来的收益也不如自身面板充能更高的雷电将军、香菱等角色。对于融化流罗莎莉亚只能视作渔获、断浪长鳍的下位替代。 |
| 护摩之杖 决斗之枪 赤月之形 柔灯挽歌 | 护摩之杖副属性提供较高暴击伤害，武器特效根据生命值提供一定攻击力，适合大部分长柄武器输出角色。 决斗之枪提供高额暴击率的同时，武器特效还提供一些攻击力，较为通用。 赤月之形副属性提供暴击率，武器特效的增伤重击启动，在避免被治疗的情况下期望尚可。 柔灯挽歌副属性提供暴击率，武器特效常驻攻击力加成，但除此之外的武器特效无法被罗莎莉亚触发，仅为面板武器。 |
| 匣里灭辰 | 匣里灭辰副属性提供高额元素精通，武器特效为对火元素附着怪物造成的伤害提高，均为融化反应有收益的属性。 |
| 和璞鸢 息灾 | 和璞鸢提供的暴击率可以缓解罗莎莉亚的圣遗物面板伤害，但武器特效要求叠层，不太适合元素爆发有快照机制的罗莎莉亚，伤害上限比起其他输出型五星武器以及四星武器略逊一筹。 息灾提供高额攻击力，由于罗莎莉亚的元素爆发快照（锁面板）机制，因此并不太契合武器特效的后台持续叠层的特点。以快照前台1层特效计算，息灾的融化期望可持平2层特效的和璞鸢。 |
| 风信之锋 贯虹之槊 黑岩刺枪 | 风信之锋是3.1版本活动限定四星武器，提供元素精通和攻击力，均为融化反应有收益的属性。 贯虹之槊提供高额攻击力，特效需要叠层并且需要有护盾角色以保证特效的触发，不算太适配罗莎莉亚融化队，输出能力与风信之锋在同一水平。 黑岩刺枪是商城中可以用星辉兑换的武器，副属性提供暴击伤害，武器特效叠满收益很高，但对单攻坚时武器特效基本等于白板。 |
