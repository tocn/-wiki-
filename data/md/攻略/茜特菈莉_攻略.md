描述
**普通攻击**
唤起烟谜主世代传承的秘仪，进行至多三段的攻击，造成冰元素伤害。

**重击**
进入瞄准状态，并在长按结束时消耗一定体力，向瞄准的方向挥出一枚寒星，对路径上的敌人造成冰元素伤害。

**下落攻击**
凝聚冰元素的力量，从空中下坠冲击地面，攻击下落路径上的敌人，并在落地时造成冰元素范围伤害。

霜昼黑星

描述
依凭烟谜主千年传承的密契，展开白曜护盾，并召唤（传闻中）无比可怖的「黑曜星魔」伊兹帕帕，造成具有夜魂性质的冰元素范围伤害。
白曜护盾的伤害吸收量受益于茜特菈莉的元素精通，对冰元素伤害有250%的吸收效果，并在展开护盾时，为茜特菈莉施加短暂的冰元素附着。
施放后，茜特菈莉将获得24点夜魂值，并进入夜魂加持状态。

**夜魂加持·茜特菈莉**
伊兹帕帕退场时，茜特菈莉的夜魂加持将会结束。

**伊兹帕帕**

- 伊兹帕帕将跟随角色行动；
- 若茜特菈莉拥有至少50点夜魂值，伊兹帕帕将进入白燧状态，持续消耗夜魂值，并卷起跟随角色的霜陨风暴，攻击范围内的敌人，造成具有夜魂性质的冰元素伤害；
- 夜魂值耗尽时，伊兹帕帕的白燧状态也会结束。

不过，茜特菈莉对于颜色本身没有什么特殊的偏好，事情便也就这样成了。*

夜域赐礼·镜烟翾风

描述
在纳塔存在燃素机制的区域时，能够进行夜魂传递·茜特菈莉。当前场上角色位于一定高度的空中时，切换茜特菈莉登场时触发：茜特菈莉将高高腾跃而起，并借助「白曜星魔·茜特菈琳」在空中飘行。自己的队伍每10秒可以触发一次夜魂传递。
长按瞄准时，茜特菈莉会进入「灵觉」状态，处于这种状态下时，茜特菈莉可以与「灵谜涂鸦」和「灵谜纹」交互，提取其中的信息与力量，这些物件的交互规则沿袭暝视龙的交互规则。
此外，长按跳跃时，茜特菈莉将消耗75点体力腾跃而起；在纳塔存在燃素机制的区域时，茜特菈莉将优先消耗5点燃素，腾跃至更高的高度。
位于空中时，茜特菈莉可以长按普通攻击，消耗燃素或体力进行瞄准与重击；在空中进行重击时，茜特菈莉将优先消耗20点燃素。

奥秘传唱

描述
在纳塔存在燃素机制的区域时，触发「夜魂迸发」能恢复20点燃素。
该效果在秘境、征讨领域、深境螺旋中无效。

## 角色定位

茜特菈莉定位是后台挂冰、护盾以及火、水减抗辅助角色，作为可以进入夜魂加持状态的角色可以搭配 烬城勇者绘卷 四件套（简称“勇者套”）增伤，与钟离一样提供元素战技启动、持续时间长于冷却时间（20秒/16秒）的护盾。
茜特菈莉的元素战技配合元素爆发能提供较长时间持续后台挂冰能力（伊兹帕帕白燧频率为半径6米2秒1次），且茜特菈莉的优势在于施放元素战技接元素爆发可在短时间内快速挂1单位冰（黑曜星魔）+2单位冰（冰风暴）+1单位冰（宿灵之髑）稳定将怪物冰元素附着。此外，茜特菈莉的挂冰也为天赋一「五重天的寒雨」的减抗提供触发条件（即夜魂加持状态下附近角色触发冻结/融化），相比于翠绿之影四件套，对于水、火元素输出角色而言优势在于茜特菈莉在后台就可长时间触发。
尽管茜特菈莉并**不能**提供冰元素减抗，但凭借护盾辅助能力以及「烬城勇者绘卷」四件套触发冰元素相关反应后提供冰元素伤害加成及对应元素增伤的能力，乃至第一命座提供的基础伤害加成，茜特菈莉也可以在冰元素直伤队（主要是搭配水元素角色的直伤队，可同时提供水元素伤害加成与水元素减抗）中就业，其后台挂冰能力有助于维持双冰共鸣的增益。
茜特菈莉的关键命座为二命、六命。

- 第一命座可为场上角色提供10-16段的倍率加成，以1000精通为例，每轮（16秒）能够提供总计最多32000的基础伤害区提升，并提升大世界能力。
- 第二命座为前台角色提供250的高额精通，为自己提供125精通，将天赋一的减抗加成提升至40%，且可以为联机状态的队友的提供护盾。解锁该命座后茜特菈莉可作为精通辅助角色就业，如*月绽放 月绽放*队。
- 第三命座提升元素战技等级，进一步提升元素战技的盾量。
- 第四命座提供最快8秒一次的弱冰伤害与夜魂值回复，提升很小。
- 第五命座提升元素爆发等级，提高元素爆发造成的伤害。
- 第六命座根据夜魂消耗提升高额火、水元素伤害加成，最多提升60%；在部分配队中茜特菈莉的后台挂冰可以直接元素战技启动。

| 可用圣遗物增益 | 烬城勇者绘卷 ：一层12%，一层28%，共40%（通常为冰、火/水增伤） 千岩牢固 ：20%攻击力，30%护盾强效 教官 ：全队8秒120点精通加成，同时提升自身盾量与一命增益 | 千岩牢固 ：20%攻击力，30%护盾强效 悠古的磐岩 ：拾取结晶晶片35%火/水/雷/冰元素增伤 |

| 治疗能力 | 仅当装备试作金珀时 | 六命：护盾受到攻击时回复场上角色生命值 |

综上所述，相比于护盾辅助能力，茜特菈莉的价值更多在于后台挂冰及相应增伤减抗能力上，在除恰斯卡以外的非增幅的火水队中与钟离各有千秋，在非火水队中则通常价值不如钟离（天赋鼓励冰系角色进队的个别角色除外）。在投入命座后钟离几乎没有后续提升，而茜特菈莉在拥有一命、二命、六命后则可分别在基础伤害区、反应与抗性区、增伤区实现辅助能力的飞跃。

#### 圣遗物

- 通用辅助

| 词条推荐理由 | |
| 茜特菈莉的基础盾量只基于元素精通，元素精通能够提升茜特菈莉护盾量以及第一命座的增伤数值。当茜特菈莉装备西风秘典时需要堆高暴击率触发其武器特效；当茜特菈莉装备尘光七谕时需要堆高攻击力（2600点攻击力即可达到上限）以提升其武器特效的增伤能力。非满命茜特菈莉的持续挂冰能力依赖元素爆发（在不施放元素爆发的情况下，首轮茜特菈莉从施放元素战技到积攒足够夜魂值进入白燧状态开始挂冰需要约11.4秒），在部分配队中（以火C融化队为代表）有较高元素充能效率需求，茜特菈莉单冰且队内存在一把西风系列武器时，装备勇者套需要180%元素充能效率，若队内无西风系列武器则元素充能效率需求提高15%左右；双冰时元素充能效率需求可下降；装备非勇者套时元素充能效率需求大幅上升至240%甚至更高。若队伍不需要茜特菈莉的挂冰（如 玛拉妮 队、冰/水元素直伤队等），则茜特菈莉不需要元素充能效率。 | |

| 4件套 千岩牢固 | 千岩牢固四件套（简称“千岩套”）在有队友带勇者套的情况下，攻击倍率体系可选。茜特菈莉的元素战技可持续造成伤害，持续触发四件套效果，其护盾强效加成可最大化茜特菈莉的盾量，攻击力加成对于攻击倍率体系也有提升。由于不提供回能，茜特菈莉的充能需求很高。 |
| 4件套 饰金之梦 | 过渡圣遗物，提供盾量，提升有限，茜特菈莉有一命的情况下还能提升一命的基础伤害区加成，但对护盾量的提升不如千岩套，对于攻击倍率主C而言计入一命基础伤害加成的提升后基础伤害加成通常依旧不如千岩套。 千岩和饰金的选择计算过程 以900基础攻击力的攻击倍率主C为例，忽略队内攻击力倍率副C伤害，假设16秒内打出的倍率为x，900x\*0.2=230\*2\*16，解得x≈41，即16秒轴内，主C倍率高于4100%则千岩牢固四件套更优。若考虑队内攻击力倍率副C伤害，则千岩牢固四件套优势更大。 |
