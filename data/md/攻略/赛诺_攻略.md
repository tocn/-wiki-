## 角色定位

赛诺是一名雷元素驻场输出型角色，通过元素爆发「圣仪·煟煌随狼行」进入「启途誓使」状态，进行普通攻击造成无法被附魔覆盖的雷元素伤害，并配合元素战技「秘仪·律渊渡魂」展开长轴驻场输出，并具有固有天赋「落羽的裁择」的QTE（Quick Time Event，快速反应事件，在此指「末途真眼」状态）输出机制，同时联动固有天赋「九弓的执命」具有额外元素精通倍率，具有多种雷元素附着能力，因此可应用于超激化、激绽等多种体系，同时由于自身具有长轴驻场、锁定驻场的特性，因此也可搭配 夏沃蕾 而组建超载体系。
当同时搭配低频水元素（如 芙宁娜 或二命以下 夜兰 单草双雷）与草元素角色时赛诺可参考【激绽输出】配装（此时赛诺草伤占比小于雷伤），当只打超激化时参考【激化输出】配装，当搭配高频水元素（如 夜兰 双草单雷或 行秋 ）与草元素角色时赛诺可参考【超绽输出】配装（此时赛诺草伤占比高于雷伤），在水雷直伤感电体系或搭配夏沃蕾时赛诺可参考【直伤输出】配装。

| 时之沙元素精通、元素充能效率（单雷） 空之杯雷元素伤害加成 理之冠暴击率、暴击伤害 | 暴击率、暴击伤害≥元素充能效率、元素精通＞攻击力百分比＞数值攻击力 |
| 词条推荐理由 | |
| 赛诺的输出十分依赖高达80能量的元素爆发，因此副词条中有一些元素充能效率对于改善循环非常有帮助。通常 菲谢尔 久岐忍 双雷队的赛诺不需刻意堆叠充能即可实现无缝循环，若雷元素队友产球能力较弱则依旧需要堆叠110%~160%元素充能效率，单雷队则需要165%左右的元素充能效率（极端不产球环境则需要200%元素充能效率），若赛诺使用如雷套可降低20%~40%的充能效率需求，若赛诺装备喜多院十文字则不需要额外充能。建议安排其他队友使用西风系列武器以优化队伍循环。 赛诺充能需求计算 以饰金之梦四件套、装备非充能武器的赛诺在队友无西风、纯打桩的少产球环境中计算，假设一轮在怪物掉球上只获得3颗异色微粒（怪物产球数据参考元素能量学/敌人数据），行秋装备祭礼剑触发双E，等效0命夜兰装备西风猎弓触发西风（或近似略高于1命及以上夜兰双E）。参考元素能量学/原理，普通攻击的固定回能触发期望不到7次，因此可假设一轮触发4点固定回能，总产球回能需求为76点。角色元素战技产球数据参考元素能量学/角色数据。 - 前台同色：赛诺起手E×3+Q期间5次强化E×4/3，共29点。若双雷久岐忍，则久岐忍10E×0.45+双雷共鸣×4，共25.5点。 - 前台异色：纳西妲灭净三业（判定冷却7秒，触发2次）×3，怪物产异色微粒×3，共9点。芙宁娜（无西风）E×8，共17点。 - 后台异色：行秋双E或夜兰E触发西风×10，钟离E（假设岩脊立刻破碎无后续产球，无西风）×0.5，纳西妲灭净三业×3，白术（无西风）E×3.5。 综上所述，对于赛草行/夜久双雷队获得能量71.3点，元素充能效率需求为106.6%；赛草芙久双雷队获得能量73.3点，元素充能效率需求103.7%；赛草行/夜钟单雷队获得能量46.1点，元素充能效率需求164.9%；赛白芙草单雷队获得能量49.9点，元素充能效率需求152.3%。 元素精通既能提高赛诺的技能直伤，也能提高其超绽放、超激化反应伤害，在超激绽队伍中的收益通常高于攻击力，因此在满足循环的前提下，超激绽队伍中的赛诺优先选择元素精通主词条的「时之沙」。特定情形下精通收益可接近暴击率、暴击伤害，如多水激绽队中队伍的激化频率显著低于挂水频率，赛诺超激化反应伤害占比较低而超绽放反应伤害占比较高，此时「理之冠」部位也可以考虑选用“元素精通”主词条（优先选用副词条更好的即可），但需注意双雷配队中一部分草原核会由后台雷触发超绽放。在少水激绽队即有较高超激化占比的超激绽队伍中，也可参考纯激化队伍，在装备高基础攻击力武器时若有攻击力百分比主词条的时之沙副词条比元素精通主词条的时之沙好很多则也可选用。 | |

## 阵容搭配

- 激绽激化
- 超载直伤

赛诺作为长轴输出角色，元素能量需求高达80点，自身天赋、命座没有为自身回能的能力，而赛诺的关键产球来源为元素爆发状态下的元素战技，切人会结束元素爆发状态，因此如果提前切人结束元素爆发状态会导致充能压力陡增，故可认为**赛诺常规配队中双雷体系的优先级远高于单雷体系**，雷元素角色不仅可以通过元素战技产出雷元素微粒帮助赛诺充能，好磕通过双雷共鸣帮助赛诺充能。赛诺的元素爆发最大持续时间长达18秒（且受卡肉机制延长），而翠绿之影的减抗仅持续10秒，枫原万叶配合元素爆发的总增伤时间仅持续16秒，班尼特元素爆发的加攻时间为12~14秒，更无法覆盖赛诺的输出轴，因此传统上刻晴、雷电将军、克洛琳德等中短轴雷元素输出角色的配队中风系角色入队的情况对于赛诺并不适用，仅有以下增益可供优先考虑：

- 希诺宁 元素战技「音火锻淬」配合天赋「四境四象回声」提供15秒较长时间的减抗与元素爆发「豹烈律动！」充分的单体治疗能力
- 烬城勇者绘卷 装备者可通过触发雷元素相关反应为全队提供20秒的雷元素伤害加成
- 纳西妲 元素爆发「心景幻成」在单水时零命即可提供21秒的摩耶之殿领域覆盖，可基本全覆盖赛诺的输出轴
- 芙宁娜 元素爆发「万众狂欢」提供18秒的增伤，可覆盖赛诺大部分的输出轴

在草元素构建上：

- 纳西妲 元素战技「所闻遍计」对敌人施加的蕴种印在理想情况下（单波次敌人）可以提供25秒的超长时间对群挂草，可完全覆盖赛诺的输出轴，但无法应对多波次敌人（即存在转火问题）；第二命座「正等善见之根」可提供激化减防与超绽放伤害可暴击的增益。
- 白术 元素爆发「愈气全形论」可提供14秒对单挂草以及无郤气护盾的抗打断，解锁二命后提供后台全自动对单挂草，但挂草量较低；元素爆发配合元素战技「太素诊要」可分别提供充分的单体与群体治疗，天赋「在地为化」可为站场受到无郤气护盾治疗的赛诺提升触发的超激化、超绽放反应伤害。

以上两名角色可视为赛诺队伍草元素角色的首选。

其他草元素角色选择

- 旅行者/草 （简称“草主”）的元素爆发「偃草若化」可提供12秒的后台挂草，但仅为领域挂草存在画地为牢的问题，且元素爆发能量需求极高。草主天赋「蔓生的埜草」可为赛诺提供元素精通加成、六命「蕴思的霜草」可为赛诺提供雷元素伤害加成，圣遗物通常选择 昔日宗室之仪 四件套为全队加攻或 深林的记忆 四件套（简称“草套”）减草抗以提升队内草元素角色的直伤与激化伤害以及角色触发的超绽放反应伤害，装备草套时需注意覆盖率问题。
- 柯莱 元素爆发「猫猫秘宝」配合天赋「徐如旷林」提供至多9秒后台挂草，作为领域挂草范围较小且存在画地为牢的问题，元素战技「拂花偈叶」配合天赋「飞叶迴斜」与第二命座提供仅6秒的随身挂草，**单草无法满足激绽队赛诺的挂草需求，需要绑定纳西妲等双草**。
- 瑶瑶 的元素战技「云台团团降芦菔」与元素爆发「玉颗珊珊月中落」均可提供治疗，元素战技月桂·抛掷型投掷的白玉萝卜可提供10秒的后台挂草，但挂草不稳定，受角色生命值与离怪物目标距离影响，**单草无法满足激绽队赛诺的挂草需求，需要绑定纳西妲等双草**。此外，瑶瑶自身缺乏辅助能力。
- 绮良良 的元素战技「呜喵町飞足」生成的安全运输护盾可提供生存与抗打断能力，配合第四命座可提供12秒左右的后台挂草，第六命座为全队提供全元素伤害加成，**单草无法满足激绽队赛诺的挂草需求，需要绑定纳西妲等双草**。

激绽队在激化队伍的基础上引入水元素，产生的草原核由高精通的赛诺稳定触发超绽放反应，不仅利用了赛诺的精通转模（与刻晴等其他角色相区别），还充分利用了过量的草元素（超激化反应实际上并不持续消耗草元素），伤害下限与上限均高于纯超激化队。

水元素队友选择

- 芙宁娜 为后台输出兼增伤辅助角色，荒性形态元素战技「孤心沙龙」召唤的沙龙成员可提供长达30秒的挂水与后台输出，元素爆发「万众狂欢」可根据全队生命值变动为全队提供18秒的长时间增伤，队伍构建上偏向于雷伤＞草伤，非满命芙宁娜需要队内绑定一名治疗角色，对于二命以下芙宁娜而言 白术 等能提供高额群体治疗的角色较为推荐。
- 行秋 为后台输出兼生存辅助角色，元素战技「古华剑·画雨笼山」与元素爆发「古华剑·裁雨留虹」生成的雨帘剑可提供至多15秒的减伤与抗打断，元素爆发生成的虹剑势在解锁二命后可提供长达18秒的水元素协同攻击，20秒的长冷却时间契合赛诺队的长循环轴。行秋的水元素附着能力较强，队伍构建上偏向于草伤＞雷伤。
- 夜兰 为为后台输出兼增伤辅助角色，元素爆发「渊图玲珑骰」提供15秒的水元素协同攻击，配合天赋「妙转随心」提供15秒内从0%到50%逐渐提升的增伤。夜兰的水元素协同攻击时间较短，二命以下时附着频率低于行秋，而增伤能力逊于芙宁娜，导致激绽队伍中地位较为尴尬，偏重雷伤时表现不如芙宁娜，而偏重草伤时表现不如行秋，零命以下时自身水元素直伤能力则与芙宁娜、6命行秋基本处于同一水平，缺乏突出优势。

由 赛诺 与 夏沃蕾 为核心的队伍，通常搭配其他雷元素与火元素输出或生存角色组成的雷火直伤队伍，通过限制配队、触发超载反应最大化利用夏沃蕾的天赋以提高队内火、雷元素角色伤害。夏沃蕾的天赋「尖兵协同战法」可在队内绑定火、雷角色的情况下任意超载反应发生后的6秒内降低敌人火元素与雷元素抗性，天赋「纵阵武力统筹」在夏沃蕾发射近迫式急促拦射的「超量装药弹头」为全队火、雷角色提供至多40%攻击力加成，持续30秒，解锁满命后还可使队伍中的角色受到近迫式急促拦射的治疗后获得20%火元素伤害加成与雷元素伤害加成，满层60%增伤可持续16秒，总增伤可持续20秒，大大提升了赛诺面对多波次敌人的转火能力，此时可完全视为枫原万叶的上位替代。受赛诺元素爆发充能需求的限制，赛诺超载队基本**绑定双雷体系**。雷元素队友通常选择 菲谢尔 、 北斗 、 伊安珊 或 欧洛伦 。最后一人通常选择有后台火附着能力的队友，因为夏沃蕾的天赋「尖兵协同战法」提供的减抗效果仅有6秒，需要不断触发超载反应刷新该天赋效果以覆盖赛诺的长输出轴。火元素队友通常选择 玛薇卡 杜林 香菱 托马 迪希雅 ，其中香菱入队则自身充能压力较大，基本只能选择西风长枪，且由于缺少班尼特，香菱自身直伤输出能力薄弱。虽然 班尼特 无法覆盖赛诺的输出轴且画地为牢且超载减抗覆盖不完全，但在打桩时覆盖赛诺轴的部分仍然能带来显著的提升。在该队伍中， 玛薇卡 可视作最佳第四人火后台位，且队伍整体伤害表现高于带班尼特的队伍。玛薇卡不仅可以长时间触发两层烬城勇者绘卷四件套的40%火、雷元素增伤，还能通过施放元素爆发联动天赋「基扬戈兹」为场上角色提供长达20秒的逐渐衰减的增伤（解锁四命后不再衰减并额外获得10%伤害加成），第二命座还可以使焚曜之环附近的敌人的防御力降低20%，上限很高，不过该队伍中零命玛薇卡在不绑定其他纳塔夜魂角色时存在战意值不足的问题。此外亦可考虑同样拥有后台挂火与减抗的 杜林 入场，在队内至少有两名魔导角色时「白焰之龙」提供35%的稳定减抗，且命座对赛诺自身伤害的辅助能力更优。
