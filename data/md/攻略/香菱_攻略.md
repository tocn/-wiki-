## 角色定位

香菱是一位火属性后台输出角色，其核心优势是高频火元素附着能力，核心技能是元素爆发「旋火轮」，拥有快照（锁面板）机制，可脱手随身（在切换角色之后依然存在并随站场角色移动而移动）独立施加火元素附着，且攻击范围较大，缺点是元素能量需求高达80点。香菱的元素战技召唤的锅巴同样可脱手可快照，但范围较小且无法主动移动，产球不稳定。
由于以上特点，香菱的配装可分为以下三类：

- 后台蒸发：搭配高频水元素角色（如 行秋 夜兰 达达利亚 等）使自身打出高频蒸发获得优秀的输出能力。
- 后台直伤：
- 搭配冰元素输出角色或低频水元素输出角色（如 玛拉妮 ）挂火使队友打出融化、蒸发伤害。其中，在玛拉妮蒸发队等队伍中香菱通常仅作为单火，此时武器通常只能选择高精炼 西风长枪 并使用辅助套装，以下不再详述。
- 搭配 基尼奇 艾梅莉埃 持续触发燃烧。
- 搭配 夏沃蕾 与部分低频雷元素输出角色（如 雷电将军 或 刻晴 单雷）挂火持续维持超载。
- 其他火、风、岩直伤体系。
- 剧变反应：
- 搭配 夏沃蕾 与部分高频雷元素输出角色（如 克洛琳德 / 刻晴 ＋ 菲谢尔 双雷）挂火持续触发超载。
- 搭配草元素角色持续触发烈绽放。

| 词条推荐理由 | |
| 香菱为攻击力倍率输出角色，双暴与攻击力为攻击力倍率输出角色的基础词条，元素精通可提升蒸发反应伤害，元素充能效率则保证香菱的元素爆发循环。时之沙部位以及副词条的取舍需要根据不同队伍选择： - 在 雷电将军 的雷神国家队中，香菱承担后台蒸发的职能，在班尼特加攻被快照的情况下元素精通的收益高于攻击力百分比。由于雷电将军帮助队友充能的能力，香菱的充能需求相对较低，一般装备充能武器再加上副词条的充能就足够，因此可以使用主词条为「元素精通」的时之沙，强化蒸发反应的增幅效果；如果装备的是非充能武器则仍建议装备「元素充能效率」主词条的时之沙。副词条元素精通收益高于攻击力百分比。 - 在 达达利亚 的“万达国际”、 神里绫人 蒸发队等队伍中，香菱承担后台蒸发的职能，但为了循环流畅通常需要装备充能武器的同时装备元素充能效率主词条的时之沙。副词条元素精通收益高于攻击力百分比。 对于 赤沙之杖 、 断浪长鳍 等非充能武器而言，要么元素精通有额外收益，要么武器特效提供了足够多的增伤，此时如果副词条无法提供足够的充能而选择充能沙时，则精通杯有时会优于火伤杯。 | |
