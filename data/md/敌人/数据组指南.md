## 前言

数据组负责的范围巨大（对没错可以用巨大来说），基本Wiki的核心就可以说是数据了；简单来说就是游戏内的所有静态数据都由数据组负责，比如角色的各种属性，怪物属性，图片收集，语音录入等等。

本篇将会较为详细的介绍数据组的任务和编辑方式，Wiki页面多通过“模板”进行编写，大多时候只需要掌握模板的使用方式即可

## 模板介绍

### 为什么要使用模板

- 在游戏类WIKI中会有大量的图鉴页面，这些页面因为内容结构基本一致，会有一个框架性的重复部分，通常我们会把图鉴连带其样式做成一个名字叫图鉴的模板。并将这个内容放置在“模板:图鉴”的页面。
- 模板可以复用，调用也比较简单，只需要写`{{模板名|参数=}}（部分模板参数可省略）`即可调用模板内容到当前页面。
- 当代码改变时，仅需修改模板，调用模板的页面会自动更新。
- 模板可以隐藏大量重复使用的代码，提高代码可读性。
- 模板可以接受参数，提供一定范围内的自定义效果。

**eg:**

**填写的：**

---

```
{{野生生物图鉴
|名称= 填写的内容1
|类型= 填写的内容2
|种类= 填写的内容3
|实装版本= 填写的内容4
|出现地点= 填写的内容5
|能否捕捉= 填写的内容6
|描述= 填写的内容7
}}
```

**展示的：**

---

## 生物志页面

生物志页面说明

**例子：生物志：赤团雀**

按照模板填写即可，注意！！创建页面时请在生物名称加上生物志：比如：生物志：赤团雀（因为有部分生物与其他物品重名，加个前缀做为区分）

图片上传规整：

生物志内截图的命名规则为：生物名称详图.png如赤团雀详图（格式为png）

生物头像命名规则为：生物名称图标.png如赤团雀图标（格式为png）

```
{{野生生物图鉴
|名称=
|类型=选填：禽鸟、走兽、游鱼、其他
|种类=选填：鹰、格子、团雀、鸭、飞鸟、狸、松鼠、猪、犬、猫、鼬、鱼、晶蝶、鳅鳅、蛙、蟹、蜥、陆鳗鳗（如果版本新加物种请添加）
|实装版本=
|出现地点=
|对应鱼饵=（选填，鱼类专用）
|描述=
}}
```

- 模板:野生生物图鉴

## 任务页面

任务页面说明

**根据规律填写，可以往下拓展（章节、段落均最多到20个，应该也够了不够群里私聊管理）**

**例子风、勇气和翅膀2**

ps：换行只是为了方便展示共同部分，填写不必换行

章节简述、开启需求不填写的话会隐藏，奖励则不会（也就是必填项）

请在“剧情”模板的“内容X.X”下使用“剧情对话”模板进行编写

```
{{剧情
|章节名称1=填写章节名称1
|章节简述1=我是章节1简述
|开启需求1=我是章节1开启需求
|章节奖励1=写法：奖励1*奖励1数量、奖励2*奖励2数量 eg（原石*100、摩拉*1000000）

|段落名称1.1=填写段落名称1.1
|内容1.1=我是内容1.1

|段落名称1.2=填写段落名称.2
|内容1.2=我是内容1.2

|章节名称2=填写章节名称2

|段落名称2.1=填写段落名称2.1
|奖励2.1=原石*100、摩拉*1000000
|内容2.1=我是内容2.1
}}
```

- 模板:剧情（还差部分细节才才完成，但不影响编写）
- 模板:剧情选项
- 模板:传说任务（旧模板无特殊情况请勿再使用）
- 模板:左侧目录（旧模板无特殊情况请勿再使用）

### 模板代码实例

面包屑：公用模板请看商贩公用介绍

语音tab样式：样式模板直接抄上去即可，无所需编辑内容

角色语音表头：填写对应的cv即可（包含在了语音页面代码示例）

角色/语音、角色/语音1：这两个分别为旧、新模板，如无特殊情况请使用新版“角色/语音1”

```
一般只需要填写即可（在语音文件命名符合规范的前提下）
语音文件规范：
命名规范：语种_角色名称_游戏内语音类型名称（！！！中文语种请填空）
录制规范：文件格式为ogg或者mp3，四国语音加起来整体大小不超过20兆并且保持语音质量清晰明了无杂音

语音命名规范：
可莉_冲刺开始·其二.mp3
日_可莉_冲刺开始·其二.mp3
英_可莉_冲刺开始·其二.mp3
韩_可莉_冲刺开始·其二.mp3

一般情况：
{{角色/语音1
|语音类型=
|语音文件=
|语音内容=
}}

下述为全部模板内容：
{{角色/语音1
|语音类型=游戏内语音类型文本（如需要游戏内为收入音效，请根据音效种类命名。eg：爬山·其一）
|语音文件=模板-文件名（模板：player/player1）（必填）（文件上传命名方式：角色名_语音类型。ps：中文配音不需要语言选项）
|语音文件日语=模板-文件名（模板：player/player1）（选填）（文件上传命名方式：日_角色名_语音类型。ps：照此命名方式可以不填，可以自适应）
|语音文件英语=模板-文件名（模板：player/player1）（选填）（文件上传命名方式：英_角色名_语音类型。ps：照此命名方式可以不填，可以自适应）
|语音文件韩语=模板-文件名（模板：player/player1）（选填）（文件上传命名方式：韩_角色名_语音类型。ps：照此命名方式可以不填，可以自适应）
|语音内容=游戏内语音文本内容
}}
```

- 模板:语音tab样式
- 模板:角色语音表头
- 模板:角色/语音1
- 模板:角色/语音
