## 渊月祝福

### 1.5版本

| | |
| --- | --- |
| 剑舞之月（2021年5月上） | 角色的普通攻击在2秒内连续命中敌人时，该角色造成的物理伤害提升5%，持续10秒，至多叠加5层；这些攻击类型同时命中多个敌人时，只能叠加一层。处于5层效果下的角色的攻击命中敌人时，会释放冲击波，造成范围伤害，每1秒至多释放一次冲击波。 |
| 荆棘之月（2021年5月下） | 敌人的攻击命中处于护盾庇护下的角色时，会进行反噬：释放冲击波，造成范围伤害。该效果每6秒只能触发一次。 |
| 叛逆之月（2021年6月上） | 角色的物理属性的普通攻击、重击或下落攻击命中敌人时，该角色的暴击率提升3%，持续10秒，至多叠加5层；这些攻击类型同时命中多个敌人时，只能叠加一层。处于5层效果下的角色的攻击造成暴击时，会释放冲击波，造成范围伤害，每1秒至多释放一次冲击波。 |

| 天行之月（2021年4月下） | 下落攻击命中敌人后的10秒内，敌人的防御力降低40%。 |
| 风行之月（2021年04月上） | 角色拥有提升攻击力的风行光环，至多使角色的攻击力提升60%。光环中的敌人数量每增加1个，该光环的效果就降低25%。当角色身边的敌人数量大于或等于4个时，该效果不再提供攻击力提升效果。 |
| 明威之月（2021年03月下） | 当前场上角色的生命值低于50%时，普通攻击与重击命中敌人后的10秒内，造成的伤害提高2%。该效果至多叠加10次，该效果对队伍中不同角色有独立的持续时间与叠加次数。该效果叠加或持续时间刷新时，有50%的概率释放能量冲击。每10秒至多触发一次能量冲击。 |
| 吐故之月（2021年03月上） | 每10秒，会进行一次能量充能，同时至多持有3层能量充能。若当前场上的角色生命值低于50%，在普通攻击命中敌人时，会消耗充能，并在敌人所在位置留下一个不稳定的能量团，1秒后爆炸。每2秒至多产生一次能量团。 |
| 正行之月（2021年02月下） | - 当前场上的角色生命值低于70%时，攻击力提升20%，攻击速度提升15%。 - 当前场上角色生命值低于35%且处于护盾庇护下时，暴击率提升20%，暴击伤害提升40%。 |
| 霜噬之月（2021年02月上） | 角色获得岩元素与冰元素结晶反应产生的冰元素晶片时，暴击率提高8%。该效果持续20秒，至多叠加5次。 |
| 仲冬之月（2021年01月下） | 角色获得岩元素与冰元素结晶反应产生的冰元素晶片时，获得5%攻击力提升、5%攻击速度提升，与4%移动速度提升。该效果持续20秒，至多叠加5次； |
| 初雪之月（2021年01月上） | - 角色获得岩元素与冰元素结晶反应产生的冰元素晶片时，会释放冲击波，对周围的敌人造成伤害。 - 角色获得岩元素与冰元素结晶反应产生的冰元素晶片时，元素战技的冷却时间减少1秒。 |
| 抗争之月（2020年12月下） | 处于护盾庇护下的角色受到攻击时，会引发能量爆裂，对周围的敌人造成伤害。此效果4秒内最多触发一次，伤害受益于角色的护盾强效属性。 |
| 宝石之月（2020年12月上） | 角色获取结晶反应的晶片时，会对周围的敌人造成晶片对应元素的范围伤害。该伤害受益于角色的护盾强效属性。 |
| 坚守之月（2020年11月下） | 角色处于护盾庇护下时，攻击力提升50%。 |
