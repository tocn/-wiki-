## 基本信息

| 冰晶蝶 | |
| --- | --- |
| 类型 | 其他 |
| 种类 | 晶蝶 |
| 出现地点 | 至冬、蒙德·龙脊雪山 |
| 实装版本 | 1.2 |
| 能否捕捉 | 能 |
| 描述 | 空气中飘荡不定的冰元素微粒聚合而成的纯粹元素生命，同蛱蝶一般悠游。 闪光的冰元素生物，是元素上升凝合而成的产物，以飞散在霜雾中的冰元素维生。 尽管无比脆弱，却能在风雪的簇拥下起舞。尽管本身完全无害，却昭示着霜雪降临，万物沉寂。 |
