## 基本信息

| 凛角鹿 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 鹿 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 高大而温驯的动物，拥有一双仿佛能洞悉万物的双眸。 曾有一位诗人在初次见到凛角鹿时留下了这样的文字：「它的身姿，如同远古神明遗落的幻影般寂静。那一身毛皮，不是凡尘所织，而是月色亲手披上的霜纱…」 霜月之子们相信凛角鹿是有灵性的，它们能引领迷途之人、疗愈伤痛，因此不猎不扰。据说，如果靠近凛角鹿的人心怀善意，它们会静静地注视来人片刻，仿佛在回应某种古老的约定。 |
