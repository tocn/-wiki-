## 基本信息

| 古石螺 | |
| --- | --- |
| 类型 | 其他 |
| 种类 | 海螺 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 能 |
| 描述 | 外形神似头盔的海螺。根据须弥教令院生论派学者的研究，这种海螺可能是提瓦特大陆上最古老的生物之一，因此得名古石螺。 当然，对挪德卡莱的孩子们来说，古石螺的壳更像是万能的宝贝：有人专门收集花纹独特的个体、或是将其当作兵战演习中的头盔、靠在耳朵边，还能听到大海的呼吸声…总之，再没有比它更好的玩具了！ |
