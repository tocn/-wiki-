## 基本信息

| 岩晶蝶 | |
| --- | --- |
| 类型 | 其他 |
| 种类 | 晶蝶 |
| 出现地点 | 震雷连山密宫前的挑战右前方的山洞里 |
| 实装版本 | 1.0 |
| 能否捕捉 | 能 |
| 描述 | 空气中飘荡不定的岩元素微粒聚合而成的纯粹元素生命，同蛱蝶一般悠游。 闪光的岩元素生物，是元素上升凝合而成的产物，以无处不在的岩元素维生。 在难以尽览的万古中，即使是磐岩也会做梦。据说岩晶凝成的飞蝶正是嵯峨山石之梦。 |
