## 基本信息

| 幽浮鳐 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 鳐类 |
| 出现地点 | 渊下宫 |
| 实装版本 | 2.4 |
| 能否捕捉 | 不能 |
| 描述 | 极为罕见的空游生物。 传说中，这种鳐最初是在漆黑的外海海底，通过荧光与元素的微粒，魅惑着渴求光芒者的掠食生物。 传说还说道，之所以幽浮鳐会出现在渊下宫，起初是误以为身披珊瑚的大蛇是它们所栖息的海床… |
