## 基本信息

| 暝彩鸟 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 飞鸟 |
| 出现地点 | 须弥森林 |
| 实装版本 | 3.0 |
| 能否捕捉 | 能 |
| 描述 | 生活在须弥的森林中的鸟类，因为绚丽的色彩颇受喜爱。在驯化之后，能够传递信件。 据说暝彩鸟在过去有着相当的智慧，能句够学会人的话语，甚至连文字也能理解。 |
