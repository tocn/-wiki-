## 基本信息

| 月萤虫 | |
| --- | --- |
| 类型 | 其他 |
| 种类 | 虫 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 挪德卡莱常见的奇特生物，浑身被白色的厚实绒毛包裹，据说其轻微颤动的触角能够感知月华的流向。 不知为何，捕获它后能够得到原本产自晶蝶的晶核，或许和挪德卡莱鲜少见到晶蝶有什么联系… |
