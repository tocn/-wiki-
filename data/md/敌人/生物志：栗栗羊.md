## 基本信息

| 栗栗羊 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 羊 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 能 |
| 描述 | 除了带有辉光的羊角和斑纹，与生活在提瓦特大陆其他地区的羊并无二致。 因柔软绵长的栗色毛发而得名栗栗羊。它们拥有双层毛发，栗色的外层长而防水，乳白色的内层毛发细腻蓬松，是用于制作冬衣和毛毯的绝佳原材料。 由于长期栖息于月矩力浓度极高的地区，羊角和身上的斑纹会微微发光。 |
