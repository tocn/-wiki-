## 基本信息

| 毒蝎 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 蝎 |
| 出现地点 | 须弥沙漠、稻妻八酝岛 |
| 实装版本 | 3.1 |
| 能否捕捉 | 不能 |
| 描述 | 生活在砂岩之下的大型节肢动物，擅长利用毒液捕猎。 因为在受到攻击时会分泌出含有剧毒的液体，因此在很久之前就被诸多阴谋家和炼金术士们盯上，成为了各类毒药的常用原料。果然比起毒蝎，还是人心要更加可怕。 |
