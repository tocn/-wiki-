## 基本信息

| 沙狐 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 狐 |
| 出现地点 | 须弥沙漠 |
| 实装版本 | 3.1 |
| 能否捕捉 | 能 |
| 描述 | 精灵般隐匿的狡黠生灵，在民话传说中拥有奇特的智慧与悠远的记忆。 生活在广阔的沙漠之中，或许是因为与同类相比体型更小的缘故而躲过了古时的灾厄。长长的耳朵是为了适应适应酷热干燥的沙漠环境而演化出来的。 |
