## 基本信息

| 游炎古琵鹭 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 水禽 |
| 出现地点 | 纳塔 |
| 实装版本 | 5.5 |
| 能否捕捉 | 不能 |
| 描述 | 能够在液态燃素上恣意游动的禽鸟。 因为一直生活在火山之内，而拥有与外界的琵鹭并不相同的习性与体态。有学者认为，游炎古琵鹭与山蓝琵鹭的关系，就如同浮燃鸟和浮流鸟的关系，但也有学者认为游炎古琵鹭会更加古老一些…如果真是如此的话，那就说明从很久以前开始，名为「琵鹭」的物种就一直是这样的大小了。 |
