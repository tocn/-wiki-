## 基本信息

| 灰羽鸽 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 鸽 |
| 出现地点 | 蒙德桥头（三只）和璃月奥藏山东方、绝云间北方的锚点东侧房屋屋顶上（三只） |
| 实装版本 | 1.0 |
| 能否捕捉 | 能 |
| 描述 | 提瓦特常见的鸟类，肉质肥美，训练后也能远程传信。 普通的鸽子，因灰白的羽毛而得名。这种鸽子颈部的羽毛呈现渐变的翠绿色，但可惜因为过于常见，许多人已经不再对这种美丽的毛色多加注意。 |
