## 基本信息

| 珊瑚蝶 | |
| --- | --- |
| 类型 | 其他 |

| 出现地点 | 「三界路飨祭」 |
| 实装版本 | 2.5 |
| 能否捕捉 | 能 |
| 描述 | 珊瑚王虫的迁徙形态，看起来像是蝴蝶。在接近完全转化一片区域的荒蛮元素时，下一代珊瑚王虫的骨骼就会凝聚为翅膀一般的形态。它们会在渊下宫中飞舞，寻找下一片繁衍生息之地。 它们是旧秩序的破坏者，原本只能在暗海偷生。但是蛇神给了它们新的机会。 |
