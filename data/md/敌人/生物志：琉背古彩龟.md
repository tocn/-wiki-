## 基本信息

| 琉背古彩龟 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 龟 |
| 出现地点 | 安饶之野 |
| 实装版本 | 5.5 |
| 能否捕捉 | 不能 |
| 描述 | 厚实的甲壳上，沉积着固态燃素结晶的爬行动物。 与生活在提瓦特大陆的其他同类相似，不过，似乎是因为从始至终都生长在燃素富集的区域，所以在甲壳上沉积了许多饱含固态燃素的岩石。据说曾有因为火山喷发而出现在火山外的个体，一些学者对其进行研究后，认为这种龟相对于现在的其他龟类来说，演化更为缓慢。 |
