## 基本信息

| 石鸢 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 鹰 |
| 出现地点 | 孤云阁最高点，白天 |
| 实装版本 | 1.0 |
| 能否捕捉 | 不能 |
| 描述 | 目光锐利的高傲鹰隼。 在山岩林立的绝峰之间筑巢的猛禽，人们传说这种禽鸟永远在云间放浪，无足无巢。但那只是鄙陋的无知与浪漫的想象结合之产物，石鸢也是要为腹中餐食、巢中幼鸟而奔忙的生灵。 |
