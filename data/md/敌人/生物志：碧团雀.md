## 基本信息

| 碧团雀 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 团雀 |
| 出现地点 | 孤云阁锚点东侧（四只）、璃月港内NPC萍姥姥附近的草地上（一只）、云来海七天神像东南侧锚点的东方偏南（六只）、绝云间锚点西方的小路上（一只）、望舒客栈北面桥头（一只）和石门锚点附近（一只）。 |
| 实装版本 | 1.0 |
| 能否捕捉 | 能 |
| 描述 | 聒噪的小小鸟类，遍布提瓦特大陆的各个角落。 羽毛如同翠玉宝石般碧蓝的团雀，古代矿工记事中常提到的「笼中雀」最初指的便是它们，因为碧团雀的健康状态很容易从羽毛色泽分辨出来。顺带一提，虽说今日的矿工依然在带团雀下矿，但已经不再讲究其羽毛的颜色了。 |
