## 基本信息

| 秋绒鸭 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 水禽 |
| 出现地点 | 沉玉谷古树茶坡东北方七天神像左下角桥南边水面上（3只） |
| 实装版本 | 4.4 |
| 能否捕捉 | 不能 |
| 描述 | 呱呱叫的水禽，生活在提瓦特大陆的河湖与湿地之中。 棕褐色的绒羽会使人想起秋日的落叶，由这些绒羽制成的温暖衣物在寒冷的秋日也广受欢迎，故而得名。 |
