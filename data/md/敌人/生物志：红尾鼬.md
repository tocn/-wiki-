## 基本信息

| 红尾鼬 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 鼬 |
| 出现地点 | 琥牢山最下方琥珀每日刷新概率出；稻妻九条阵屋传送点南面有聚集。 |
| 实装版本 | 2.0 |
| 能否捕捉 | 能 |
| 描述 | 身材细长灵巧、钟爱恶作剧的捣蛋鬼。 通体赤红的鼬鼠，擅长捕食昆虫与蜥蜴。身上赤红的颜色十分显眼，由于红尾鼬的和火元素色彩相称，许多惧怕烧灼的捕食者会敬而远之。 |
