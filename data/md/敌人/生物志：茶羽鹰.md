## 基本信息

| 茶羽鹰 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 鹰 |
| 出现地点 | 遁玉陵西侧、青墟浦中间 |
| 实装版本 | 1.0 |
| 能否捕捉 | 不能 |
| 描述 | 目光锐利的高傲鹰隼。 总是在清冷的高空盘旋，伺机寻找着隐身于草木间的小小松鼠与鸟雀。据老练的猎人说，这种猛禽稍加训练，便会是优秀的猎鹰。 |
