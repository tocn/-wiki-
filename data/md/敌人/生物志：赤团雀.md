## 基本信息

| 赤团雀 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 团雀 |
| 出现地点 |
| 实装版本 | 1.0 |
| 能否捕捉 | 能 |
| 描述 | 聒噪的小小鸟类，遍布提瓦特大陆的各个角落。 这种鸟雀生着鲜艳的赤色羽毛，以便求偶时用来大肆炫耀。不幸的是，这样鲜艳的羽毛也很容易吸引捕猎者的目光，娇小可爱的赤团雀可以说是提瓦特大陆食肉动物主要的食物来源之一。 |
