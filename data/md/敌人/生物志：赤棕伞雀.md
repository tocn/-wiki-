## 基本信息

| 赤棕伞雀 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 团雀 |
| 出现地点 |
| 实装版本 | 4.0 |
| 能否捕捉 | 能 |
| 描述 | 体型浑圆的小型飞禽，是团雀的枫丹远亲。其伞雀的名字正是来自于它那有若蘑菇伞盖般，形貌独特的羽冠。 研究显示，赤棕伞雀的飞行能力较差，难以躲避各种捕食者。但其会利用自己赤棕色的羽色，在森林中伪装成某些植物或岩石，从而避开攻击。 |
