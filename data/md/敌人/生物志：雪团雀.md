## 基本信息

| 雪团雀 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 团雀 |
| 出现地点 | 星落湖七天神像西侧（两只）、清泉镇南侧锚点西侧（四只）和奔狼领锚点与晨曦酒庄七天神像之间的山上（四只） |
| 实装版本 | 1.0 |
| 能否捕捉 | 能 |
| 描述 | 聒噪的小小鸟类，遍布提瓦特大陆的各个角落。 通体雪白的小小生灵，在冰天雪地中自得其乐。雪团雀天生适应寒冷气候，对温度的变化十分敏感，在温暖的地域会变得有些缺乏精神，因而比较容易捕获。 |
