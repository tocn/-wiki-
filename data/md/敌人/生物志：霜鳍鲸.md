## 基本信息

| 霜鳍鲸 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 鲸 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 对大多数生物来说，霜鳍鲸都是凌厉的掠食者，但只有对人类除外。 虽然它们巨大的尾鳍能轻易掀翻渔船，也能一口将人吞下，但老渔民都知道，霜鳍鲸从不主动攻击人类。相反，它们喜欢与船只竞速，也常跃出水面，掀起巨浪，仿佛很享受和人类一同玩要。 据说，也有好事者不惜在船上瑟瑟发抖地等待好几个小时，只为一赌霜鳍鲸跃水的瞬间。毕竟谁也不能拒绝，拥有此等力量的美丽生物，只对你展露笑颜的模样吧？ |
