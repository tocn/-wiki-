## 基本信息

| 面具鼬 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 鼬 |
| 出现地点 | 须弥沙漠 |
| 实装版本 | 3.1 |
| 能否捕捉 | 能 |
| 描述 | 身材细长灵巧、钟爱恶作剧的捣蛋鬼。 黑色的面部给人一种戴着大盗面具的印象，但其实却是温顺友好的品种，也很少会进入人类的领地偷窃食物。尽管如此，面具鼬温顺友好的天性有时也会被不怀好意之徒盯上，利用来满足自己不劳而获的私欲。 |
