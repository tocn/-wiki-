## 基本信息

| 靴子鼬 | |
| --- | --- |
| 类型 | 走兽 |
| 种类 | 鼬 |
| 出现地点 | 翠玦坡西侧和天云峠西侧岛屿 |
| 实装版本 | 2.0 |
| 能否捕捉 | 能 |
| 描述 | 身材细长灵巧、钟爱恶作剧的捣蛋鬼。 因为四肢的深色毛发看似长靴而得名。靴子鼬性情较其他同类更加胆小谨慎，其蹑手蹑脚的动作反过来正加深了「穿靴子的鼬」的印象。因此，提瓦特大陆的居民们多有关于这些贼头贼脑的小动物的奇妙传说。 |
