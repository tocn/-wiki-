## 基本信息

| 黑王鸽 | |
| --- | --- |
| 类型 | 禽鸟 |
| 种类 | 鸽 |
| 出现地点 | 璃月轻策庄西侧锚点附近（四只）、璃月奥藏山东方绝云间北方锚点东侧房屋屋顶（四只）和蒙德城桥头（两只） |
| 实装版本 | 1.0 |
| 能否捕捉 | 能 |
| 描述 | 提瓦特常见的鸟类，肉质肥美，训练后也能远程传信。 较为常见的鸽子，以黑色的头部闻名。比其他种类的鸽子更加勇敢好斗，因而更容易捕获。肉质紧实美味，适宜烤制。 |
