## 基础信息

| | |
| --- | --- |
| 名称 | 「夜魂迸发」 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 5.0 |

教程说明
队伍中有纳塔角色时，当角色对敌人造成元素伤害时，就会触发「夜魂迸发」；队伍中的纳塔角色越多，「夜魂迸发」触发的间隔就会越短：队伍中有1/2/3或更多名纳塔角色时，「夜魂迸发」触发的间隔分别为18/12/9秒。

教程说明
「夜魂迸发」能进一步引发其它的效果，如角色天赋、圣遗物的效果等。
