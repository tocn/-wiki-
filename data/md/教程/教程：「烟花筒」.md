## 基础信息

| | |
| --- | --- |
| 名称 | 「烟花筒」 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 2.4 |

教程说明
放置「烟花筒」后，可以在「燃放准备」界面配置燃放烟花的种类、次序等参数，按照不同的需求燃放烟花。
烟花燃放结束、进入战斗状态或距离过远时，「烟花筒」将被自动回收。

教程说明
使用[烟花筒」的「改造样式」功能，可以在烟花原有的样式上进行改造，制造出旅行者中意的烟花效果！
