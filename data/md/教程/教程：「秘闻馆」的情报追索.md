## 基础信息

| | |
| --- | --- |
| 名称 | 「秘闻馆」的情报追索 |
| 类别 | 系统 |
| 类型 | 永久教学 |
| 教程数目 | 4 |
| 实装版本 | 月之二 |

教程说明
「秘闻馆」的角色可以通过特殊的情报调查能力，从挪德卡莱的部分住民处获取情报。

教程说明
在某些情况下，获取的情报可以解锁特殊的对话选项…

教程说明
每周至多可以获取六条情报。获取情报后，由「秘闻馆」的角色前往冒险家协会，即可与凯瑟琳进行情报交易，获取「机密信息」。

教程说明
「机密信息」可以用于解锁新的情报任务。完成情报任务后，还会解锁与「秘闻馆」角色相关的新任务，并获取额外的奖励。
