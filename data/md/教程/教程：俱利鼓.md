## 基础信息

| | |
| --- | --- |
| 名称 | 俱利鼓 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 3.6 |

教程说明
过去由矫论团的先辈所制造的鼓，按照特定的方式敲击似乎便能震响其中的元素之力…
俱利鼓有三种敲击方式，对其使用普通攻击能够击出轻响，使用下落攻击则会击出重响，停止不动则为空拍。

教程说明
俱利鼓附近通常绘有鼓谱。鼓谱由叶片符号组成，分为空、半、满三种，分别指代停、轻、重三种节奏。
可以按照从左至右，从上至下的顺序阅读鼓谱。

教程说明
演奏开始后，俱利鼓每闪烁一次视为一个节拍。按照鼓谱，在对应的节拍击出相应的鼓声，便可以完成演奏！
