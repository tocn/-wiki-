## 基础信息

| | |
| --- | --- |
| 名称 | 元素附魔 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 1.0 |

教程说明
战斗中，有一些技能、效果能使使用武器类型为单手剑、双手剑与长柄武器的角色获得元素附魔：进行普通攻击、重击与下落攻击时，攻击会造成对应的元素伤害。多种附魔效果无法共存。

教程说明
此外，一些技能会使角色的攻击发生变化，使其造成元素伤害。虽然与附魔有相似之处，但无法被元素附魔覆盖。
