## 基础信息

| | |
| --- | --- |
| 名称 | 八奇乱斗 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 5 |
| 实装版本 | 5.3 |

教程说明
在「八奇乱斗」中，场地顶部标记区域将不断生成新的方块并下落，旅行者可以控制方块进行左右移动、旋转或加速下落。当4个及以上的同色方块相连时将触发消除。

教程说明
当消除结束后，我方藤人会根据「连锁等级」向对手藤人发起攻击并获取能量。

攻击将会对对手藤人造成伤害并在对方的场地上设置阻碍。

当双方有一方藤人的生命值耗尽时，另一方便将获得胜利。

教程说明
当触发消除后，处于被消除方块顶部的方块会立刻下落，若下落的方块再次触发消除则将触发连锁消除效果。
连锁消除将提升藤人的攻击力与获取的能量，同时使设置阻碍时的效果增强。

教程说明
不同藤人拥有效果不同的战技，点击施放后将可以为己方提供增益效果。
当藤人充能完成后，将会自动施放强力技能，对对手造成阻碍。

教程说明
对局中，方块受技能影响可能携带各类不同的效果，具体效果可查看藤人的技能详情。
在「友好拼斗」和「全力竞技」模式中，不同的对手会周期性在我方场地中设置具有不同负面效果的方块。
