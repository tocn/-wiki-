## 基础信息

| | |
| --- | --- |
| 名称 | 前哨龙迹 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 月之三 |

教程说明
在「前哨龙迹」中，旅行者需要操纵勘测机关「前哨龙龙」沿着指定航线飞行，在限定时间内抵达终点，并尽可能收集更多冒险币。
抵达终点时剩余时间越多，收集的冒险币越多，完成挑战时的得分就越高。

教程说明
挑战中存在「航线障碍」和「屏护之盾」，触碰「航线障碍」时将损失得分，「屏护之盾」则可以让「前哨龙龙」一段时间内免受「航线障碍」的影响。

教程说明
挑战中会出现「冲刺门扉」和「聚引之环」。触碰「冲刺门扉」后，「前哨龙龙」将爆发冲刺一段距离。获取「聚引之环」后的一段时间内，「前哨龙龙」将自动收集附近的冒险币。
