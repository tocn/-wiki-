## 基础信息

| | |
| --- | --- |
| 名称 | 剪影辑帧 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 4 |
| 实装版本 | 5.4 |

教程说明
根据脚本规划，为每一镜选择合适的素材，组成成片并完成剪辑。

教程说明
符合脚本规划的剪辑成片，将获得特别好评。
在成片获得过特别好评后，剪辑成片时将不再受脚本限制，可自由决定成片使用素材的总量，并尝试不同的方案，拍摄不同长度的成片。在同一脚本中，同一个素材至多可重复使用3次。

教程说明
点击查看素材一览，可以阅览所有可用的素材和对应台词。

教程说明
在剪辑完成后，可以保存成片方案。初次完成时的成片方案将被自动设置为分享。在剪辑记录中，可以查看好友分享的成片方案。
