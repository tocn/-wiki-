## 基础信息

| | |

| 名称 | 古月力与古月波纹 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 月之八 |

教程说明
神奇的古月力，与月矩力有着相似的表现，可以改变物体受到的作用力。角色吸取富含古月力的物体后，将进入「月纹充盈」状态。

教程说明
「月纹充盈」状态下身体会更加轻盈，跳跃高度变高。跳跃状态下也可使用古月波纹。

教程说明
使用攻击键可释放古月波纹。点按将原地释放，长按以瞄准发射释放。发射后再次点按则会引爆古月波纹，对爆炸范围内物体赋予「月纹充盈」状态，该物体受到的重力将受到影响。点按元素爆发键可以退出「月纹充盈」状态。
