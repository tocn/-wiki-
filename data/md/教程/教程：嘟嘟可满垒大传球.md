## 基础信息

| | |
| --- | --- |
| 名称 | 嘟嘟可满垒大传球 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 8 |
| 实装版本 | 月之七 |

教程说明
在「嘟嘟可满垒大传球」中，需要帮助可莉，将蹦蹦炸弹通过传球的方式交给所有嘟嘟可伙伴。
每次传球后，将从蹦蹦炸弹当前停留的位置进行下一次传球。

教程说明
场地内存在正面区域和负面区域，命中时，能够触发对应的效果，或者获得可以主动使用的奇妙道具。成功触发后的2回合内，不能再次触发。

教程说明
每次传球，都会记录1次传球次数。如果仅触发了正面区域，将减少1次传球次数；如果仅触发了负面区域，将额外记录1次传球次数。
挑战成功时，所用的传球次数越少，最终得分越高。

教程说明
若是不慎将蹦蹦炸弹传到了盗宝鼬的活动区、沉沉水域或界外，本次传球将无效，蹦蹦炸弹将被送回传球开始的位置。

教程说明
准备传球时，可以调整传球的方向和力度。在0-10m的力度下传球，蹦蹦炸弹会贴地滑动，而更大力度的传球则会使其以抛物线飞出。

教程说明
蹦蹦炸弹到达预估位置后，还会额外向前滑动或弹跳一段距离。随着传球力度提升，弹跳和滑动距离也将变远。

教程说明
传球至嘟嘟可伙伴、正面区域和负面区域所需的力度，将在控制力度的刻度条上显示。开始传球后，指针将自左向右移动，在指针移动到对应位置时点击按钮，即可确定对应的传球力度。若指针移动到最右端时还未点击按钮，则默认使用最大力度。

教程说明
指针移动到最右后将会立即返回，自右向左移动，此时控制的是传球的准度。在指针处于准度刻度条中心的位置再次点击按钮，可以减少蹦蹦炸弹偏移预期落点的距离。若指针移动到最左端时还未点击按钮，落点偏移预期的程度将默认为最大。
