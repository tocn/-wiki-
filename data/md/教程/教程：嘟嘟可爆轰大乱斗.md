## 基础信息

| | |
| --- | --- |
| 名称 | 嘟嘟可爆轰大乱斗 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 4 |
| 实装版本 | 月之一 |

教程说明
在「嘟嘟可爆轰大作战」挑战中，旅行者可以选择不同形象的嘟嘟可，组成四位嘟嘟可的乱斗小队，共同使用蹦蹦炸弹击败角角鱼和坏鱼们请来的外援强敌…

教程说明
挑战中，嘟嘟可被敌人与强敌攻击，或被自己的炸弹爆炸波及时，均会损失「活力值」，通过拾取「小小绷带」，可以恢复嘟嘟可的「活力值」。

教程说明
挑战中，通过击败敌人，或破坏「均质水草」，可以累积经验值，从而提升各项能力。击败敌人的经验值与能力提升将与队伍中所有嘟嘟可共享。

教程说明
在关卡详情界面中，可以查看当前关卡的敌人信息，以及可以获得的各种乱斗助益，以便更有效地战胜外援强敌…
