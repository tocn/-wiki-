## 基础信息

| | |

| 名称 | 嘟嘟可砰砰假日 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 月之三 |

教程说明
强壮的角角鱼士兵，身披来历不明…或许是用水下垃圾攒出来的装甲，非常耐打。破坏装甲后才能对其造成伤害。若是在巡逻时撞上嘟嘟可，就会对嘟嘟可造成伤害。

教程说明
获取「空心装药」后，嘟嘟可的炸弹升级为自锻炸弹，获得穿透水草和敌人的效果，对爆炸范围内的所有敌人造成伤害。此外，嘟嘟可通过空心装药升级后的自锻炸弹能够直接穿透装甲，对装甲角角鱼造成伤害。

教程说明
冠名角角实际却无角的斧枪鱼士兵，似乎也是爆炸爱好者，会不断部署水泡炸弹。水泡炸弹将对嘟嘟可造成伤害，并且能够引爆嘟嘟可放置的炸弹。此外，水泡炸弹将不会对角角鱼士兵或水草造成伤害。
