## 基础信息

| | |
| --- | --- |
| 名称 | 多人演奏 |
| 类别 | 系统 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 月之三 |

教程说明
在曲谱选择页面，可以发起多人演奏。
在多人演奏中，所有参与者将各自进行演奏，争夺最高的最终评分。

教程说明
在多人演奏中，发起者可以额外选择曲谱的特化效果，以提升或降低演奏难度，或是进行特殊的挑战。
部分特化效果在多人演奏中无法生效。
