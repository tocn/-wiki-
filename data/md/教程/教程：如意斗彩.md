## 基础信息

| | |
| --- | --- |
| 名称 | 如意斗彩 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 月之四 |

教程说明
在挑战中，击败敌人会掉落如意钱。每隔一段时间，「聚财兜」自动吸取场地中的如意钱。旅行者需在限定时间内尽可能多地击败敌人，以获取更多如意钱。

教程说明
通过特定方式命中或击败敌人，以及在与强敌交战过程中完成特定行为，均能获得更多的如意钱。

教程说明
吸取一定数量的如意钱后，「聚财兜」将升级，并使敌人掉落更多如意钱。「聚财兜」最多可以升级两次。
