## 基础信息

| | |
| --- | --- |
| 名称 | 安全接敌实训 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 2 |
| 实装版本 | 月之二 |

教程说明
在「安全接敌实训」中，每个关卡均包含2轮战斗。在「先遣准备」的战斗中，需要以规定方式完成目标挑战，「先遣准备」的挑战结果越好，「正式接敌」战斗中获得的增益效果便越多。

教程说明
在「正式接敌」的战斗中，需要在限定时间内利用特殊的增益效果尽可能多地击败敌人，从而获取更高的积分。
