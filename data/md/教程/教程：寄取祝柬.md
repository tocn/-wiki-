## 基础信息

| | |

| 名称 | 寄取祝柬 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 5.3 |

教程说明
旅行者也可以自行创作祝柬，并用各种纹样装饰祝柬。制作完成的祝柬可以赠送给伙伴，亦可以赠送给其他旅行者，或公开在祝柬展栏中。

教程说明
公开在祝柬展栏中的祝柬，可以被其他玩家浏览和搜索。对于已公开发布的祝柬，旅行者们亦可以随时将其切换至非公开状态。

教程说明
祝柬可以赠送给伙伴，或是其他旅行者。将祝柬赠予伙伴们时，会获得特别的「祝语纹样」。
