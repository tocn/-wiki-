## 基础信息

| | |
| --- | --- |
| 名称 | 尘歌壶 |
| 类别 | 系统 |
| 类型 | 永久教学 |
| 教程数目 | 9 |
| 实装版本 | 1.5 |

教程说明
旅行者使用并召出「尘歌壶」后，可以与「尘歌壶」交互进入「尘歌壶」内。
当旅行者处于「尘歌壶」内时，也可以使用并召出「尘歌壶」，与「尘歌壶」交互后，即可离开「尘歌壶」。
旅行者还可以直接打开地图界面，使用传送锚点进行传送，直接离开「尘歌壶」。

教程说明
在「尘歌壶」内，可以在壶灵处了解和操作「尘歌壶」的诸项事宜。

教程说明
通过制作界面，可以制作各种物品。

教程说明
可以在世界各处搜集制作物品所需的材料。

教程说明
在获得了摆设后，可以通过放置功能对其进行摆放。

教程说明
成功放置摆设，可以提升尘歌壶的洞天仙力等阶。随着仙力等阶的提高，洞天宝钱的搜聚速度也会随之增加。

教程说明
洞天宝钱可以在洞天百宝内交换各种物品。

教程说明
每隔一段时间，都会有一位周游壶灵造访洞天。这位周游壶灵，也许会带有一些珍稀的宝货。

教程说明
如果获得了摆设套装图纸，就可以进行对多件摆设进行批量放置。放置时，单件摆设依然可以进行微调。
