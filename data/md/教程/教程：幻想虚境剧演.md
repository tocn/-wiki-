## 基础信息

| | |
| --- | --- |
| 名称 | 幻想虚境剧演 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 月之七 |

教程说明
在「幻想虚境剧演」玩法中，旅行者需要先参与「训练计划」，完成各项训练目标以获取「猎魔动力」。随后在「猎魔剧演」中，击败敌人赢取积分。

教程说明
在「训练计划」中，击败敌人不会获得积分，仅会获取「猎魔动力」。

「训练计划」时间结束，或训练目标完全达成后，将开启「猎魔剧演」。

部分敌人在训练中，会展现出特殊的性质。

教程说明
在「猎魔剧演」中，角色将持续消耗「猎魔动力」，以获取「猎魔助益」并维持剧演时长。在此阶段击败敌人即可获得积分。

「猎魔动力」完全消耗后，需重新进行「训练计划」。

累计完成两次「猎魔剧演」后，挑战结束。
