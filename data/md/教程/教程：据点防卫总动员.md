## 基础信息

| | |
| --- | --- |
| 名称 | 据点防卫总动员 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 5 |
| 实装版本 | 月之五 |

教程说明
在挑战过程中，旅行者需要设置多种机关，击退来袭的敌人，确保据点免遭破坏。

教程说明
不同机关可选择不同的升级方案，根据选择的方案，可组合形成多样化的机关效果。

教程说明
已升级的机关可随时消耗螺栓改造为其他升级选项。

教程说明
在敌人发动攻击后，可使用支援技能协助击败敌人。支援技能的能量将随时间缓慢恢复，通过收集机关可加快充能速度。

教程说明
完成特定波次挑战后，可选择协议。协议将强化我方的火力，或提升获取螺栓的效率。
