## 基础信息

| | |
| --- | --- |
| 名称 | 斗魂试炼 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 4 |
| 实装版本 | 月之三 |

教程说明
在「斗魂试炼」玩法中，旅行者需要合理选择不同种类的「斗魂」，并在战斗中触发「斗魂」的效果，以提升队伍的战斗力和获取积分的能力。

教程说明
「累进斗魂」可以在单次挑战中增加敌人被击败时所提供的积分，「豪烈斗魂」则可以提升单次挑战中队伍获得积分时的额外倍率。

教程说明
此外，每个挑战都具备专属的「基础风格」。触发后，可在一段时间内成倍提升队伍获取积分的能力，并大幅增强角色战斗力，重复触发将刷新持续时间。

教程说明
击败敌人时，会根据敌人被击败时所提供的基础得分、难度倍率、获得积分时的额外倍率与「基础风格」触发后所提供的限时倍率（未触发时此倍率为1）互相乘算后所得的乘积，计算击败敌人所获得的积分。
