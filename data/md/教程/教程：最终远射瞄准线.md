## 基础信息

| | |
| --- | --- |
| 名称 | 最终远射瞄准线 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 7 |
| 实装版本 | 月之八 |

教程说明
在「最终远射瞄准线」中，旅行者需要发射「观测榴弹」，在不触碰到障碍物的情况下，命中演习场地内的所有目标。

「观测榴弹」命中目标后，能够以目标的当前位置为出发点，改变方向，再次发射，直线飞行。

命中障碍物时，挑战将失败。

教程说明
「观测榴弹」飞行的距离越远，命中目标后，评分越高。因此，规划好射击的弹道，尽可能打出远程命中，是在演习中取得高分的关键。可以通过标记目标，合理排列射击顺序，辅助射击弹道的规划。

教程说明
瞄准目标时，可以通过对应按钮标记目标，再次点击按钮将取消标记。

教程说明
也可以通过全部取消按钮，取消当前所有目标的标记。

关卡Ⅲ「山地僵持站」中

教程说明
演习场地内存在一次性的「理想弹道环」，「观测榴弹」从中穿过并命中目标后，将获得大量评分。

教程说明
演习场地内存在多个射击阵位，可以通过箭头提示的位置，在不同射击阵位间进行切换，观察全局，规划出最高效的射击方案。

关卡Ⅳ「突破谷地关隘」中

教程说明
部分目标展开的盾牌能够抵挡「观测榴弹」，使本次射击无效化。合理规划弹道，绕过盾牌将其命中，是更有效的选择…
