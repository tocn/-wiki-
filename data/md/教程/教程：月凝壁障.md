## 基础信息

| | |
| --- | --- |
| 名称 | 月凝壁障 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 月之四 |

教程说明
纯粹的月矩力能量凝结之后形成的壁障，其中或许封存着意想不到的东西…
利用充盈的月矩力的事物进行冲击，或是利用其他手段释放月矩力波使其进入充盈状态，上面的壁障便会随之融解。

教程说明
但若是大型的壁障，则需要多次充能后，才能使其进入充盈状态。通过观察壁障表面的状态，可以判断当下的充能进度。

教程说明
完全充能之后的月凝壁障会显露出其中封存的事物，同时转变为充盈状态。此时的月凝壁障将会为进入其中的可被月矩力影响的事物补充能量。
