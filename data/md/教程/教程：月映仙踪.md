## 基础信息

| | |
| --- | --- |
| 名称 | 月映仙踪 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 月之四 |

教程说明
在「月映仙踪」玩法中，旅行者需要根据章节顺序，依次击败三只大詹。
挑战开始后，需要在有限的回合时长内击败詹诸和点亮霄灯，以吸引大詹的现身。

教程说明
回合开始后，白马仙人会自动攻击附近的敌人，并点亮附近的霄灯；由敌人或者霄灯掉落的心愿，在白马仙人靠近后能够自行收取。

教程说明
若未能成功在限时内击败大詹，可通过收集到的心愿强化自身，提升实力后再次挑战。
