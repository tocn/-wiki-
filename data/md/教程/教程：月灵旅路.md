## 基础信息

| | |

| 名称 | 月灵旅路 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 月之一 |

教程说明
一说是月灵行过留下的痕迹，在月矩力充盈的挪德卡莱并不少见。
乘上月灵旅路，便能借助月灵的力量沿着轨迹快速移动，不过，旅路也并非总是一路畅通，在必要时，更换路径也是不错的选择。

教程说明
化身红色或蓝色的月灵乘上旅路时，可自由驱使月矩力与轨道附近的物体进行交互。
