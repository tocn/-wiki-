## 基础信息

| | |
| --- | --- |
| 名称 | 深渊的雾障 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 月之四 |

教程说明
不断淤积的深渊气息形成的雾障，可以利用月矩力波将其清除。

教程说明
但若是多个深渊雾障汇聚而成的大型雾障，则需要将与之连结的深渊雾障全部清除后，才能将其彻底净化。
