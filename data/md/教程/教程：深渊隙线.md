## 基础信息

| | |
| --- | --- |
| 名称 | 深渊隙线 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 月之四 |

教程说明
「边界」之外的深渊意志无时无刻不窥伺着此世，这些隙线便是它们从裂隙中伸出的探针。
需要利用锋萼花[1]，施放月矩力光刃切断「深渊隙线」的薄弱节点，或是释放足够强力的月矩力波，才能将其清除。

教程说明
有时，被其连接的生物会因受到深渊意志的影响而丧失理智。受其影响的敌人会变得更加凶恶，原本友好的伙伴也会因此变得狂暴。
遇到这种情况时，需设法切断「深渊隙线」以阻断其影响。
