## 基础信息

| | |
| --- | --- |
| 名称 | 清理单元 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 4 |
| 实装版本 | 月之一 |

教程说明
月矩力试验设计局中随处可见的小型机械装置，可以通过操作台对其进行操作。愚人众也早已对其存在习以为常。

教程说明
运作中的清理单元会进入赋能状态，能够吸收或投掷「双极」物件。

教程说明
清理单元暂时停止运作时，将不会继续携带此前吸收的「双极」物件。

教程说明
暂时停止运作的清理单元同样能够使角色进入赋能状态。
