## 基础信息

| | |
| --- | --- |
| 名称 | 璇珑花 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 月之四 |

教程说明
与月矩力能量共生的奇异植株，似乎与周围的特定物件存在着无法目见的连系。
吸取「璇珑花」中的能量核心后，通过控制能量核心与「璇珑花」之间连线的长短，可以使周围的特定物件旋转或位移。

教程说明
旋转或位移至特定的位置后点按释放，可以使能量核心与「璇珑花」之间连线固定下来，从而使周围的物件停留在特定位置。
