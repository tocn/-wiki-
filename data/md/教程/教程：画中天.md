## 基础信息

| | |
| --- | --- |
| 名称 | 画中天 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 月之六 |

教程说明
在空之神殿内，有时会找到一些封存着空间的画作。
将画中的图景重叠在现实中对应的场景上，小右便能将画中封存的空间复原，使画中之物化为实体。

教程说明
画作内容与实景越贴合，画框发出的光芒便会越明亮。

教程说明
小右也可以随时取回或重新投出画作。
