## 基础信息

| | |
| --- | --- |
| 名称 | 瞬影旅集 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 2 |
| 实装版本 | 月之四 |

教程说明
在挑战的第一阶段，需要依据关卡给定的剪影，做出正确的动作，并使用「瞬影」留影机，捕捉与剪影相符的瞬间。挑战中经过一定时间后，可使用「动作提示」功能，获得正确动作的提示。此外，挑战中角色处于部分特殊动作状态时，无法使用「瞬影」留影机。

教程说明
在挑战的第二阶段，还需要调整相机完成构图。当角色与剪影重合度达到一定程度时，即可进行拍摄，完成挑战。此外，挑战中经过一定时间后，可使用「协助」功能，获得镜头设置的帮助。
