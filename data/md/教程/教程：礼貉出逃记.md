## 基础信息

| | |
| --- | --- |
| 名称 | 礼貉出逃记 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 4 |
| 实装版本 | 月之七 |

教程说明
在「礼貉出逃记」挑战中，需要引导不断前进的大礼貉更换路线或进行跳跃，躲避各种障碍，尽可能收集更多饭团。

教程说明
前进过程中，如果不慎撞击障碍物，大礼貉将损失活力值，活力值耗尽后，挑战失败。

解锁关卡「Ⅲ为了饭团疾速冲刺」后

教程说明
部分挑战中，如果大礼貉在一段时间内未撞击障碍物，将不断加速至最高速度。

解锁关卡「∞无尽的逃跑诀窍」后

教程说明
「礼貉出逃记」的最终挑战中，大礼貉将不断前进，面临速度更快，难度更高的挑战。
挑战过程中，随时可以提前结算。
