## 基础信息

| | |
| --- | --- |
| 名称 | 笔腾墨跃 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 2 |
| 实装版本 | 月之四 |

教程说明
在挑战中，由旅行者回忆而来的伙伴会保持奔跑的状态，妥善利用伙伴们的元素战技跨越沟壑或障碍，在限定时间内抵达终点即可完成挑战。

教程说明
抵达终点时，剩余的时间越多，收集的玉石越多，完成挑战时的得分就越高。
