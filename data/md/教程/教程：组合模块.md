## 基础信息

| | |

| 名称 | 组合模块 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 月之一 |

教程说明
组合模块是能够承载红色或蓝色「单极」的物件。

教程说明
向未被激活的组合模块投掷月矩力中继机关可激活其力场。

教程说明
力场激活后，受到施力效果影响的组合模块将会产生位移。
