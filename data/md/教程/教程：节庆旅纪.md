## 基础信息

| | |

| 名称 | 节庆旅纪 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 5 |
| 实装版本 | 5.3 |

教程说明
在海灯节期间，总务司在璃月港内布置了各种节庆玩具。造访这些节庆玩具，提升节庆旅纪的进度后，可兑换相应奖励。

教程说明
在「灯下游艺」界面中，可查看各个节庆玩具在璃月港的所在位置。

教程说明
通过攻击激活「吉语钱」，将其拨动旋转。成功拨动「吉语钱」后，可提升节庆旅纪的进度。

教程说明
造访「观景镜」，从中观察远方的景致。成功观察到景致后，可提升节庆旅纪的进度。

教程说明
通过攻击激活「烟花筒」，使其停止旋转，可以提升节庆旅纪的进度。当停止旋转的「烟花筒」指向特定图案时，还能够发射出对应的烟花。如果能让「烟花筒」同时显示出四种相同的图案，也许会有不一样的事发生…？
