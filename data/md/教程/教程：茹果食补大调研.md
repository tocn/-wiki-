## 基础信息

| | |
| --- | --- |
| 名称 | 茹果食补大调研 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 8 |
| 实装版本 | 5.7 |

教程说明
与派蒙一起在果园中规划路线，尽可能高效地采集同一种颜色的树果。
以采摘者派蒙为起点，选中八个方向相邻的同类型树果或其他可选目标，进行连接，以作为果园采摘的规划路线。点击行动后，派蒙就将按照路线收集树果，或与可选目标互动。

教程说明
在单次规划路线的采集中，每通过采集、互动或消除10/20/30个目标，都将会在场上的随机位置生成一块三色树果冻。在采摘规划路线经过放置三色树果冻的格子之后，可以选择任意颜色的树果继续进行这一次的采摘规划。

教程说明
每次挑战只能使用一次，使用后，场地内的所有树果种类都将被全部重置。被重置的树果不会计入关卡采摘进度。

教程说明
两次行动内未能将盗果鼬赶走，或是采摘规划路线的终点停留在盗果鼬周围区域的格子，盗果鼬会逃跑，从场上随机一个格子重新出现，偷走格子里的三色树果冻或树果。

教程说明
任何类型的树果都能够与盗果鼬所在的格子相连，只要采摘规划的路线经过它，就能将其赶跑，被赶跑的盗果鼬，会在果园中留下三色树果冻。

教程说明
使用后，会消除采集者所在横排格子内所有的树果，被消除的树果会计入关卡采摘进度。

教程说明
丛生荆棘出现后，会使出现的格子变更为不可通过和选中的状态，在2次采摘行动过后，荆棘将会枯萎消失。
丛生荆棘可使用相应道具进行清除。

教程说明
使用后，会消除采集者所在格子周围区域的所有树果和丛生荆棘，被消除的树果会计入关卡采摘进度。
