## 基础信息

| | |
| --- | --- |
| 名称 | 草露 |
| 类别 | 元素 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 月之一 |

教程说明
队伍中的角色触发月绽放反应后的2.5秒内，每2.5秒便会为队伍提供一枚草露。
草露上限为三枚。持续期间，再次触发月绽放反应时，将刷新上述效果的持续时间。

教程说明
部分角色可以消耗草露，对敌人造成月绽放反应伤害。
