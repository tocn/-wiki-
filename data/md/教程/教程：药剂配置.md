## 基础信息

| | |
| --- | --- |
| 名称 | 药剂配置 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 月之三 |

教程说明
放入药材，覆盖更多区域，可以提升本次炼制的调和率。调和率达到100%或以上，即可完成炼制，获得药剂。

教程说明
每次炼制药剂时，可以使药材在炼金釜中重叠占用方格。
由于有砂糖的帮助，炼制时可重叠的方格数量为5个。

教程说明
每种药材对应的倾向不同影响最后药剂的成品倾向，制作出指定的药剂即可完成考核
