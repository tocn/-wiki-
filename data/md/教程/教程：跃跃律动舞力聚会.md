## 基础信息

| | |
| --- | --- |
| 名称 | 跃跃律动舞力聚会 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 月之二 |

教程说明
在「跃跃律动舞力聚会」中，领舞将会先行做出动作，旅行者需记忆领舞的动作，并在后续的音乐中指挥舞者做出相同动作。

教程说明
在聚会中，需要时刻注意聚光灯和鼓点。在聚光灯下听到两声鼓点后，就需要做出与上轮领舞相同的动作。

教程说明
随着音乐流淌，气氛进入高潮，狂热时刻也将来临！

在狂热时刻来临时，可通过有节奏地敲击节拍来获得额外评分。

在舞曲临近尾声时，还可以通过连续敲击节拍来获得额外评分。
