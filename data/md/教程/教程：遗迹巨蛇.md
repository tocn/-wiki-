| | |
| --- | --- |
| 名称 | 遗迹巨蛇 |
| 类别 | 敌人 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 2.6 |

教程说明
异形的遗迹机械。在战斗中会创造「淤泥涌口」，并在一些状态下试图从中汲取能量，以进行破坏力强大的攻击。

教程说明
利用「流明石触媒」的纯光绽放，破坏向遗迹巨蛇输送能量的淤泥涌口，可以打断这种状态，并使它分布在身躯上的能量核心失能。当4个能量核心均失能后，遗迹巨蛇会进入虚弱状态。
