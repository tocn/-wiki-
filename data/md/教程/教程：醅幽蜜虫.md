## 基础信息

| | |
| --- | --- |
| 名称 | 醅幽蜜虫 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 5.8 |

教程说明
与醅幽花共生，会帮忙培育醅幽花并吸取花蜜的乖巧蜜虫。
可以通过点按召唤以发出指令，将它们召唤到身边。

教程说明
在蜜虫被召唤到身边后，可以通过长按驱使技能并进行瞄准，以命令它们前往需要的方向收集养分。
在蜜酒的酿造过程中，可以依靠蜜虫将收集的花蜜送入酿酒装置之内；另外，在花田中也可以指挥蜜虫收集养分，让它们用养分滋润萎靡的醅幽花。
