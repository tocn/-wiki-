## 基础信息

| | |
| --- | --- |
| 名称 | 钓鱼 |
| 类别 | 系统 |
| 类型 | 永久教学 |
| 教程数目 | 6 |
| 实装版本 | 2.1 |

教程说明
若在某水域中看到水面波纹荡漾，说明此处是一个鱼群汇聚的钓鱼点，接近钓鱼点与之交互后开始钓鱼。
鱼儿的感知十分灵敏，如果靠的太近或者有攻击行为，会使鱼儿受到惊吓致其逃离，一段时间后鱼儿会恢复平静返回附近水域。

教程说明
每处水域生活的鱼类不尽相同，在钓鱼准备中可以查看此处出没鱼类，并挑选对应的鱼竿和鱼饵。
鱼饵的制作图纸可以从各地的钓鱼协会获得，学习后可在各地合成台制作鱼饵。
不同种类的鱼儿喜爱的鱼饵也不同哦。

教程说明
按住「甩竿」按键进入瞄准状态；松开「甩竿」按键将带有鱼饵的鱼钩扔出去。
若鱼钩落点离鱼太远，对鱼类的吸引力会大大降低。
若鱼钩落点离鱼太近，则可能惊吓到它们致其逃离。

教程说明
有鱼上钩时，请及时点击「提钩」按键，否则鱼儿会吃光鱼饵并逃脱。成功提钩后，鱼儿会进入挣扎状态。

教程说明
当鱼儿上钩进入挣扎状态时，旅行者可以通过按住和松开「钓鱼」按键来把鱼线张力控制在黄色的最佳张力区。只有在最佳张力区内，钓鱼进度环才会提升，反之则会下降。
钓鱼进度环升满时钓鱼成功。

教程说明
上钩的鱼儿有时会进入猛烈挣扎的状态，此时张力变化的速度会受到影响，张力区域也会变为橙色并抖动。
钩鱼进度降至最低时，鱼儿即将逃脱，此时张力区域会变为红色并抖动。
