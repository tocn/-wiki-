## 基础信息

| | |
| --- | --- |
| 名称 | 阿夏 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 3 |
| 实装版本 | 5.8 |

教程说明
在悠悠度假村附近活跃的奇特幻写灵，喜爱并擅长使用颜料，对于灵觉的亲和度也比其他地区的幻写灵更高，有时甚至可以依靠灵觉依附于其上。
此
时，可以向前扔出颜料弹进行攻击或进行喷涂，长按则会进入瞄准模式。

教程说明
阿夏可以进行一小段的快速位移，长按即可选定想要的方向进行位移。此外，如果长按跳跃，可以跳得更高。在空中，阿夏也可以长按瞄准想要投出颜料弹的方向，此时，阿夏会悬停在空中，直到再次进行跳跃退出悬停状态。

教程说明
阿夏可以随时切换可以投出的颜料弹的颜色。也可以切换出「擦除色」，可以用「擦除色」的颜料弹将原本喷涂的颜色擦去。
