## 基础信息

| | |
| --- | --- |
| 名称 | 雨阵奔流之述演 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 6 |
| 实装版本 | 5.6 |

教程说明
在挑战中，选择兵棋并放置在场地周围的部署区，可召唤出对应的交战单位，每次部署，根据兵棋的类型，可能召唤出单个兵棋，或由多个兵棋组成的小队。

教程说明
部署的兵棋将根据兵棋特性锁定目标并寻找一条路径进行攻击。近战兵棋遇到障碍物时会绕行，如果封闭空间外没有符合条件的目标，则将会尝试拆除木质拒马。远程兵棋若攻击距离足够，则可以越过障碍物进行攻击。

教程说明
当进攻方的兵棋击破防守方所有兵棋、设施（障碍物除外）后，则可赢得想定胜利。

教程说明
不同的兵棋拥有不同的特性，该特性可长按头像或通过综合情报进行查看，了解兵棋特性有助于更轻松完成推演。

教程说明
拖动头像即可预览兵棋的攻击目标。

教程说明
防守方的兵棋无法移动，当其攻击范围内有进攻方兵棋进入时，则会自动迎击。点击兵棋即可查看其攻击范围。
