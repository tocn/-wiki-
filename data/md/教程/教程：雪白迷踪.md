## 基础信息

| | |
| --- | --- |
| 名称 | 雪白迷踪 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 8 |
| 实装版本 | 月之三 |

教程说明
在「雪白迷踪」中，双方玩家将分别扮演「游侠」与「猎手」。

「游侠」需要躲避猎手的追捕，坚持到限定时间结束。

而「猎手」需要在限定时间内捕获所有「游侠」。

教程说明
「猎手」拥有更快的移动速度，体力消耗大幅降低，还可以使用强大的「猎手特技」探测对方位置和识破对方的伪装。
而「游侠」可以使用「游侠特技」伪装成当前地图内特定的物件，布置诱饵，或暂时进入隐形状态。

教程说明
游侠将受到寒冷值限制，寒冷值将随时间逐渐增长到达满值的过程中，该游侠将开始发抖，最终被封冻，被封冻期间，该游侠的位置将持续被猎手感知。封冻状态下连续快速点按按键可以破除封冻，并削减一定的寒冷值。

教程说明
场地中存在暖源，游侠可以将之开启。被开启的暖源将在一段时间内持续削减附近游侠的寒冷值，但也会在被开启时，点亮对所有人可见的小地图标记。

教程说明
游戏开启一段时间后，场上将出现暴风雪，暴风雪持续期间，游侠的寒冷值的增长速度将大幅提升，同时，双方的视野都将受到限制，且小地图上双方坐标信息都将被隐去。

教程说明
游戏过程中，场地内将随机降下「雪白眷顾」。
拾取「雪白眷顾」后，可为「雪白秘技」充能，这一强大的秘技足以左右胜负。

教程说明
被猎手捕获后，游侠将进入「游观者」状态，处于「游观者」状态中时，依然可放置「幻形信标」帮助游侠进行游戏。

教程说明
在本次「雪白迷踪」中，玩家可以单独或与其他好友共同参与的匹配游戏以获取「迷踪币」。若至多两名好友一起匹配游戏时，好友均会扮演游侠。

累积获取一定数量的「迷踪币」，即可解锁多种奖励。

四名玩家自行组队参与游戏，或是获取「迷踪币」的数量达到当前上限时，参与游戏将无法再获取「迷踪币」。
