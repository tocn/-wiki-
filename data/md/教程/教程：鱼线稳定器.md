## 基础信息

| | |
| --- | --- |
| 名称 | 鱼线稳定器 |
| 类别 | 冒险 |
| 类型 | 永久教学 |
| 教程数目 | 2 |
| 实装版本 | 3.0 |

教程说明
在各地的钓鱼协会兑换获取「鱼线稳定器」后，可以利用这一道具辅助钓鱼。
「鱼线稳定器」默认处于启用状态。旅行者可以自行选择启用或停用「鱼线稳定器」的辅助功能。

教程说明
旅行者在钓获某一种鱼类时，根据过去已钓获的该种鱼类的数量，「鱼线稳定器」将提供不同等级的辅助效果，诸如：在鱼线张力处于最佳张力区时，钓鱼进度的增长速度将获得一定的提升。
最佳状态的「鱼线稳定器」甚至能在鱼线张力位于最佳张力区外时依旧提供钓鱼进度的增长。
在「图鉴·生物志」中，可以查看已钓获的鱼类数量。
