## 基础信息

| | |
| --- | --- |
| 名称 | 龙龙同游 |
| 类别 | 冒险 |
| 类型 | 活动教学 |
| 教程数目 | 3 |
| 实装版本 | 月之二 |

教程说明
在挑战过程中，旅行者可以自由切换自身或龙伙伴进行操作。
此外，角色无法在挑战中使用技能或自身特殊的移动能力。

教程说明
龙伙伴能够利用自身能力通过诸多险要之地，而旅行者可以操纵机关开启通路。
若想通过挑战——收集冒险币并抵达终点，需要与龙伙伴默契配合，齐心协力。

教程说明
当旅行者或龙伙伴在挑战中遭遇失败时，可在建立过联系的复苏之门处重新出发。
此外，当旅行者与龙伙伴距离过远时，可通过复苏之门将龙伙伴召回。
