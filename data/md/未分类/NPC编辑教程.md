## 编辑准备：移除旧模板

首先请您阅读源代码，若源代码出现如下内容即代表此页面使用的是旧模板，然后清空整份内容准备重写：

```
<div class="row">
<div class="col-sm-8">
==对话==
*人：？？
{{剧情选项
|选项1=
|剧情1=
|选项2=
|剧情2=
}}
<!--添加：
|选项X=选项B
|剧情X=文本B-->
</div>
<div class="col-sm-4">
==相关剧情==
===任务===
{{人物出场|{{PAGENAME}}|任务}}
===活动===
```

如果阁下发现页面是新模板并且只是计划对页面进行小编辑，请直接编辑那一部分即可。

## NPC基本信息

阁下可以把光标移到需要修改的“=”后面，然后输入该项内容。

### 名称

1. 名称即为NPC头顶的白色部分。例如该NPC的姓名为快刀陈，该行代码即为：

```
|姓名=快刀陈
```

### 称号

- 通常角色姓名下方有一个<>，这个<>中间的文字即为称号。
- 例如：<小吃摊摊主>，输入的代码即为：

```
|称号=小吃摊摊主
```

### 性别

- 请在这里填写该NPC的性别
- 可用选项：`男`、`女`、`未知`
- 示例代码：

```
|性别=男
```

### 职业

- 请阁下根据NPC职业填写。
- 售卖东西的使用“商人”描述职业。做菜的使用“厨师”描述职业。
- 未知职业的请写：未知。
- 示例代码：

```
|职业=商人
```

### 位置

- 填写NPC所在的地理位置，使用地名，地名之间使用“·”连接，尽量不用方位词。
- 示例代码：

```
|位置=璃月港·吃虎岩
```

### 所属国家

- 您需要在此处填写NPC所属国家。
- 可用选项有：蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬、未知
- 所属国家未知的请填“未知”。
- 示例代码：

```
|所属国家=璃月
```

### 所在国家

- 您需要填写该NPC所处国家。
- 若该NPC含商店，则必须填写此项。
- 可用选项有：蒙德、璃月、稻妻、须弥、枫丹、纳塔、至冬、未知
- 示例代码：

```
|所在国家=璃月
```

### 所属组织

- 请根据游戏内对话与各种资料填写，也可填写工作单位
- 所属组织未知的请填“未知”。
- 示例代码：

```
|所属组织=八重堂
```

### 相关系统

- 请填写NPC相关系统
- 可用选项为：`委托`、`声望`、`活动`、`商店`、`烹饪`、`尘歌壶`
- 未知的话，请写：无
- 示例代码：

```
|相关系统=[[商店]]
```

### 对话赠礼

- 填写与NPC对话后会赠送的具体东西。

#### 如果NPC没有对话赠礼

- 请填写“无”
- 示例代码：

```
|对话赠礼=无
```

#### 如果NPC有一个对话赠礼

- 请按以下格式填写：{{NPC图标|物品名|数量}}
- 示例代码：

```
|对话赠礼={{NPC图标|暗铁剑|1}}
```

#### 如果NPC有多种对话赠礼

- 直接在后面插入{{NPC图标|物品名|数量}}，不要空格，也不要换行。
- 示例代码：

```
|对话赠礼={{NPC图标|暗铁剑|1}}{{NPC图标|摩拉|40}}
```

### 实装版本

- 填写与NPC的实装版本。
- 未知请填写“未知”。
- 示例代码：

```
|实装版本=2.0
```

## NPC商店

- - 商店内容的填写有比较高的格式要求，请仔细阅读。
- 商店内容整体格式为六列的表格，分别填写商品、商品价格、限购数量、刷新时间、限制条件。
- 商品填写方式： 物品名\*数量
- 商品价格填写方式： 货币名\*数量、货币名\*数量
- 商店内容每行格式要求：商品,商品价格,限购数量,刷新时间,限制条件+
- 不同内容之间之间采用 , 分隔（英文逗号），请勿添加多余的空格，末尾使用 + 结尾。添加新的一行需要另起一行书写。
- 最后一行表格末尾不要使用 + 结尾。
- 填写示例： 甜甜花\*1,摩拉\*50000、原石\*100,3,周二/周五4:00,冒险等阶45+

帮助我理解展开/折叠

- 示例代码：

```
|商店内容=鸣川鹈饲*1,花鳉*20、琉璃花鳉*20、肺棘鱼*20、流纹京紫蝶鱼*20,1,无,无+
「渔获」*1,雷鸣仙*6、金赤假龙*20、锖假龙*20,1,无,无+
赤穗酒枡*1,雷鸣仙*3、炮鲀*10、苦炮鲀*10,4,无,无
```

## 对话

### 若NPC没有对话

- 这种情况下，请阁下在存在对话一栏填“否”并删除如下内容：

```
|对话内容={{NPC对话
|标题=
|内容={{NPC剧情
|选项1=
|选项1图标=
|剧情1=
}}
```

示例代码：

```
|存在对话=否
```

### 若NPC存在对话

- 请阁下先在存在对话中填“是”。
- 标题一栏视情况填写，如果NPC有多个对话，请在标题栏写触发条件，如果只有单个对话，请写“日常对话”即可。
- 注意：请不要在NPC图鉴中收录活动剧情。活动剧情需要单独写在活动详情中
- 将光标移动到{{NPC剧情前，这里要写的是跟NPC对话时NPC打招呼的内容。示例如下：

```
|标题=日常对话
|内容=*快刀陈：新鲜热乎的吃虎鱼！尝尝吧，便宜！
```

- 打完招呼以后通常会有对话选项供旅行者挑选，旅行者首先要记录选项中旅行者说了什么。
- 然后旅行者要选择一个对画图标，可供选择的有：
- Talk
- Store
- Gift
- Activity
- 这四个分别对应着日常对话、商店、赠礼、活动。
- 然后就是填写该分支的剧情了，要求和对话内容一致。
- 按照此标准填完所有分支。

```
|选项2图标=Gift
|剧情2=*快刀陈：千八百条吧大概，拍着胸脯说，我家的吃虎鱼绝对是璃月最地道的…
*快刀陈：…因为城里至少一半的烤鱼都是从我这儿买的，我家不地道谁地道呢？哈哈哈…

*快刀陈：唉，提起师门，多少还是会有些怀念的，也不知道师父和师弟、师妹他们现在在做什么…
```

### 待机语音

- 先打出待机语音内容，然后再打出一个`%`，继续输入NPC头顶气泡内容，然后输入`+`。
- 最后一个待机语音时请删除+。
- 示例代码

```
|待机语音=新鲜热乎的吃虎鱼咯！%新鲜热乎的吃虎鱼…
```

- 如果该NPC无待机语音，请直接删除“待机语音”这一行。

### 心声

- 在待机语音后填写

```
|心声=（心声内容）
```

## 出现地点

- 具体格式为：{{NPC位置|出现时间|显示方式|显示方式具体数据|具体位置图片名}}
- 出现时间有三个选项：`白天`、`夜晚`、`全天`。
- 显示方式可以选地图或者图片
- 若想要用嵌入式地图显示NPC位置，请填写地图
- 若想要用图片（游戏地图截图）显示NPC位置，请填写图片
- 显示方式的具体数据根据上一项所填数据来
- 地图：填入NPC坐标
- 图片：填入图片名称，不要加文件扩展名
- 具体位置图片名一般为<NPC名>位置，不需要加入扩展名，例：黑田位置
- 示例代码：

```
|出现地点={{NPC位置|出现时间：全天|地图|1494.976806640625, -505.5, 4|快刀陈位置}}
```

获取NPC坐标教程

- 打开浏览器，在地址栏输入https://wiki.biligame.com/ys/原神地图工具\_全地标位置点

- 下拉网页到地图，连续点击三次搜索框，此时地图右下角会多出选项卡，选中“坐标”。

- 此时点击要获取坐标的位置，会弹出一个气泡，括号内即为坐标信息。

该图片中，坐标为1494.976806640625, -505.5。

- 2025.10.17后的地图版本，需要在坐标后方添加第3个数值4。

## 上传文件

2022-05-27 下午04:37更新：您无需上传这些文件，我们在收到NPC图鉴编辑记录以后会补全所需图片
一个NPC需要如下三个文件：

1. 头像：这是NPC图鉴会调用的缩略图，文件名应该为NPC名+文件扩展名（例：黑田.png），其大小要求为125像素×125像素。
2. 建模：正文头像以及大头照会共用此文件，文件名为NPC名+建模+文件扩展名（例：黑田建模.png），其大小要求为240像素×500像素，亦可上传1000像素×480像素的版本。
3. 位置：记录下NPC以及附近的环境，文件名为NPC名+位置+文件扩展名（例：黑田位置.png），其没有大小要求，但推荐为1920像素×1080像素。（推荐图片长宽比16:9）

请阁下注意：服务器最大允许的文件大小为8MB。

### 截图教程

截图简要教程

1. 找到相关NPC。
2. 将时间调到对应时间，如果NPC脸上存在明显阴影可能需要继续调节时间，直到NPC脸上没有明显阴影。
3. 切换到与NPC身高相近的角色，站在NPC附近。
4. 打开拍照，选择左上方第一个按钮，进入拍照设置，将人物隐藏。
5. 将缩放调到最大（左边缩放条在最下面）。
6. 使用WASD、鼠标滚轮和鼠标拖动调整角度和大小。
7. 按照大小规范截图。

## 图片相关规范

### NPC头像

命名规范：直接使用NPC的名称，如提米使用 提米.png。
大小规范：250×250像素或125×125像素。
图片要求：

- 时间尽量在白天拍摄（6:00-18:00）。错误示范：
- 面部无明显阴影。错误示范：
- 面部大小适中。错误示范：

### NPC建模

命名规范：使用NPC的名称后面加上“建模”二字，如提米使用 提米建模.png。
大小规范：240×500像素或480×1000像素。
图片要求与NPC头像类似。

### NPC位置信息图片

位置信息一组包含两张图片，分别显示NPC地图中的位置和具体位置。

**地图图片**

命名规范：格式使用 NPC-地图位置-(NPC名称)-(具体情形)，如提米白天出现位置使用 NPC-地图位置-提米-白天.png。
大小规范：1920×1080像素或1920×1200像素（直接截取整个游戏窗口）。
请把地图缩放到最大（左侧缩放条在最上面），再进行截图标识。
关于地点标识可以用自己的方式来，部分NPC会移动，可以绘制移动路线在图上。

**具体位置**

命名规范：格式使用 NPC-具体位置-(NPC名称)-(具体情形)，如提米白天出现位置使用 NPC-具体位置-提米-白天.png。
大小规范：1920×1080像素或1920×1200像素（直接截取整个游戏窗口）。
图片无特别要求，能够在图片中明显看到对应NPC即可。
