**不知道怎么编辑wiki？WIKI基础教程、功能教学**

## 功能类

### B站视频引用

调用参数说明：

```
{{B站视频|av号或bv号|分P号|视频名称|宽|高}}
```

必填项目：

- av号：全数字av号或bv号只填一个
- bv号：英文大小写和数字av号或bv号只填一个

选填项目：

- 分P号：默认不填即为1
- 宽 高：默认不填为638\*359

### 网易云音乐调用

基础：

```
{{网易云音乐|id=网易云id}}
```

小尺寸：
`类型=歌单`或`类型=专辑`或`类型=电台歌单`时无效

```
{{网易云音乐|小|id=网易云id}}
```

自定义宽度：
普通和歌单默认值为310，小尺寸默认值为278

```
{{网易云音乐|id=网易云id|宽度=200}}
```

歌单：

```
{{网易云音乐|类型=歌单|id=网易云id}}
```

专辑：

```
{{网易云音乐|类型=专辑|id=网易云id}}
```

电台：

```
{{网易云音乐|类型=电台|id=网易云id}}
```

电台歌单：

```
{{网易云音乐|类型=电台歌单|id=网易云id}}
```

自定义高度：
只有`类型=歌单`或`类型=专辑`或`类型=电台歌单`时有效，默认值为430

```
{{网易云音乐|类型=歌单|高度=600|id=网易云id}}
```

## 活动计时模板

### 参数

说明：
用于计时的模板，会自动判断活动开始和结束的时间显示文案。

```
{{活动计时|填写活动名字，活动等|开始时间（精准到秒）|结束时间（精准到秒）}}
```

使用案例：

| 你输入的内容 | 你看到的显示 |
| --- | --- |
| 当实际时间处于填写的时间范围时 ``` {{活动计时|活动|2020/09/25 12:00|2021/09/25 20:00}} ``` |
| 当实际时间超过填写的时间范围时 ``` {{活动计时|活动|2019/09/25 12:00|2019/09/25 20:00}} ``` |
| 当实际时间未到填写的时间范围时 ``` {{活动计时|活动|2021/09/25 12:00|2021/09/25 20:00}} ``` |
| 当需要自定义活动名字时 ``` {{活动计时|自定义|2020/09/25 12:00|2021/09/25 20:00}} ``` |
