| 点位类型 | 备注 |
| --- | --- |
| 丘丘人 | 不打普通丘丘人和射手丘丘人。 |
| 史莱姆 | 按富集点标注，小史莱姆算1，大史莱姆算2，大于等于5为富集点。 |
| 宝箱 | 所有宝箱都要打点，与之对应的机关也要打点，为了宝箱数量与视频攻略的宝箱数量能对得上 |
| 怪物 | 可以考虑用富集点标记，不要求每一个都打点。 |
| 怪物营地 | 每一个怪物营地里有什么怪，有几只，可以标注一下，其他怪物同理 |
| 愚人众 | 一群一点。 |
| 机关 | 一套机关只标记一个位置，其他机关一定要在备注里写明是什么；带有宝箱的机关在备注中注明宝箱的id，有机关的宝箱在备注中注明机关id |
| 树莓 | 多个存在于一处的，只打一个点 |
| 武士 | 一群一点。 |
| 点火机关 | 篝火只记录雪山里取暖用的，其他的都算点火机关 |
| 特产 | 可以考虑用富集点标记，不要求每一个都打点。 |
| 盗宝团 | 一群一点。 |
| 篝火 | 篝火只记录雪山里取暖用的，其他的都算点火机关 |
| 素材 | 可以考虑用富集点标记，不要求每一个都打点。 |
| 草实 | 多个存在于一处的，只打一个点 |
| 调查点 | 只记录可重复调查的 |
| 雷立方体 | 多个存在于一处的，只打一个点 |
| 雷霆指针 | 多个存在于一处的，只打一个点 |
