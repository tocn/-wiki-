## 地图图标本地修改方案

#### 前言：本方法修改的是本地css,页面刷新后就会消失

对着图标点击右键，选择检查(Q)部分浏览器可能是审查元素(N)：

然后在弹出里找到：

```
#map-wrap #map-menu .markerList .orderItem .items-wrap .catTit .list-img {
width: 20px;
padding-right: 12px;
margin-top: -3px;
```

修改为：

```
#map-wrap #map-menu .markerList .orderItem .items-wrap .catTit .list-img {
width: 40px;
padding-right: 2px;
margin-top: -23px;
```

本地样式修改完成后效果：
