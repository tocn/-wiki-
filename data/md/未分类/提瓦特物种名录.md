| 汐藻 | 随波逐流的藻类，依靠其他植物释放出的养分维持自身存在。虽然经常会被误解成浮游动物，但本质上其实是浮游植物。根据记载，古代的哲学家们曾盛赞汐藻的存在，称其为「凡世间最高贵的生灵」，因它「虽是拥有自由意志的动物，却不依靠吞噬生命来维持自身存续」。这样的赞誉最终伴随着生物知识的发展而消失了。 出处：游戏已实装 |

| 树王圣体菇 | 如云海般层层叠叠生长的菌类，大多寄生于雨林深处的乔木之上，因此被须弥人视为树王遗德熏结而出的圣体。 在须弥，森林中的居民有着向教令院贡奉树王圣体菇的传统，但这些贡品的用途却不为世人所知。据某些逸话中说，教令院每年会在净善宫进行秘密的仪式。在仪式上，贤者们会通过食用树王圣体菇的方式来纪念树王的牺牲。 出处：游戏已实装 |

| 微光角菌 | 在黑暗中微微发出光芒的菌类，因为形似暝视龙的角冠而被称为角菌。 出处：游戏已实装 |
| 红果果菇 | 看似形态普通，风味却相当特殊的蘑菇，只会生长于瓦雷莎家的果园附近。既然派蒙取下了很可爱的名字，说明味道深得她心。 出处：游戏内已实装 |
| 绿果果菇 | 看似形态普通，风味却相当特殊的蘑菇，只会生长于瓦雷莎家的果园附近。听说生长能力很强，如果遇见必须马上吃掉。 出处：游戏已实装 |
| 锦葵筑锋菇 | 「锦葵红色」的庞大菌菇，生存能力顽强，表面的质感特殊，富有弹性的同时，还能长期保持潮湿。 出处：锦葵筑锋菇 |
| 沙褐穹窿菇 | 生有厚重菌盖的菇类，形如某些房屋的弧形穹顶，因此被称为「穹窿菇」。 出处：沙褐穹窿菇 |
| 曦红摇曳菇 | 形姿奇异的菇类，呈现出浓重的「曦红色」。菌柄有着与纤细外表不符的坚韧特性。 出处：曦红摇曳菇 |
| 杏黄枯叶菇 | 菌盖宽大的菇类，在阳光映照下，以明艳的「杏黄色」为人们所熟知，独特的纹路和菌褶如同枯叶，亦有「枯叶菇」的别称。 出处：杏黄枯叶菇 |
| 铁棕林立菇 | 挺拔高大的菇类，菌盖呈现出特别的「铁棕色」。它们直立的形貌相仿于树木的，又具备丛生的特性，因而得名「林立菇」。 出处：铁棕林立菇 |
| 无 | 「一头菇」 | 兰那罗烹饪修行的料理材料之一。 出处：料理是自然的风味 |
| 弹弹菇 | 三相眾物之一，在上面可以跳很高。此菇下方白色菌丝上其实有两对眼睛，两对眼睛都会睡觉，游戏时间晚上时眼睛会睡觉，两对睡觉的时间不同，睡觉时是看不到白色菌丝的眼睛的。在早上眼睛因为还没清醒所以颜色较浅，两对眼睛清醒的时间也不同。若烧它，菌丝会直接消失，用草再打一次可以让它复甦，再用雷产生激化反应在上面跳的高度会增加。 出处：大世界须弥 |
| 蕈兽 | 拥有一定智能的孢子生物，具有强大的环境适应能力。 出处：游戏内已实装 |
