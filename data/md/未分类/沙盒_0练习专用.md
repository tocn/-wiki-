## 角色配装推荐

- 一
- 二

| | |
| --- | --- |
| 圣遗物套装 | 4件套 追忆之注连 或 4件套 来歆余响 +任意散件 |
| 套装推荐理由 | 强化E期间普攻伤害 |
| 主词条推荐 | 【沙】攻击力 或 元素精通（配合行秋双雷打反应且精通沙副词条远优于攻击沙时） 【杯】火元素伤害 或 攻击力（伤害词条过高或攻击杯副词条远优于火伤杯时） 【头】暴击伤害 或 暴击率（副词条的暴击率很拉胯或伤害词条过高时） |
| 副词条推荐 | 暴击率＝暴击伤害≥攻击力＞元素精通＞充能 |
| 词条推荐理由 | 宵宫自身突破加暴击率，因此优先推荐通过副词条满足暴击率需求，帽子主词条选择暴击伤害；或副词条爆伤占比较大时，帽子主词条选择暴击率。当宵宫配合行秋、双雷打反应时可以考虑兼顾元素精通。由于宵宫自身的词条在一般情况下会比较雨露均沾（自身突破加暴击，天赋、圣遗物与武器提供大量增伤，最适配的两个四星武器均为攻击+增伤词条），因此应当根据自身实际情况选择，遵循稀释最小化的原则，缺啥补啥。使用破魔之弓时可以考虑兼顾充能效率以满足武器词条要求。 |
| 技能升级推荐 |
| 推荐理由 |
| 毕业武器 | 飞雷之弦振 |
| 推荐理由 | 副词条为暴击伤害，与自身突破词条完美搭配；装备追忆四件套时，开E后一次普攻即可获得三层巴印；三层印可持续10秒，刚好E结束开大退场，非常适合宵宫。 |
| 可选武器 | 天空之翼 阿莫斯之弓 弓藏 |
| 推荐理由 | 五星武器的白值较高。天空弓副词条兼顾暴击爆伤，阿莫斯均衡增加普攻和重击伤害。但二者的技能都不能被宵宫很好利用。宵宫附魔后平A的输出模式契合弓藏。高精弓藏可以碰瓷低精的天空/阿莫斯。 |
| 可选武器 | 破魔之弓 试作澹月 |
| 推荐理由 | 破魔之弓兼顾普攻伤害与重击伤害，技能要求兼顾充能效率词条或搭配雷主等快速充能角色，对4追忆适配性较差。试作澹月需要先瞄一次要害（无须蓄力满），怪物无要害时比较疲软。同时作为锻造武器容易满精，技能上有所提升。 |
| 可选武器 | 风花之颂 黑岩战弓 弹弓 |
| 推荐理由 | 勉强能用的水平。风花弓缺点为加攻击力的效果不能全程覆盖，黑岩弓的缺点为需要造成击杀才能触发。可以考虑三星的弹弓，牺牲白字和作战距离换取两个蛮适合宵宫的词条。都这水平了不是真爱建议换个C用 |

| 圣遗物套装 | 4件套 炽烈的炎之魔女 +任意散件 |
| 套装推荐理由 | 搭配行秋打不俗的蒸发伤害，同时可以用大招当副C使用。没有追忆4时其他人那扒下来凑合用 |
| 主词条推荐 | 【沙】攻击力 或 元素精通（配合行秋用） 【杯】火元素伤害（没有火伤杯就用攻击力） 【头】暴击伤害（没有就用暴击头） |
| 副词条推荐 | 暴击率＝暴击伤害≥攻击力＞元素精通＞充能效率 |
| 词条推荐理由 | 突破带暴击，副词条有暴击就可以。其它只要不是防御生命都是好词条 |
| 技能升级推荐 |
| 推荐理由 |
| 毕业武器 | 飞雷之弦振 |
| 推荐理由 | 爆伤弓谁不喜欢。 |
| 可选武器 | 天空之翼 阿莫斯之弓 弓藏 |
| 推荐理由 | 五星＞四星，天空之翼双爆属性谁都能用，痛苦弓攻击高武器技能也凑合，弓藏完美契合输出方式且四星相对容易出。 |
| 可选武器 | 试作澹月 破魔之弓 |
| 推荐理由 | 锻造武器容易满精炼。不掉原胚可以忽略这些武器 |
| 可选武器 | 风花之颂 黑岩战弓 宗室长弓 |
| 推荐理由 | 四星弓里属性比较好的，凑合过也可以。最大缺点就是获取难度高，活动武器错过就要等好久了 |
