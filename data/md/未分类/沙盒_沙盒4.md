## 角色分析

| | |
| --- | --- |
| 刻晴 | 综合评价：S+ |
| 主力输出 | 除了反应体系外也可以打超导物理流混伤体系，但个人感觉不如自身的反应体系，也不如雷泽体系，而且无论是配合温迪的大招的聚怪扩散超载，还是翠绿之影（风套）带来的减抗都提升了雷反应C的地位。目前一般只推荐在开荒期使用物理流刻晴。 |
| 元素反应工具人 | 大招脱手，勉强也能承担提供元素的任务。 |
| 探索 | 瞬移，无论是赶路还是收集风/岩神瞳都非常好用。 |

| | |
| --- | --- |
| 莫娜 | 综合评价：S+ |
| 主力输出 | 倍率还算可观，但输出曲线不够平滑，在没有大招的时候输出不高。适合作为大招流速切反应副C。 |
| 元素反应工具人 | 小技能能持续提供元素。 |
| 进攻型辅助 | 小技能带嘲讽。大招附带4秒易伤，易伤比例还随着技能等级上升，唯一的缺点是持续时间过短。推测是独立乘区的情况下，在后期对于伤害加成是非常恐怖的。 |
| 探索 | 特殊冲刺方式，无论是过河还是赶路都相当好用。 |

| | |
| --- | --- |
| 温迪 | 综合评价：S+（基于三测强度推测） |
| 主力输出 | 虽说一般不会把温迪作为主C考虑，但扩散伤害还是相当可观的。 |
| 元素反应工具人 | 扩散可以配合挂元素辅助反应。 |
| 进攻型辅助 | 小技能和大招的控制、聚怪、扩散，配合圣遗物套装翠绿之影的减抗。螺旋中永远的神。 |
| 探索 | 垂直起飞，探索、爬山的不二之选。弓箭角色可打猎。风扇解谜。 |

| | |
| --- | --- |
| 迪卢克 | 综合评价：S+ |
| 主力输出 | 版本之子，火魔女套的完美使用者。 本身火元素属性角色就是版本之子，无论是蒸发还是融化反应，只要由火元素角色触发就是火元素伤害，能完美吃到火元素伤害加成、元素精通、以及自身攻击力、暴击率、暴击伤害带来的加成。 卢老爷的三段e能完美触发火魔女套，且q带来的火元素附魔在四次突破延长到12秒后几乎全程覆盖。 无论是打蒸发还是融化反应体系还是超载体系，强度都很高。 |
| 探索 | 挖矿/大剑锻造工具人 |

| | |
| --- | --- |
| 可莉 | 综合评价：S+（基于三测强度推测） |
| 主力输出 | 输出爆炸。作为法系角色，本身普攻即可触发反应，小技能又能储存次数且是多段伤害。大招需站场，自动攻击不影响可莉本身输出以及闪避。天赋带来的免体力消耗额外伤害重击在站桩输出中挺好用的。她需要的只是帮她聚怪、减抗、持续提供元素的工具人们。 |
| 元素反应工具人 | 小技能留下的诡雷可以在切人后仍然提供元素，但大招需要站场，无法脱手。 |
| 探索 | 炸矿、炸鱼。 |

| 元素反应工具人 | 大招可以挂元素。 |

| 探索 | 显示周围特产。 |

| --- | --- |
| 雷泽 | 综合评价：S |
| 主力输出 | 目前最强势的4星输出之一，主要伤害来自于物理伤害，几乎没有因为元素属性导致雷泽完全打不了的敌人。超导反应的改动、自身命之座带来的减防、突破带来的物理伤害加成、q带来的攻速提升和抗打断都极大地增强了雷泽的物理输出能力。 主要伤害靠超导后开q平a输出，e的充能也使得雷泽的回转速度相当可观。 简单的雷泽超导物理体系相当亲民，只需要雷泽+凯亚就行。甚至对凯亚的练度没有要求。 复杂点可以搭配超载、感电体系，在超导后，切工具人脱手提供元素，切雷泽开q平a输出，也能频繁触发元素反应。由于雷泽的高攻速，多半是由雷泽挂上元素，工具人触发反应。在工具人堆叠等级和元素精通后，伤害也是相当可观的。 注意：雷泽和任何附魔类辅助（重云、满命班尼特）都不搭，附魔会导致雷泽的普攻转变为对应元素伤害，吃不到自己的物理伤害加成以及减防的收益。 |
| 探索 | 减少冲刺体力、挖矿工具人。 |

| 元素反应工具人 | 扩散。 |

| 香菱 | 综合评价：S- |
| 主力输出 | 虽说公测削了锅巴的cd，现在有了大概5秒左右的真空期。但香菱作为白给角色，在没有其他适合作为主C的角色的情况下，也是最适合承担主力输出位置的人。 除了如同其他火元素角色一样的反应体系外，收益于长柄武器的高攻速和4星锻造武器流月针的词缀，流月针香菱混伤体系也是一个不错的选择。 不带增加普攻伤害和重击伤害词条，流月针词缀的特效吃不到这个加成。 叠攻击力、暴击率、爆伤（理论上来讲平均分配收益最高）就行了。 实际想达到最大收益还需配合超导减防，那么队伍基本锁定三个位置，最后多半再上一个火凑双火25%常驻攻击力buff元素共鸣。 配合水/冰可以打蒸发/融化物理混伤流。 可以考虑搭配重云，带征服寒冬的勇士（冰抗套），理论上来讲配合重云附魔，可以冰元素普攻、火元素技能融化全程享受到35%的伤害加成。（云出来的，得实测） |
| 元素反应工具人 | 目前除了满命班尼特外，唯一也是最好的火元素反应工具人，小技能大招双脱手。 |
