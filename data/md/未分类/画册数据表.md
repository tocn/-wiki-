在此编辑画册CG的信息
格式：

```
{{#subobject:画册_CG类别_CG名称【全局唯一名】
|CG名称=【必填，不用加png后缀，例：战场之上】
|CG类别=【必填，选一个填：【主线剧情】【隐藏剧情】【外篇剧情】【外篇隐藏】【间章剧情】【过场相关】【活动剧情】【涂装相关】【联动】【同人CG】】
|文件名称=【选填，如果不填则文件名称与CG名称一致，不带png后缀】
|排序=【排序数字，用于画册的检索排序，各类别独立计数，从0001开始，按照组内的画册文本表格排序】
|描述=【CG的文本描述】
}}
```

例：

```
{{#subobject:画册_概念原画_风起地
|CG名称=风起地
|CG类别=概念原画
|文件名称=
|排序=0001
|描述=Text
}}
```

注：编辑本页面后，等待自动刷新的周期会比较长。如需要立刻生效，请手动点本页面的【WIKI功能-刷新】。
