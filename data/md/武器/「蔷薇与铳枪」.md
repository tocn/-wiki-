### 参与条件

冒险等阶≥20级
且完成魔神任务序章·第三幕「巨龙与自由之歌」
※完成魔神任务第四章·第五幕「罪人舞步旋」、雷电将军传说任务「天下人之章 第二幕」、芙宁娜传说任务「司颂之章 第一幕」后体验更佳。

### 活动说明

- 活动期间，将陆续解锁「千步拦射角分间」、「幻光奇技实录」、「极限驱策法」、「巧像入帧」各阶段玩法。
- 「千步拦射角分间」玩法中，旅行者需要利用模拟装置，操控铳枪击败敌人，完成射击挑战。
- 「幻光奇技实录」玩法中，旅行者需要借助「特技光效」，在影棚之中进行战斗击败敌人并获得评分。
- 「极限驱策法」玩法中，旅行者需要与朋友们比赛追逐争夺「稳像机械球」，尽可能赢得更高的积分。
- 「巧像入帧」玩法中，旅行者将会挑战独特的摄影剪辑试炼。通过拍摄不同角度的映影片段并将其剪辑，以完成映影的创作。
- 完成各个玩法，可获得「剧戏票券」。收集指定数量的「剧戏票券」可获取「究极霸王超级魔剑」及其精炼材料，同时还可以获得原石、智识之冕、大英雄的经验、精锻用魔矿等奖励。
- 完成各个玩法，可获得「逸趣映片」。使用「逸趣映片」可以在活动商店中兑换角色天赋素材、武器突破素材、精锻用魔矿和摩拉等奖励。

## 玩法教学

| | |
| --- | --- |
| 千步拦射角分间 | 在「千步拦射角分间」挑战中，旅行者需要使用特殊光学目镜，瞄准并射击敌人。 按下「瞄准」按钮，即可进入瞄准状态。瞄准敌人后，按下「射击」按钮便可向目镜瞄准之处发射子弹射击敌人，击败情景中的所有敌人即可完成挑战。 |
| 在部分演练情景下，弹药的数量会受到限制，旅行者需要利用有限的弹药击败所有敌人。 |
| 在部分演练情景下，会出现高价值目标，旅行者需要在保护高价值目标的同时击败所有敌人。 |
| 通过调整「设置」界面下「控制」中的「镜头水平灵敏度（瞄准模式）」和「镜头垂直灵敏度（瞄准模式）」，可以改善模拟射击的操纵性。 |
| 幻光奇技实录 | 在「幻光奇技实录」中，需要在限定时间内击败不断出现的敌人以获得评分。挑战结束后，将依据评分获得相应级别的奖章。在挑战开始前，可以根据不同「特技光效」，调整上阵队伍的阵容。 |
| 挑战过程中，击败敌人即可为「特技光效」积累准备的进度。「特技光效」准备就绪后，可以在合适的时机主动施放。激活的「特技光效」将在一定时间内提供强大的战斗增益。充分利用「特技光效」，即可更高效地完成挑战。 |
| 极限驱策法 | 「稳像机械球」会自动躲避测试员，朝测试员接近自己的反方向运动。 |
| 「稳像机械球」的移动会受到所有测试员的影响。 |
| 利用这一特性，在限定时间内尽可能将更多「稳像机械球」驱赶到自己的目标区域中。 |
| 除了「普通稳像球」，场上也会出现「华丽稳像球」。 一个「普通稳像球」记1分，「华丽稳像球」记7分。 |
| 测试场上会出现跳跃助益。拾取后可以进行更高更远的极限跳跃，有益于迅速转移至「稳像机械球」的另一端，请妥善利用。 |
| 测试将在五种不同的场地中随机选择一种展开。 |
| 巧像入帧 | 在「巧像入帧」玩法中，需要根据导演的各项需求拍摄多个镜头，将它们组合成一段映影。 拍摄时，首先需要确认机位需求，选择合适的拍摄机位。 |
| 部分镜头还存在旁白需求，需要根据故事，选择最贴合需求的旁白。 |
| 所有镜头的机位和旁白都选择好后，可以开始拍摄，查看效果。 根据实际拍摄与导演需求的贴合程度，映影将获得不同的评分，尽量满足各项需求，获取较高的评分以赢得奖励。 |

### 极限驱策法

欢快的节庆之时，也有映影行业的相关人士愁眉不展，你与派蒙就在会场附近找到了一位倒霉的乙方员工…

**稳像平台测试场**
由伊莲精心挑选的无人秘境，临近城区且空旷平整。在这里，基于「稳像平台」的「稳像机械球」将迎来属于它的极限测试…

### 巧像入帧

年轻而才华横溢的导演小露米埃尔先生向你们递来了「名片」，他对映影的技法似乎有着独到的见解…

**地图描述**
小露米埃尔导演选择的拍摄地点，有着最符合拍摄主题的环境，能让映影工作者充分尝试多种镜头与台词的处理方式，高效完成短篇映影的拍摄，进而充分感受映影的魅力…

#### 太阳的方向

在水下迷失道路的演员（琳妮特饰）在水草间四处游动却找不到方向。当她抬头向上看，透过水面，太阳的光芒照亮了她的脸，为她指引了前进的道路。

#### 烈日下的等待

烈日炎炎之下，主角（娜维娅饰）正在等待与自己的朋友（派蒙饰）会面，后者难以忍受酷晒，无精打采地出现在了主角的视野中。主角拿出准备好的遮阳伞与墨镜，示意朋友一同躲避太阳。

#### 一场交易

来到枫丹的烟花商（宵宫饰）与客户（里凯蒂饰）相约在德波大饭店商谈销售事项。仔细考察过样品后，客户认可了烟花商的产品，二人达成交易。

#### 瞬间留影

在枫丹廷街头一角架起了留影机的演员（夏洛蒂饰）正在挑选合适的角度，以便拍下能一览枫丹廷全部美景的画片。在心中比对了几个不同的角度之后，她做出了决定。
