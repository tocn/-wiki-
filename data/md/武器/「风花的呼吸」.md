### 活动说明

- 活动期间，将陆续解锁「风物之歌」、「万风逐花」、「风物留影」各阶段玩法。
- 「风物之歌」玩法中，旅行者可以参与乐曲演奏。演奏过程中，屏幕上会出现不同的音符，根据一定节拍触击音符，可获得不同等级的得分。
- 「万风逐花」玩法中，旅行者可以体验由蒙德冒险家协会推出的新式游戏「逐花棋」。在棋局中依靠不断搜集「风花球」来提升评分，完成相应挑战。完成挑战后可获得活动专属武器「双手剑· 饰铁之花 」。
- 「风物留影」玩法中，旅行者需要帮助冒险家法斯宾制作画册，在蒙德各处留影。
- 在「风物之歌」玩法中，旅行者也可自行编曲，完成编曲后可前往「乐曲交流」投稿分享自己的编曲，或者从中获取其他优秀编曲分享码。
- 完成各个玩法，可获得「 逐花券 」和「 庆典券 」，可在活动商店内兑换智识之冕、活动专属武器精炼材料等奖励。
- 活动结束后，「逐花券」和「庆典券」将会消失，请旅行者及时兑换奖励。

## 玩法教学

玩法教学一览

| | |
| --- | --- |
| 万风逐花 | 在开始「万风逐花」挑战后，旅行者需要不断搜集「风花球」以提升评分，在当前区域搜集到一定数量的「风花球」后，下一个区域才会开放。 在最后一个区域中，当旅行者搜集到一定数量的「风花球」后，「风逐花环」将会出现，旅行者可以触摸此花环，结束本局挑战。 |
| 在挑战区域中，存在着不断追逐旅行者的「拟像气球」，旅行者需要躲避「拟像气球」的追逐。如果被「拟像气球」追逐到，则会失去一个「逐风点」，并被送回当前区域的开始点。 |
| 「风花球」和「拟像气球」都会显示在左上角的小地图中，旅行者可以调整小地图的显示大小，以及小地图的旋转方式。 |
| 在单人游戏状态中，可以进行联机匹配挑战。在多人游戏状态中，可以邀请队伍中的一名玩家共同进行挑战。 |
| 风物之歌 | 演奏过程中，屏幕上会出现不同的音符，当音符掉落至判定线位置时，触击判定线即可得分。根据你触击的时机，可获得不同等级的得分。 |
| 代表长音音符呈长条状，需长按演奏键位，直至光条下落结束后松开，方可得分。 |
| 风物留影 | 旅行者需要装备「留影机」，与留影点交互后进入留影模式。 留影分为留影设置调整阶段，和可以移动以及施放技能的留影阶段。 |
| 在留影点位调整阶段，旅行者首先需要选择一个留影设置，并可以在此设置的基础上继续调整留影的位置和角度。 需要注意的是，留影点需要在留影范围内。确认留影设置后，进入留影阶段。 |
| 在留影阶段，当旅行者使用「留影机」拍摄画片时，画片完成时的角度将由之前所调整的留影设置决定。 在留影过程中，留影的方向会由「留影射光」指示。 |
| 若想重新调整留影设置，也可以点击中断挑战，选择回到预设重新调整留影设置。 完成留影后，若想继续以当前的留影设置继续进行留影，可点击继续留影回到留影阶段。 |
