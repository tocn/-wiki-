活动期间，协助万端珊瑚侦探社完成「小动物大量失踪奇案」调查，即可获得原石、大英雄的经验、武器突破素材等奖励。

## 活动时间

2021/12/07 10:00 ~ 2021/12/20 03:59

## 参与条件

冒险等阶≥30级
且完成魔神任务「不动鸣神，恒常乐土」

## 活动说明

- 活动共有四个阶段，活动阶段为递进关系，前一阶段全部目标完成后，才可开启后续阶段的内容。
- 活动期间，旅行者可前往各处调查点进行案件调查，通过潜行或战斗的方式解救失踪的小动物。潜行过程中可使用小道具「四方之网」解救小动物。
- 装备「四方之网」进入「调查点·遁藏之地」后，使用「四方之网」，捕捉技能会取代「元素战技」，该技能可按住进行瞄准。若该技能命中「调查点·遁藏之地」中被标记的小动物，可顺利将其解救。
- 「调查点·遁藏之地」中，会有战斗力异常强悍的幻犬分身在各处巡逻，如被发现则会遭到攻击，注意观察幻犬分身的目光朝向及时躲避，可避免被其发现。旅行者也可使用调查点中的机关巧妙避开幻犬分身的目光。
- 2021/12/20 03:59活动结束后，「四方之网」将会消失。

## 活动玩法

### 玩法教学

| **玩法教学** |
| --- |
| 靠近触发点后，「调查点·遁藏之地」挑战开启；若在完成挑战前离开挑战区域，则保留挑战的进度并暂离挑战。 |
| 装备「四方之网」进入「调查点·遁藏之地」后，使用「四方之网」，捕捉技能会取代「元素战技」，该技能可按住进行瞄准。 若该技能命中「调查点·遁藏之地」中被标记的小动物，可顺利将其带走。 |
| 等待解救的小动物们分散在「调查点·遁藏之地」中不同的位置，开始前最好先观察并确定好所有小动物的方位。 等待解救的小动物均已被标记，其位置处于「四方之网」的捕捉范围内时，标记会自动变化。 |
| 巡逻中的幻犬分身战斗力异常强悍，与其对战可能不是明智之举… 注意观察幻犬分身的目光朝向，避免出现在其目光所及的范围内，否则被幻犬分身发现后，若未及时逃离其视线范围，则会被攻击。 |
| 在「调查点·遁藏之地」中，若「四方之网」命中巡逻中的幻犬分身，则能使其在短时间内无法行动。 |
| 「调查点·遁藏之地」中布有烟雾机关，能够通过触碰或者攻击开启。开启后，若能藏身于其中，则不会被幻犬分身发现。在被幻犬分身攻击时，合理利用烟雾机关能够躲避其追赶。 |
| 「调查点·遁藏之地」中布有烟花机关，能够通过触碰或者攻击开启。开启后，会吸引周围幻犬分身的注意。 |
| 「调查点·匪贼之窝」中关押着亟待解救的小动物们，需要先打败周围的敌人再打开牢笼，才能救出小动物。 |
