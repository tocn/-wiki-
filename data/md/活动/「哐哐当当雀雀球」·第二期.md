## 基本信息

### 活动时间

### 参与条件

冒险等阶≥20级
且完成魔神任务：序章·第三幕「巨龙与自由之歌」
※完成魔神任务：第五章·第五幕「炽烈的还魂诗」后体验更佳。

### 活动说明

- 活动关卡中，旅行者需要按照规则击打「雀雀弹球」，并使用「雀雀特技」，击退敌人，保卫农田。
- 活动开启后的前4天，每天解锁2个新的关卡。

生论派的学者、新星商人和可爱动物专家拜希麦·五世在「沃陆之邦」领地内推广游戏的新摊位，在此开放的第三代「哐哐当当雀雀球」 采用了全新的规则，相信能给大家带来不一样的快乐！

| | |
| --- | --- |
| 大大魔法！ | 施放后，当前场上的雀雀弹球的体积和重量都会变大！神奇的魔法持续10秒。 |
| 多多出击！ | 施放后，将额外召唤2枚雀雀弹球，多多痛揍场上的贼鸥和山鼬！ 不过持续10秒后，额外的雀雀弹球就会下班回家睡觉。 |
| 气气火球！ | 施放后，雀雀弹球将引导火山气气地反击！最多自动选择场上的4个目标，降下火球，造成范围伤害！ |
