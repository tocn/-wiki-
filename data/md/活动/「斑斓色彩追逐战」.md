### 活动说明

- 活动开始后的第1、3天，会各开启2个新关卡，活动开始后第5天，会开启1个新关卡，共5个关卡。
- 关卡内，旅行者需要和其他旅行者一起，追逐游离颜料球，使用色彩转化它们的颜色，并将它们推入与颜色相同的收集区内获取积分。
- 在关卡内完成各项挑战，可获得相应的收集进度。收集进度到指定值，可获得对应的奖励。
- 收集进度存在上限。活动开启首日上限为2000，活动开启后第3、5天，上限会增加，最终上限为5000。

### 当前挑战机制

| 名称 | 描述 |
| --- | --- |
| 「坏蛋纸板」 | 随处可见的反派角色，会干扰游离颜料球的移动。 |
| 「调色欢饮瓶」 | 欢饮瓶会间歇性地喷发或吸气，在推动或牵引周围游离颜料球的同时，将其转化为自身颜色。 |
| 「大调色池」 | 存储着大量颜料的调色池，可利用它转化颜料球的色彩。 |
| 「调色家阿夏」 | 「调色家阿夏」们会向周边的游离颜料球喷涂色彩。 |
| 「调色蹦床」 | 踩踏后可以高高跃起的蹦床。角色借助其腾空后，落地时的冲击可将周围的游离颜料球转化为蹦床的颜色。 |
| 游离颜料球 | 色彩游离不定的特殊颜料聚合体，会根据最近一次接触到的颜色，转变为蓝色或橙色。 有时，游离颜料球还会进入特殊的炫彩状态：此时将其推入任意收集区，均会被视为推入同色收集区。 |
| 色彩收集区 | 游离颜料球的专属收集区。若推入的颜料球与收集区色泽一致，将积累阶段进度。 进度充满后将进入下一阶段，挑战区域也会随之改变。 |
