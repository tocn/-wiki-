### 参与条件

冒险等阶≥20级
且完成魔神任务序章·第三幕「巨龙与自由之歌」

### 活动说明

- 「月引周巡之述演」中，旅行者需要选取战线领队和交战单位，组成出战阵容，与对手的阵容进行对决。推演开始时，旅行者会获得一名战线领队，每个回合中，旅行者都会获得一定数量的交战单位和战斗策略，然后与一位对手进行推演对抗。
- 完成10个回合的战斗或累计失败4个回合后，推演完成。若推演完成时，至少获胜7个回合，则会进入不息推演。所有推演结束后，会根据获胜场数和综合表现获得「推演积分」。
- 「推演积分」存在上限。活动开启首日，「推演积分」上限为2000，活动开启后第4天，积分上限会增加，最终积分上限为4000。

### 推演规则

| | |
| --- | --- |

| 场推演开始时，旅行者可以从4个「战线领队」中抽选一个。领队实力强大，且有一个专属的战斗策略以提供增益。 |

| 拥有2个等阶相同的交战单位时，会立刻将它们合成为1个等阶高一阶的战斗单位。 最多可以通过这种方式合成3阶的战斗单位。战斗单位的等阶越高，等级便越高，战斗力也越强。 等级上限为120。 |
| 在每场推演的第3/5/7回合，旅行者将获得1次机会，抽选战斗策略。 战斗策略能为推演提供多种助益，合理选择战斗策略，可对推演产生可观的影响。 |
| 在每场推演的第2/6回合，旅行者将获得1次机会，抽选阵列战旗。 己方佩戴阵列战旗后，将强化队伍内的交战单位。 在第4/8回合，旅行者的阵列战旗会获得强化。 |
| 除领队以外的交战单位有着普通、精锐和顶尖三种精锐度，其对应的初始等级分别为20/30/50。 随着推演进行，出现更高精锐度交战单位的概率也将提升。精锐交战单位将在第2回合后出现，顶尖交战单位将在第6回合后出现。 |
| 准备阶段 | 战斗开始前，可以确认对方出战的阵容，从而调整我方阵容，合理选择出战顺序和阵列战旗。 阵列战旗会对我方同队伍内的交战单位生效。 |
| 可以通过执行退换单位操作，退回暂时派不上用场的单位，换取机会抽选新的单位。 每退换一个1/2/3阶交战单位，分别可以获得1/2/4点增援点数，消耗3点增援点数，可以获得1次抽选新单位的机会。 |
| 战斗阶段 | 战斗开始后，双方的交战单位将依照小队顺序自动入场，向对方行进，并发起攻击。 |
| 战斗开始时，双方只能同时派出一队阵列。 当阵列战败或战斗时间过长时，阵容中下一队阵列将按照顺序入场，继续战斗。 |
| 如果战斗进行了一段时间而未分出胜负，则将进入消耗战阶段：场上所有交战单位持续损失生命值。 |
| 战斗中，成功击败对方所有单位的一方获胜。 推演会在完成10个回合的战斗或输掉4个回合的战斗时结束。尽可能赢取更多胜局，以获得更多推演积分吧。 |
| 压制策略 | 不同的交战单位之间存在一定的压制关系： 能造成范围伤害的单位，面对小队单位时具有显著优势。 近战单位压制远程单位，远程单位压制空中单位，空中单位压制近战单位。 |
| 近战单位拥有极高的战斗韧性，承受更高的伤害，能够一定程度上保护其他单位。 空中单位能在空中飞行，从而规避来自地面的近战伤害和一些范围伤害。 远程单位射程较远、伤害较高，但是相对比较脆弱。大部分远程单位都可以攻击空中单位。 |
| 当上阵或调整我方单位时，对阵的敌方单位若存在元素免疫或空中单位的压制关系，则会显示压制提示。 |
| 不息推演 | 当旅行者完成推演时，如果至少获胜7个回合，将可进入不息推演，参与不息推演将不会获得推演积分。 在不息推演中，旅行者将使用已配置好的队伍与其他对手进行战斗。仅有一次失败的机会，请尽可能获得更多的胜场吧！ |
| 在不息推演中，旅行者不能抽选或退换单位。阵容中交战单位的等级提高也改为临时提高。 同时，旅行者无法查看对手所佩戴的阵线战旗效果。 |
