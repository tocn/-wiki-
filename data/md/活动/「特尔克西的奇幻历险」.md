### 活动说明

- 活动期间，将陆续解锁「主板调试问题集」、「参寻荣耀追游录」、「肃清邪物反击战」各阶段玩法。
- 「主板调试问题集」玩法中，旅行者需要通过布设有限长度的回路，引导信号前往信号终点以调试主板解决问题。
- 「参寻荣耀追游录」玩法中，旅行者需要奏响回响海螺，前往标记点回收指定数量的「虹彩荣耀」即可完成挑战。
- 「肃清邪物反击战」玩法中，旅行者需要在指定时间内完成战斗挑战，使用「特尔克西」王子的「水妖之歌」可以更轻松地战胜敌人。
- 完成各个玩法，可获得「特尔克西徽章」。收集指定数量的「特尔克西徽章」可邀请「潜怀遐梦· 菲米尼 (冰)」，同时还可以获得原石、智识之冕、大英雄的经验、角色天赋素材、精锻用魔矿、摩拉等奖励。

## 玩法教学

| | |
| --- | --- |
| 主板调试问题集 | 布设有限长度的回路，保证信号从信号起点出发，能够到达指定的信号终点，即可完成调试。 |
| 在调试中存在着断开的通路。当信号通过对应颜色的感应式开关时，断开通路会立即连通。 |
| 一次调试中至多存在两个不同的回路，同一回路的信号起点和信号终点颜色相同。 |
| 当调试经过一段时间后，可以通过调试手册获取建议布设回路位置的提示。 |
| 当信号通过特定颜色的感应式开关后，分支通路的连通方向将进行切换。分支通路的感应式开关可以重复触发。 |
| 参寻荣耀追游录 | 回响海螺奏响后，将在小地图和视野内标记可能存在「虹彩荣耀」的位置，回收指定数量的「虹彩荣耀」即可完成挑战。 |
| 有些材料的回收或许需要利用异色原海异种的力量… |
| 肃清邪物反击战 | 使用「特尔克西」王子的「水妖之歌」，可以更轻松地战胜敌人。在使用「水妖之歌」后「特尔克西」王子会进行充能，待充能完毕方才能再次使用。 |

| Ⅷ 综合全局控制 | 对于错综复杂的应用情境不存在多少取巧的空间，基于已有的经验勇于试错并不断改正方才是最好的技法… |
