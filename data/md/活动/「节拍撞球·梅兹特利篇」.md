### 参与条件

### 活动说明

- 活动开始后，每天都会解锁一个新的关卡，共6关。
- 旅行者需要移动球板，回击飞来的撞球，击碎各种节奏方块。
- 利用角色的元素类型，可以为球板赋予相应元素，改变撞球的元素，从而触发元素反应，更高效地进行挑战。
- 在限定时间内获得更高得分，或是尽快击败节拍首领，将有机会赢取物资奖励。

### 玩法规则

- 教程：节拍撞球·规则

| | |
| --- | --- |
| 节拍撞球·爆轰球 | 「弹球」与弹板发生超载反应后，将附加破坏效果「爆轰」：命中节奏方块时，将发生爆炸，对一定范围内的节奏方块造成伤害。 |
| 节拍撞球·馈电球 | 「弹球」与弹板发生感电反应后，将附加破坏效果「馈电」：命中节奏方块时，将释放电弧，对一定范围内的节奏方块随机造成伤害。 |
| 节拍撞球·凝冻球 | 「弹球」与弹板发生冻结反应后，将暂时停留在弹板上，此时弹板仍可以移动。冻结时间结束后，「弹球」将自动向前击出，也可以选择时机，主动击球。 |
| 节拍撞球·弥散 | 「弹球」与节奏方块发生扩散反应时，将触发效果「弥散」：对一定范围内的节奏方块进行元素附着，附着的过程中如果接触到了其他元素，则会继续进行反应。 |
| 节拍撞球·爆轰 | 「弹球」与节奏方块发生超载反应时，将触发破坏效果「爆轰」：对一定范围内的节奏方块造成伤害。 |
| 节拍撞球·凝冻 | 「弹球」与节奏方块发生冻结反应时，将触发破坏效果「凝冻」：与该节奏方块相连的所有同类型节奏方块将被冻结。「弹球」再次撞击被冻结的方块时，将直接击碎该方块与所有相连的被冻结的方块。 |
| 节拍撞球·馈电 | 「弹球」与节奏方块触发感电反应后，将触发破坏效果「馈电」：在命中的节奏方块位置释放电弧，对一定范围内的节奏方块随机造成伤害。 |
| 节拍撞球·锐化 | 「弹球」与节奏方块发生超导反应时，将触发破坏效果「锐化」：命中节奏方块时不再发生反弹，而是继续沿原路径飞行，直接击碎路径上的节奏方块。「弹球」与场地边界碰撞后，此破坏效果立即结束。 |
| 节拍撞球·蒸灼 | 「弹球」与节奏方块发生蒸发反应时，将触发破坏效果「蒸灼」：对命中的节奏方块造成更高伤害。 |
| 节拍撞球·熔解 | 「弹球」与节奏方块发生融化反应时，将触发破坏效果「熔解」：对命中的节奏方块造成更高伤害。 |
| 节拍首领·其一 | 节拍首领「呆呆浮游鸟」会在场上唤出多枚雷元素节奏方块，或许可以利用这一特性，让「弹球」在对方和雷元素方块之间连续反弹，或者利用元素反应触发破坏效果，对其造成伤害… 击败节拍首领，即可赢得本关卡的挑战！ |
| 节拍首领·其二 | 节拍首领「炽热熔岩鸟」会以环形的节奏方块保护自身，利用击破音浪方块的增益获得强化焰火弹，迅速破坏首领周围的节奏方块，以便对其造成伤害。 击败节拍首领，即可赢得本关卡的挑战！ |
| 节拍首领·其三 | 节拍首领「烈奏狂热熔岩鸟」后方有着多个熔岩反射板，弹球打入后，将分裂成多个弹球反射回来。节拍首领的生命值降低后，分裂的弹球数量将进一步提升。 击败节拍首领，即可赢得本关卡的挑战！ |
