## 基本信息

### 活动时间

2023/02/16 10:00 ~ 2023/02/27 03:59

### 参与条件

冒险等阶≥30级
且完成魔神任务「离岛逃离计划」
※ 完成魔神任务「危途疑踪」后体验更佳。
※ 活动期间，如果没有完成魔神任务「危途疑踪」，可在活动界面通过「快速体验」参与活动。

### 活动说明

- 活动开始后，每天都会解锁一关斗虫挑战，共5关。
- 每关斗虫挑战均有「切磋」、「锐意」、「狂热」3个难度。挑战开启后，「切磋」和「锐意」难度会解锁。成功挑战「锐意」难度后才可解锁「狂热」难度。
- 迎接对手的挑战，达成相应条件后即可在活动界面领取奖励。完成更高难度的挑战，可直接获得较低难度模式的奖励。

## 玩法教学

| |
| --- |
| 点按前进按钮，可以指挥鬼兜虫消耗少量体力向前移动半个砖块的距离，接近对手。 这一招式不会造成伤害。 |
| 长按前进按钮，可以指挥鬼兜虫蓄力，结束蓄力时，将消耗较多体力向前突进，突进击中对手后，可以造成伤害。根据蓄力时间的不同，鬼兜虫消耗的体力、移动的距离和造成伤害将有所变化，完全蓄力时，可以突进两个砖块的距离。 |
| 若完成突进时，鬼兜虫恰好抵达对手的位置，击中了对手，即可施放一次「刺挑」，造成更高的伤害。点按前进无法施放「刺挑」，蓄力过度也无法触发「刺挑」。 |
| 蓄力的时间决定了突进的距离，可以借助蓄力的进度来判断我方鬼兜虫的突进距离。 |
| 点按后退按钮，可以消耗一定体力，指挥鬼兜虫后撤一个砖块的距离，闪避对手的攻击。 若是闪避的时机和距离不当，鬼兜虫仍有可能受到伤害。 |
| 如果两只鬼兜虫同时发起攻击，我方将被撞倒，无法对对手造成伤害。注意发动攻击的时机，如果改变决策，可以取消蓄力，避免无谓的体力消耗。 |
