## 基本信息

### 活动时间

### 参与条件

冒险等阶≥20级
且完成魔神任务序章·第三幕「巨龙与自由之歌」

### 活动说明

- 活动开始后，每天会解锁一条新的越野路线，共5条。
- 越野挑战中，旅行者需要在限定时间内搜集尽可能多的「野踪气球」，在限定时间内所搜集的「野踪气球」越多，所获得的奖励就越加丰厚。
- 旅行者可装备小道具 野踪罗盘 获得各类护佑，可在挑战开启前选择合适的护佑。
- 可邀请一名好友共同进行挑战，单人挑战成绩和多人挑战成绩均可用于结算活动奖励。每条路线的单人挑战成绩和多人挑战成绩均会计入挑战详情的结果中。

## 玩法教学

| |
| --- |
| 开启玩法后，旅行者需要在限定时间内搜集尽可能多的「野踪气球」，搜集全部「野踪气球」所消耗的时间越少，就能取得更好的评价。 |
| 进入挑战前，玩家可以选定一种护佑，在挑战中激活，以获得强化效果。 在玩法中通过「野踪罗盘」，消耗「佑能」以获得护佑。 「佑能」会随时间恢复，也会在搜集「野踪气球」，或与「佑能」接触时提升。 |
| 在挑战中存在着两种「野踪气球」。 1.在搜集「野踪气球·丰获」时，可以提高搜集「野踪气球」的整体进度。 2.在搜集「野踪气球·速纳」时，旅行者周围会出现数个「野踪气球·丰获」，这些「野踪气球」会在一段时间后消失。 |
| 旅行者可以邀请一名好友共同进行「跨野寻踪」挑战，用这种方式在挑战中所达成的各类成绩会用于结算活动奖励，并计入多人联机挑战的结果中。 |
