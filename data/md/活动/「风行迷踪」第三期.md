亲爱的旅行者，「风行迷踪」活动即将开启~
蒙德城内的吉盖克斯正在推行名为「风行迷踪」的经典游戏，参与游戏可赢取 迷踪币 ，用于解锁不同等阶的奖励。

## 基本信息

### 活动时间

### 参与条件

冒险等阶≥20级

### 活动说明

- 活动开启当天，「迷踪币」的获取上限为1200，之后6天内每天将逐步解锁「迷踪币」的获取上限，活动期间共计可获得6000「迷踪币」。通过匹配模式参与「风行迷踪」游戏，可以获得「迷踪币」。
- 累计获得一定数量的「迷踪币」或完成「迷踪挑战」任务，可以领取对应的奖励。
- 在参与风行迷踪时，会随机挑选已选中的「周旋之地」进行游戏。旅行者可以通过游戏概览中的「周旋之地」预览来更改目前选中的匹配地图。未解锁的「周旋之地」无法被选中。
- 旅行者可以通过解锁对应区域的七天神像来解锁「周旋之地」。稻妻区域的「周旋之地」需要完成任务「离岛逃离计划」且解锁对应区域的七天神像后才可解锁。旅行者可以通过游戏概览中的「周旋之地」预览看到目前已解锁的内容。

: ※ 仅在匹配模式下完成游戏，才可获得「迷踪币」；自行组队可以进行游戏和完成「迷踪挑战」任务，但无法获得「迷踪币」。

## 活动玩法

### 玩法教学

| |
| --- |
| 「风行迷踪」中，双方玩家将分别扮演「游侠」与「猎手」。 \*「游侠」需要躲避猎手的追捕，坚持到限定时间结束。 而「猎手」需要在限定时间内捕获所有「游侠」。 |
| 「猎手」拥有更快的移动速度，体力消耗大幅降低，还可以使用强大的「风行秘技」。「风行秘技」具有探测对方位置和识破对方的伪装等效果。 而「游侠」可以使用「风行秘技」伪装成当前地图内特定的物件，布置诱饵，或暂时进入隐形状态。 |
| 游戏过程中，场地内将随机降下「眷顾之能」。 拾取「眷顾之能」后，可为「眷顾秘技」充能，这一强大的秘技足以左右胜负。 |
| 参与「风行迷踪」可以获取「迷踪币」，累积获取一定数量的「迷踪币」，即可解锁多种奖励。 自行组队参与游戏，或是获取「迷踪币」的数量达到当前上限时，参与游戏将无法再获取「迷踪币」。 |
| 被猎手捕获后，游侠将进入「游观者」状态，处于「游观者」状态中时，依然可放置「幻形信标」帮助游侠进行游戏。 |
