## 2023/12/06【4.2】

**B站链接：**点击跳转

- 【快捷一键功能】

: ●探索派遣

一键派遣即将在4.3版本上线。届时，旅行者可以一键领取已完成的派遣奖励，也可以一键重复进行之前的探索派遣。

: ●食材加工和锻造界面

除了探索派遣，食材加工和锻造在4.3版本也能一键收取制作完成的道具了。

: ●还圣奥迹

在合成台进行“还圣奥迹”时，将支持批量一键放入多个圣遗物。
并且，在后续版本中，我们还将在尘歌壶系统中上线制作摆件界面的一键收取功能。

- 【圣遗物管理优化】

随着旅途的进行，旅行者可以收集的圣遗物套装也将越来越多，为了方便旅行者更快地找到对应的圣遗物并进行管理，我们对圣遗物的筛选功能做了较大的迭代。
在"背包/圣遗物"界面，增加了自动锁定和快速解锁的相关功能，旅行者可以通过该功能对符合所选条件的圣遗物进行自动锁定和解锁。

此外，在角色的圣遗物界面，旅行者可以找到基于近期活跃旅行者的角色推荐圣遗物套装信息，用来作为搭配圣遗物的参考。
关于圣遗物管理优化的详细说明，请旅行者关注后续官方介绍。

- 【养成界面的优化】

在当前版本的游戏中，旅行者进行角色培养、武器强化、圣遗物强化操作时，会出现一个展示培养前后数值变化的弹窗。在4.3版本，开发组会将培养信息和原始的界面整合，旅行者进行养成操作时就不会频繁出现弹窗，体验更加流畅。
除了养成信息的整合，这些界面还有针对性的小优化：

: ●角色培养界面

角色培养界面加快了培养相关特效的速度，并能使用快捷放入，一键放入能将角色提升到突破前的最高等级的角色经验素材。

: ●圣遗物强化界面

圣遗物强化界面的其他优化：
1. 一次强化可消耗的道具增加到了15个；
2. 增加了“阶段放入”的功能；开启后放入的素材未达到空位上限时，若本次强化可以使目标圣遗物达到4/8/12/16级，则不会自动放入更多素材；
3. 在"设置/其他"中可以开启是否快捷放入5星圣遗物作为强化素材。
配合前文提到的自动锁定功能，我们希望这些改动能够让旅行者更方便地管理5星圣遗物。

: ●武器强化界面

武器强化界面一次武器强化可消耗的道具增加到了40，并且在精炼武器时可以选择多个材料。
我们希望这些迭代能给旅行者更流畅的养成体验。

- 【重复挑战秘境时角色的刷新点】

在4.3版本，旅行者在进入秘境，或者是领取奖励之后继续挑战秘境，角色会刷新在更靠近开启秘境挑战的位置，无须再从秘境入口走到该位置。

- 【魔神任务「回响渊底的安魂曲」与世界任务解绑】

另外，在当前版本，魔神任务「回响渊底的安魂曲」需要旅行者前往「层岩巨渊·地下矿区」，而此时「层岩巨渊·地下矿区」处于封锁状态，旅行者需要先完成对应世界任务以进入「层岩巨渊·地下矿区」，才能继续推进魔神任务。
为了让旅行者有更流畅的魔神任务体验，从4.3版本开始，「层岩巨渊深游记」系列任务将不再是该魔神任务的前置；当旅行者进行到魔神任务「渊底不期的再会」的目标“进入层岩巨渊·地下矿区”时，将自动解锁一个「层岩巨渊·地下矿区」的传送锚点，方便旅行者推进魔神任务。

- 【其他优化】

为了提升游戏体验，4.3版本还将上线一些其他体验优化，例如：
1. 我们将调整冒险之证-讨伐界面内敌人头像的展示方式，方便旅行者查找；在该界面选择“停止追踪”，相关敌人的头像就不会再在地图上显示。

2. 在各种制造界面（合成/烹饪/锻造/制作摆设），如果旅行者的设备上没有记录的角色选择，会默认选择第一个能给本次制造提供增益的角色。
3. 在大地图界面，点击对应首领头像，即可查看其当前剩余复生时间。

- 【征讨领域•快速挑战】

: ●随着冒险之旅的不断推进，开发组注意到，一些新手旅行者在获取喜爱的角色后，由于未完成前置任务，暂时无法获取养成角色所需要的素材。4.2版本起，旅行者的冒险等阶达到40级后，可在单人模式下，通过冒险之证快速挑战尚未解锁的征讨领域，无需完成前置任务。

征讨领域的秘境入口将在完成特定前置任务后解锁。为确保最佳体验，建议完成对应剧情任务。
「北风的王狼，奔狼的领主」无法通过本功能快速开启挑战。

- 【传说任务系统优化】

: ●往期的开发组座谈会中提及过，我们注意到旅行者可能会为了消耗传说任务钥匙，同时解锁多个传说任务，从而出现任务之间互相占用的现象。针对这个情况，开发组将解锁和接取传说任务分成了两个独立的步骤。该功能目前已经开发完成，即将在4.2版本中上线。
: ●旅行者消耗传说任务钥匙解锁后，可自行选择是否接取任务，点击领取任务后，该任务才会出现在任务列表中。
: ●当传说任务和邀约事件有前置条件需要完成时，点击后将会出现弹窗，展示待完成的内容，点击对应任务右侧的按钮即可前往完成。

- 【地图功能优化】

: ●新地区开放后，考虑到大家对标记的需求可能也会随之增加，4.2版本起，地图标记上限将扩展至200个。
: ●同时我们还新增了批量删除标记功能，地图上标记较多时，旅行者可以更加便捷地做调整。选中标记后，点击侧边栏右下角的按钮，即可批量选择。

- 【七圣召唤系统优化】

: ●往期的开发组座谈会中提及过，我们注意到旅行者可能会为了消耗传说任务钥匙，同时解锁多个传说任务，从而出现任务之间互相占用的现象。针对这个情况，开发组将解锁和接取传说任务分成了两个独立的步骤。该功能目前已经开发完成，即将在4.2版本中上线。
: ●新版本中还将上线「牌组分享码」功能，方便旅行者分享自己创建的牌组，以及使用他人分享的牌组。

## 2023/09/13【4.0】

**B站链接：**点击跳转

- 【冒险历练】

: ●4.1版本起，旅行者们完成任务、参与活动、进行探素和收集行为后，将获得「历练点」，可换取等同于每日委托的奖勋。
: ●旅行者冒险等阶达到35级或完成魔神任务第二章第三幕后，即可通过历练点换取奖励。
: ●历练点与每日委托共享奖励领取次数和上限，一日内可组合领取（例如，领取一次历练点奖励，完成三次每日委托并领取奖励）。

- 【前期体验优化】

: ●冒险等阶突破提醒

部分旅行者们在初入提瓦特时，可能没有注意到冒险等阶突破任务，导致无法继续升级，在后续的版本中，旅行者的冒险等阶若是达到当前上限，在派蒙菜单处将出现突破提示。

: ●冒险等阶突破挑战关卡调整

考虑到旅行者们在关卡内耗时可能相对较长，且重新挑战的成本较高，我们对关卡流程进行了简化。简化后，旅行者们可以更快到达最终挑战的位置。

并且，考虑到新手旅行者可能在关卡中首次遇到部分高难度敌人，对其机制不熟悉导致无法通过挑战，我们移除了这些敌人。在对角色、武器、圣遗物进行适当的养成后，即可完成挑战。

: ●「备战」开放条件及奖励调整

开放等级由20级下调至16级，旅行者们可以更早开启任务，获得奖励。
奖励内容也根据大家前期的需要，新增了武器突破素材等养成材料，希望可以助力旅行者们前期的成长。

- 【未来的想法…】

**Q：***一键派遣什么时候能安排上？*

**A：**相关功能已经在开发中，我们将简化探素派遣、锻造、烹饪的操作流程，让旅行者们可以更便捷地收取奖动和进行派遣。

**Q：***讨伐的怪太多了，每次刷材料都要找半天。*

**A：**为了提高旅行者们定位敌人并获取养成所需的材料的体验，我们对讨伐功能进行了一些优化——调整敌人排列方式，方便大家寻找。
此外，旅行者追踪过某敌人后，再次打开本页面时，会保留上次的选择，无需再次在列表中寻找。在地图上点击首领的图标，可查看其重生时间。

**Q：***圣遗物升级要点好多次，能不能加点格子？*

**A：**与讨伐界面的优化类似，我们希望通过简化操作流程，提高旅行者们养成时的体验。
武器、圣遗物强化时可放入的材料数量将会增加，圣遗物强化的智能放入功能也在制作中，可以快速强化到4/8/12/16级。
角色升级则可以快捷放入经验书，并且合并升级和突破页面。旅行者将角色升级到当前等级上限时，可以直接完成突破操作，无需另外打开突破页面。

- 【地图与任务系统畅想】

除了即将上线的优化内容，任务角色易被占用、前置任务层级复杂等大家关心的问题也已经记录在开发组的小本本上啦，对应的优化方案正在讨论中。在这里我们想先和大家分享一些想法：

: 目前被占用任务提示比较简单，旅行者可能需要额外定位和梳理相关任务。

: 关于占用提示的表现，开发组**计划在任务界面为相关任务提供更清晰的跳转指引**，帮助旅行者们处理已存在的占用情况。

: 此外，我们还注意到旅行者们可能会为了消耗传说钥匙同时解锁多个传说任务，从而出现任务堆积，互相占用等现象。针对这个情况，开发组计划将解锁和接取传说任务分成独立的两个步骤。调整后旅行者解锁传说任务时不会自动接取，从而在不浪费钥匙的同时避免频繁引起占用情况。

: 除了以上提到的优化想法，开发组还将继续**围绕占用问题规划整体迭代方案**，希望能为大家提供更流畅的任务体验。

: 旅行者在冒险过程中会陆续解锁不同的故事，我们也注意到存在「前置任务比较多，不知道从哪里做起」的反馈。

: 开发组正在着手优化多层任务前置所带来的体验问题。我们**计划梳理前置任务完成顺序**，并以弹窗形式展示，这样旅行者可以便捷地跳转到待完成的前置任务。

- 【常驻玩法畅想】

关于任务系统和地图的优化内容先分享到这里。不久前游戏内开放了「神工天巧·宝录之章」活动，这段时间我们在社区发现了许多有趣的自拟秘境，也注意到不少类似于“希望限时活动可以常驻”的呼声。在这里，我们想借这个机会和大家聊聊**关于常驻玩法的想法**：

: 原神部分活动玩法在设计之初，开发组就会考虑其常驻的可能性。不过经过我们的评估，目前有些玩法呈现给大家的内容完成度还不足以支撑长期的游戏体验。我们会综合旅行者们的反馈对活动玩法进行迭代，并在合适的时间将它们常驻在游戏中供大家游玩。

: 未来开发组也会继续规划更多常驻内容，希望能给旅行者们带来有趣的体验。

**Q：***为什么我的枫原万叶没享受到砂糖带来的元素精通增益效果？*

**A：**这是因为在游戏中，为了避免出现无穷叠加的题，「基于某一属性的一定比例获得另一属性」的这一效果，不会被用于计算其他同类比例转換提升。对这一点，在1.3版本时，我们在载入等待中补充了相应的文案说明。

举例来说，砂糖的固有天斌「小小的慧风」,会「基于自身元素精通的20%,提升队伍中所有角色（除了砂糖自己）的元素精通」。这个效果属于「基于某一属性的一定比例获得另一属性」的效果；枫原万叶的固有天赋「风物之诗咏」,会「基于万叶的元素精通増加全队元素伤害加成」,这里用于换算元素伤害加成的精通值，是不包括砂糖的固有天赋「小小的慧风」所带来的精通提升的。

例如：当前队伍中，万叶的元素精通为100，砂糖元素精通为100，砂糖先触发天赋，使得万叶获得了100\*20%等于20点元素精通，那么万叶的元素精通是120。而后万叶触发扩散反应，触发了万叶天赋效果，导致他获得了4%元素仿害加成(而不是4.8%)。

如果不作此限制，则当末来出现“基于目标的元素伤害加成，提升全队的元素精通”的效果，或者“基于目标的精通，提升全队的元素精通”的效果时，就会出现双方彼此无限叠加的情况。

另外需要说明的是，角色或装备直接提供的附加数值效果，例如圣遗物「教官」4件套效果、阿贝多固有天赋「瓶中人的天慧」、法器「流浪乐章」的触发效果之一等等，是不受上述规则限制的。

### 开发组的答疑时间

**Q：***我想知道如果身.上有好几个盾，伤害的结算是怎么算的，先算哪个盾?*

**A：**实际上，当角色受到伤害时，角色身上的每个护盾会同时对此次伤害的数值进行单独结算，结算完毕后，如果角色身上仍有未被耗尽的护盾，则角色不会受到伤害。

举个例子:

使用角色北斗，若她身上同时存在“捉浪”护盾100点，和诺艾尔的“护心铠”护盾20点——

◆如果怪物对她造成了10点伤害，两个护盾分别结算，“ 捉浪”护盾剩余90点，‘护心铠” 护盾剩余10点，北斗不会受到伤害；
◆如果怪物对她造成50点伤害，两个护盾分别结算后，“捉浪” 护盾剩余50点，“护心铠” 护盾耗尽破裂，北斗不会受到伤害;
◆如果怪物对她造成了110点伤害，两个盾分别结算后，北斗受到10点的溢出伤害。

P.s.以上举例排除了各类伤害减免，和吸收效果提升的情况。

为什么这样设计呢？我们也请到开发组的策划小哥哥，简单介绍一下关于护盾的设计思路：

使用元素搭配进行战斗，是原神的基本战斗策略。

在防御这个维度，上，利用元素护盾吸收同种元素伤害就是策略之一。我们为角色制造的护盾设计了“对同种元素伤害有250%吸收效果”的机制，也是出于这个考虑。

我们没有采用需要重复叠加护盾的游戏设计，一方面这样的设计会强迫玩家获取大量的护盾角色，另一方面也会对我们希望看到的多样化阵容搭配起到反作用。当然，玩家适当保持1到2种元素类型的护盾，也不失为应对复杂元素伤害的一种战术，而这也可以利用结晶反应较为容易地做到。
