## 基本信息

| 冷冽巨斧鱼 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 巨斧鱼类 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 形貌独特的鱼类，与斧枪鱼有着一定的亲缘关系。曾有生物学家调侃，斧枪鱼选择了「斧状下腹」，而巨斧鱼选择了「斧状头壳」。 有着蓝紫背脊的巨斧鱼曾被普通鱼师误认为「来自海冰漂浮的北方水域」，较为珍贵，并将之置于接近冰点的水中饲养。其实，它们独特的色彩来源于不同「无奇巨斧鱼」的进食习惯。若是要研究水域中各种养分的「传导链」，这种鱼类无疑是个很好的样本节点… |

**乌吉恩圈·平静水面**

帮助了在旋涡中打转的圆圆月灵后，意外发现的绝佳位置。理论上，应该是相当广的范围内，鱼类资源最丰富的水域，这都不钓两竿，属实可惜…

**月矩力试验设计局·东南水岸**

尚未于挪德卡莱钓鱼协会注册，但在鱼师之中较为有名的钓点之一，位于月矩力试验设计局的东南，鱼类资源可观。据传，部分愚人众成员休假时会在此钓鱼消遣…

**皮拉米达城·东南小岛**

挪德卡莱钓鱼协会注册钓点之一，位于皮拉米达城东南方位的小岛上，鱼类资源丰富。

**苦壑崖·西部水岸**

鱼类资源较为丰富的水域，位于厄布拉神柱和苦壑崖之间的海岸，由于其偏远的地理位置以及存在危险生物袭击的风险，并未被列为注册钓点。

**蓝珀湖·南部浅滩**

挪德卡菜钓鱼协会注册钓点之一，位于蓝珀湖南部的浅滩，风景优美，鱼类资源丰富。

**那夏镇·西南水岸**

挪德卡莱钓鱼协会注册钓点之一,位于那夏镇西南的水岸，鱼类资源丰富。

**霜月之坊·东部水岸**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊东部的水岸，风景优美，鱼类资源丰富。

**霜月之坊·西部水域**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊西部的水域，风景优美，鱼类资源丰富。
