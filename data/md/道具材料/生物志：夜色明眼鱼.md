## 基本信息

| 夜色明眼鱼 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 明眼鱼类 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 外形亮眼的鱼类，有着水晶般晶莹剔透的头腔，常出没于挪德卡莱水域。具有深色外表的个体常使人联想到无星的夜空，因此有了「夜色」的美称。 据研究，这种鱼类的头部充满保护性的液体，主要的双眼位于其中，可以看向各个方位，观察能力卓越。得益于这种身体结构带来的卓越光通量，「夜色明眼鱼」在深水或夜间活动时，相比其他动物，有着更为清晰的视野，能帮助它们及时应对多种威胁… |

帮助了在旋涡中打转的圆圆月灵后，意外发现的绝佳位置。理论上，应该是相当广的范围内，鱼类资源最丰富的水域，这都不钓两竿，属实可惜…

**北方训练场·西北浅滩**

**月矩力试验设计局·东南水岸**

尚未于挪德卡莱钓鱼协会注册，但在鱼师之中较为有名的钓点之一，位于月矩力试验设计局的东南，鱼类资源可观。据传，部分愚人众成员休假时会在此钓鱼消遣…

**空寂走廊·西北水域**

挪德卡莱钓鱼协会注册钓点之一，位于空寂走廊西北，在此地可以直接目视月矩力试验设计局的建筑。对于普通鱼师而言，建议不要手持钓竿，作出瞄准该建筑之类的危险动作，可能会被愚人众方面视为危险分子…

**苦壑崖·西部水岸**

鱼类资源较为丰富的水域，位于厄布拉神柱和苦壑崖之间的海岸，由于其偏远的地理位置以及存在危险生物袭击的风险，并未被列为注册钓点。

**那夏镇·西南水岸**

挪德卡莱钓鱼协会注册钓点之一,位于那夏镇西南的水岸，鱼类资源丰富。

**霜月之坊·东部水岸**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊东部的水岸，风景优美，鱼类资源丰富。

**霜月之坊·西南水岸**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊西南的水岸，风景优美，鱼类资源丰富。
