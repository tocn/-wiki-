## 基本信息

| 擒霞客 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 鳉鱼类 |
| 出现地点 |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 体表浮现着斑斓霞光的珍稀鳉鱼，看似普通花鳉的变种，但无论是习性还是外观都有不小区别。 在民间传闻中，这种鱼儿还有预测天气的神异能力。每个晨光刺破天际的时刻，若能见到它们跃出水面、将小小身躯撞入第一缕朝霞，那意味着接下来，人们将会享受到一整日的好晴天。 |
