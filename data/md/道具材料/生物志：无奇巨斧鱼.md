## 基本信息

| 无奇巨斧鱼 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 巨斧鱼类 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 形貌独特的鱼类，与斧枪鱼有着一定的亲缘关系。曾有生物学家调侃，斧枪鱼选择了「斧状下腹」，而巨斧鱼选择了「斧状头壳」。 不过，除去醒目的轮廓，巨斧鱼中数量最多的亚种并无任何特别之处，说是挪德卡莱水域「平平无奇」的代表也不为过… 那夏镇酒馆的传说中，有的鱼师反而盯上了「无奇巨斧鱼」普普通通的特性，会特意训练其中一些聪颖的个体，用背脊去切断竞争对手的鱼线… |

## 钓鱼信息

| | |
| --- | --- |
| 钓鱼鱼饵 | 槲梭饵 |
| 钓鱼时间 | 全天 |
| 钓鱼地点 | 挪德卡莱 |

**北方训练场·西北浅滩**

挪德卡莱钓鱼协会注册钓点之一，位于北方训练场西北的浅滩，鱼类资源丰富。

**月矩力试验设计局·东南水岸**

尚未于挪德卡莱钓鱼协会注册，但在鱼师之中较为有名的钓点之一，位于月矩力试验设计局的东南，鱼类资源可观。据传，部分愚人众成员休假时会在此钓鱼消遣…

**皮拉米达城·东南小岛**

挪德卡莱钓鱼协会注册钓点之一，位于皮拉米达城东南方位的小岛上，鱼类资源丰富。

**苦壑崖·西部水岸**

鱼类资源较为丰富的水域，位于厄布拉神柱和苦壑崖之间的海岸，由于其偏远的地理位置以及存在危险生物袭击的风险，并未被列为注册钓点。

**蓝珀湖·南部浅滩**

挪德卡菜钓鱼协会注册钓点之一，位于蓝珀湖南部的浅滩，风景优美，鱼类资源丰富。

**那夏镇·西南水岸**

挪德卡莱钓鱼协会注册钓点之一,位于那夏镇西南的水岸，鱼类资源丰富。

**霜月之坊·西部水域**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊西部的水域，风景优美，鱼类资源丰富。
