## 基本信息

| 流纹京紫蝶鱼 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 蝶鱼类 |
| 出现地点 | 珊瑚宫地图上鲸鱼样子的岛的西北方（见下图） 珊瑚宫水月池东侧 名椎滩断船北方 董色之庭副本东南方 越石村七天神像东方 沉眠之庭副本下方传送点西南方向 鹤观逢岳之野准西南方向钓点（完成雾海纪行·日轮与菅名山世界任务后来此处对雷鸟雕像使用奇特的羽毛出现此钓点） |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 性情温和，姿态优雅的蝶鱼，拥有流线型的美丽背鳍，又有「水中王后」的美誉。体表环绕着京紫色纹路，喜好群居，以此来抵抗环境和天敌的危险。但这种习性被老道的渔师摸透后，便成了反过来捕捉它们的良方——只要想办法将头鱼引进陷阱，剩下的家伙就坐看它们自投罗网就好。 |
