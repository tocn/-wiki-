## 基本信息

| 炮鲀 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 炮鲀类 |
| 出现地点 | 果酒湖南、晨曦酒庄西南（蒙德）；云来海南（璃月）；离岛、天云峠（稻妻）；地下水泽西南（层岩巨渊·地下矿区，从地下水泽西南部的传送点向南出发到约靠近地图无名遗迹标注位置） |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 圆润短小的腹鳍、肥硕敦厚的身躯和老实巴交的脑袋构成了人们对炮鲀的第一印象。这准确地反应了它的大部分个性——呆板、迟钝、缓慢。但少有人知的是，这样的傻瓜外表下却隐藏了一项绝杀秘技——将水流快速吸入身体，然后像炮弹一样从嘴里射出去，精准，强力，即使是渔夫挨上这么一下也免不了七晕八素，是一等一的水中杀手。 「前有炮鲀出没，小心躲避口水。」——《野钓手册·炮鲀篇》 |

## 钓鱼信息

**无名遗迹**

在层岩巨渊中静静流淌的地下河，其中出没着各种鱼类，如此看，这片水域可能隐蔽地与外界相连。

**晨曦酒庄**

蒙德钓鱼协会注册钓点之一，位于晨曦酒庄附近，鱼类资源丰富。

**果酒湖（南）**

蒙德钓鱼协会注册钓点之一，位于果酒湖，鱼类资源丰富。

**璃月港**

璃月钓鱼协会注册钓点之一，位于璃月港，鱼类资源丰富。

**离岛**

稻妻钓鱼协会注册钓点之一，位于离岛港口，鱼类资源丰富。

**荆夫港·东南栈桥**

蒙德钓鱼协会注册钓点之一，位于荆夫港东南的码头栈桥，鱼类资源丰富。

**越石村（右）**

稻妻钓鱼协会注册钓点之一，位于越石村附近，鱼类资源丰富。
