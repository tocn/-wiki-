## 基本信息

| 炽铁巨斧鱼 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 巨斧鱼类 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 形貌独特的鱼类，与斧枪鱼有着一定的亲缘关系。曾有生物学家调侃，斧枪鱼选择了「斧状下腹」，而巨斧鱼选择了「斧状头壳」。 背脊如同烙铁般炽红的特殊个体，在挪德卡莱区域极为少见。相传，激怒自然之人乘船漂浮于水波之上时，这种巨斧鱼会悄然出现，用滚烫的背脊划破船体，让恶人沉底溺亡，因此，走运的渔师也会对上钩的「炽铁巨斧鱼」充满敬意，要么将其放生，要么用华丽的鱼缸将其认真供养… |
