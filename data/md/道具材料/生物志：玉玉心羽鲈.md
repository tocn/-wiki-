## 基本信息

| 玉玉心羽鲈 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 心羽鲈类 |
| 出现地点 | 仅在沉玉谷三个钓点：古茶树坡北边，上谷最东锚点小河南岸，南陵最南锚点西南边 |
| 实装版本 | 4.4 |
| 能否捕捉 | 不能 |
| 描述 | 侧面样貌呈心形的奇特鱼类，据说与鲈鱼有着一定的亲缘关系，又因羽毛般细长软骨构成的背鳍和腹鳍，被学者们形象地命名为「心羽鲈」。 「玉玉心羽鲈」的色泽尤为特别，如同水中的翡玉，因而获得了这一美称。它们有着与安静外貌完全不符的强韧生命力，能在多种特性截然不同的水域存活，而沉玉谷清冽的水质对于它们而言更是无可挑剔，在美玉之名广为流传的沉玉谷，它们生活得无忧无虑，健康安逸。 |

**古茶树坡·北侧水域**

璃月钓鱼协会注册钓点之一，位于古茶树坡以北的水域，鱼类资源丰富

**悬练山·西南水域**

静谧的水域，位于悬练山西南一段距离外的浅滩上，有着可观的鱼类资源

**沉玉谷上谷·东侧水域**

璃月钓鱼协会注册钓点之一，位于轻策庄与沉玉谷之间的水域，鱼类资源丰富
