## 基本信息

| 素素凶凶鲨 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 凶凶鲨类 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 游在挪德卡莱水域的猎手，无比凶悍的肉食鱼！曾经什么都敢往嘴里塞，大口将之嚼碎，但在不少个体误食「月矩力试验设计局」投下的未爆物后，已老实。 更惨的是，渔师们会用各种武器问候这些鲨鱼，以防它们吞食潜在的鱼获。因此，这类鲨鱼已逐渐演化出杂食的习性，有什么吃什么，甚至有些个体吃素数年都未曾开荤，也未见营养不良… |

## 钓鱼信息

| | |
| --- | --- |
| 钓鱼鱼饵 | 清白饵 |
| 钓鱼时间 | 全天 |
| 钓鱼地点 | 挪德卡莱 |

**北方训练场·西北浅滩**

挪德卡莱钓鱼协会注册钓点之一，位于北方训练场西北的浅滩，鱼类资源丰富。

**噩影泽地·东部水岸**

挪德卡莱钓鱼协会注册钓点之一，位于噩影泽地的东部水岸处，鱼类资源丰富。

**月矩力试验设计局·北部水岸**

尚未于挪德卡莱钓鱼协会注册，但在鱼师之中较为有名的钓点之一，位于月矩力试验设计局的北部，鱼类资源可观。据传，部分愚人众成员休假时会在此钓鱼消遣…

**皮拉米达城·东南小岛**

挪德卡莱钓鱼协会注册钓点之一，位于皮拉米达城东南方位的小岛上，鱼类资源丰富。

**苦壑崖·西部水岸**

鱼类资源较为丰富的水域，位于厄布拉神柱和苦壑崖之间的海岸，由于其偏远的地理位置以及存在危险生物袭击的风险，并未被列为注册钓点。

**蓝珀湖·南部浅滩**

挪德卡菜钓鱼协会注册钓点之一，位于蓝珀湖南部的浅滩，风景优美，鱼类资源丰富。

**霜月之坊·西部水域**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊西部的水域，风景优美，鱼类资源丰富。
