## 基本信息

| 綦假龙 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 假龙类 |
| 出现地点 | 蒙德 |
| 实装版本 | 月之六 |
| 能否捕捉 | 不能 |
| 描述 | 被传为龙之后裔的大型鱼类。 是假龙族群的旁支，主体呈深沉的青黑色，腹部则是醒目的淡金。与众多表亲相比，性格极为温和，从不主动与其他水生生物冲突。当然，这不意味着它们好欺负，受到攻击时，它们能如金枪直刺般暴起一击，将体型数倍于自己的进犯者利落打退，震慑整片水域… |
