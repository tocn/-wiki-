## 基本信息

| 维护机关·水域清理者 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 维护机关类 |
| 出现地点 | 枫丹 |
| 实装版本 | 4.0 |
| 能否捕捉 | 不能 |
| 描述 | 为了铺助水下活动的发条机关，提升机队总出勒来而开发的紧凑型辅助机关，限初的设计目的是清除水下的垃圾、植物残道等杂物，避免它们吸附在发条机关关键部位，从而尽可能降低发条机关的故障率。从另一种角度看，它们无疑也扮演着「水下清洁工」的角色，对枫丹的生态环境有益。 这种机关搭载了灵敏的传感器，能有效用「嗅觉J寻获目标物，或是发现水下垃圾的光学特征。因此，有时它们也会被一些鱼饵吸引。钓上了这种机关的鱼师则将它们称为「水域维护鱼」或「铁鱼」。 相比于大量铺货的「初始能力型」，这一更为成熟的量产型号「水域清理者」的表面刷有耐腐蚀能力极强的涂层，而且，该项目的研究员，不再采用一次性投放，投放后不理的运行方案，而是为其引入了周期性回收维护的设计研究员们会用特定频率的闪光向维护机关的传感器发送归航信号，将它们回收，适当修理与检查，再放回水中继续工作。这种特定频率的闪光后来则演变成一种专门针对维护机关族群的鱼饵，通过不明渠道，在普通鱼师的群体中流传了开来。 |
