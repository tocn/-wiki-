## 基本信息

| 肺棘鱼 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 棘鱼类 |
| 出现地点 | 珊瑚宫地图上鲸鱼样子的岛的西北方（见下图） 珊瑚宫水月池东侧 名椎滩断船北方 董色之庭副本东南方 离岛北方 越石村七天神像东方 鹤观逢岳之野准西南方向钓点（完成雾海纪行·日轮与菅名山世界任务后来此处对雷鸟雕像使用奇特的羽毛出现此钓点） |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 长满刺状鳍的迅猛鱼类，全速游动时矛般尖吻甚至能劈开水流。因此又得名「劈水刺」、「箭难追」等。 与诸多同类相异，肺棘鱼可以在干涸的泥塘中存活很久，除了鳃部，它们还能用退化了鳞片的皮肤来呼吸，这更符合两栖类的性状，因此除了不请自来的渔师，它们还面临着被棘鱼学科除名的存在性危机。 |
