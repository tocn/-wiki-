## 基本信息

| 苦炮鲀 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 炮鲀类 |
| 出现地点 | 果酒湖南、晨曦酒庄西南（蒙德）；轻策庄（璃月）；离岛港口处、名椎滩船北（稻妻）；地下水泽西（层岩巨渊·地下矿区，从巨渊主矿区最南部的传送点向西出发到地下水泽西侧） |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 稀有的炮鲀品种，鱼如其名，是在水底世界传播苦涩的家伙。与普通炮鲀相较，它们射出的水炮速度更慢、体积更小，但却因为附着了极具刺激性的苦味信息素而让威力不退反进。在求偶期间，还经常能够见到雄性和雌性之间互相喷射苦味水炮的奇景，或许向彼此传递生命中的苦涩，也是一种爱意的体现吧。 |

## 钓鱼信息

| | |
| --- | --- |
| 钓鱼鱼饵 | 飞蝇假饵 |
| 钓鱼时间 | 全天 |
| 钓鱼地点 | 蒙德、璃月、稻妻 |

**名椎滩**

稻妻钓鱼协会注册钓点之一，位于名椎滩，鱼类资源丰富。

**地下水泽**

在层岩巨渊中静静流淌的地下河，其中出没着各种鱼类，如此看，这片水域可能隐蔽地与外界相连。

**晨曦酒庄**

蒙德钓鱼协会注册钓点之一，位于晨曦酒庄附近，鱼类资源丰富。

**果酒湖（南）**

蒙德钓鱼协会注册钓点之一，位于果酒湖，鱼类资源丰富。

**离岛**

稻妻钓鱼协会注册钓点之一，位于离岛港口，鱼类资源丰富。

**荆夫港·东南栈桥**

蒙德钓鱼协会注册钓点之一，位于荆夫港东南的码头栈桥，鱼类资源丰富。

**轻策庄**

璃月钓鱼协会注册钓点之一，位于轻策庄，鱼类资源丰富。
