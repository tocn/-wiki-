## 基本信息

| 虹光凶凶鲨 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 凶凶鲨类 |
| 出现地点 | 挪德卡莱 |
| 实装版本 | 月之一 |
| 能否捕捉 | 不能 |
| 描述 | 游代在挪德卡莱水域的猎手，无比凶悍的肉食鱼！曾经什么都敢往嘴里塞，大口将之嚼碎，但在不少个体误食「月矩力试验设计局」投下的未爆物后，已老实。 见识到普通凶凶鲨的遭遇后，一些智慧的个体开始学习伪装自身，并通过吞食相对无害的有色食物，演化出如同彩灯招牌般的花纹，如此一来，它们埋伏水下不动时，挪德卡莱的渔师们就会以为它们是水下的垃圾…吗？ 遗憾的是，并不会。彩灯招牌很贵重，一般商家不会轻易将其丢弃…但这些特殊的凶凶鲨反倒因为外表特别，歪打正着，被一些渔师有意保护，总算有了开荤的机会… |

**噩影泽地·东部水岸**

挪德卡莱钓鱼协会注册钓点之一，位于噩影泽地的东部水岸处，鱼类资源丰富。

**月矩力试验设计局·北部水岸**

尚未于挪德卡莱钓鱼协会注册，但在鱼师之中较为有名的钓点之一，位于月矩力试验设计局的北部，鱼类资源可观。据传，部分愚人众成员休假时会在此钓鱼消遣…

**皮拉米达城·东南小岛**

挪德卡莱钓鱼协会注册钓点之一，位于皮拉米达城东南方位的小岛上，鱼类资源丰富。

**苦壑崖·西部水岸**

鱼类资源较为丰富的水域，位于厄布拉神柱和苦壑崖之间的海岸，由于其偏远的地理位置以及存在危险生物袭击的风险，并未被列为注册钓点。

**蓝珀湖·南部浅滩**

挪德卡菜钓鱼协会注册钓点之一，位于蓝珀湖南部的浅滩，风景优美，鱼类资源丰富。

**霜月之坊·东部水岸**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊东部的水岸，风景优美，鱼类资源丰富。

**霜月之坊·西部水域**

挪德卡莱钓鱼协会注册钓点之一，位于霜月之坊西部的水域，风景优美，鱼类资源丰富。
