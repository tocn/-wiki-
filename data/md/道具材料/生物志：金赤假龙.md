## 基本信息

| 金赤假龙 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 假龙类 |
| 出现地点 | 望风山地锚点东北、渌华池秘境北部、归离原东断桥、望舒客栈西草房、越石村东（神像附近）、古树茶坡西北、沉玉谷上谷最东部锚点下方 |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 被传为龙之后裔的大型鱼类。 额上长角，体表无鳞，有金赤战袍加身，有水中王者风姿。实际就血统与习性而论，它们与龙之间的距离差之千里——既无呼风唤雨之能，又无雄踞一方之技，甚至由于性格过于软弱，还常被其他掠食性鱼类抢夺食物，实在愧对这一副威风凛凛的好相貌。因此只能摘下「龙裔」之称，屈居「假龙」之号。 |
