## 基本信息

| 锖假龙 | |
| --- | --- |
| 类型 | 游鱼 |
| 种类 | 假龙类 |
| 出现地点 | 蒙德城东喂鸭子处、渌华池、归离原东断桥、望舒客栈西草房、越石村七天神像东、古树茶坡西北、沉玉谷上谷最东部锚点下方 |
| 实装版本 | 2.1 |
| 能否捕捉 | 不能 |
| 描述 | 被传为龙之后裔的大型鱼类。 是假龙族群的旁支，也可以说是假龙族群中的觉醒者。跟它不成器的表亲相比， 锖假龙褪下了原先银样蜡枪头般的金赤战袍，取而代之的是其貌不扬却硬如精铁的锖色铠甲，意志坚定，为了食物和领地敢于向任何进犯者发起反击。就战斗力而言，它们已经能够与小型海兽一较高下，堪称振兴族群的骨干力量，又有「铁骨海龙」的尊称。 鱼饵：飞蝇假饵 |
