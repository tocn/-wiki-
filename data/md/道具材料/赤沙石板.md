| 舍身步道 | 舍身步道 此段文字的显现即意味着伟大旅途的开始，顺从指引前行，以权能开启通路，并将沿途所见谨记。 舍身步道的殿宇是王的领地的入口，可惜柱梁大多崩坍，深埋地下的通路也成为了蝎子与蜥蜴的舞台。 |
| 秘仪圣殿 | 秘仪圣殿 离开舍身步道，沿着日落方向的轴线前行，便是名为秘仪圣殿之所。 人们以植物的浆水与矿石的粉末在圣殿的墙壁上留下图像，它们不会如同黄沙中的足迹一样轻易被风掩盖，长久描摹着赤王的治世。 |
| 赤王陵 | 赤王陵 壁画目送你离去，它们并不会惋惜，因为它们知晓你接下来将要去见证的事物… 低声诵出赤王的名号吧，是他将这般奇景唤至大地之上，并让每一位子民都能自由出入，称颂他的威仪。 请在此尽情徜徉，但切莫为黄金的盛器而驻足过久，旅途尚未结束。 黄沙之下的厅堂不可目视全貌，只得以双脚丈量。但是切莫行之过急，以免踏入错误的通路。 能工巧匠用千条回廊将天然的洞窟穿起，就连明辨方向的智者进入其中，也免不了迷失道路。 在此处欢歌与礼赞吧，阿赫玛尔智慧的所在于此揭露。 |
| 圣显厅 | 圣显厅 在圣显厅之前的一泓绿洲，是供人歇脚的所在。在此休憩并驱离倦容，以焕然之姿拜谒。 三重试炼的尽头是幻景的显现，前进吧，这是所有赤王子民都渴望进入的神圣之域。 王座居于圣显厅顶端的穹隆下，而欲登高处，需先谦卑下瞰。 王座之间的通路已被打开，如若吟诵祷文，便可抵达那黄金的梦乡，智慧汇集之处。 获取阿赫玛尔智慧者将失去形体，无法将他创造的盛景言说流传，因此折返罢，将所见告知每一位口述赤王恶言的昏昏之徒。 |
| 赤王陵深处 | 赤王陵深处 名为阿如的村落是遗民们的居所，但一度见证圣显之人啊，须知，最初的阿如另在他处，在沙瀑之源，在试炼之终点。 尘世如河流横亘于幽冥与阿如之间，凡人不可逾越，不可试探，不可觊觎，违背者永堕幽冥。 欲升入阿如，须有如兀鸟的形体，盘旋幽冥，啄食三种脏器，方可获阿赫玛尔的允诺，以隼的形体飞过河流。 通过再生之间试炼的坚毅者将取得不变形体。 继续前行吧，将取得不变形体的坚毅者。 通过气息之间试炼的颖悟者将取得不休欢乐。 继续前行吧，将取得不休欢乐的颖悟者。 通过吞咽之间试炼的寡欲者将取得不竭胃肠。 继续前行吧，将取得不竭胃肠的寡欲者。 所有的权能在此聚齐，除却那已被废弃的又令人怀念的古老城市，黄沙不再隐藏任何秘密。 隼的形体飞过河流后，须以飞羽燃起三处太阳的余烬，方可获阿赫玛尔的垂怜，升入阿如。 切勿惊动在此沉睡的旧梦守卫，只需保持缄默，将阿如的最初模样熟视。 |
| 「神的棋盘」 | 「神的棋盘」 勿要在此逗留，因此处贵为永恒荣光纪念之所，是千壑的索引，是绿洲的蓝图，却最终沦为刀剑相加的不祥之地。然而后来者应将一切归于原位，如是，被细沙掩埋的通途得以彰显其形廓。 |
| 居尔城 | 居尔城 这是一切落幕之处，是细沙之下最后的隐秘。此处曾是明珠中的明珠，是星中之星。然而事到如今，风沙磨砥建筑的边角，被废弃的一切犹如徒留余响的黯淡之梦。 |
