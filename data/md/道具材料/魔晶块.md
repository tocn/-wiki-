## 基本信息

| 魔晶块 | |
| --- | --- |
| 稀有度 |
| 类型 | 锻造用矿石 |
| 描述 | 两大城市的声望只需分别达到2级，就可解锁“矿点检索”功能。功能开启后，前往寻找对应城市的铁匠NPC。 可以通过「委托锻造」，利用原粹树脂，提炼成武器经验材料。 受地脉的能量侵蚀的水晶矿，寻常手段无法处理。 |
| 来源 | 野外采集 （需要冒险等级达到30级且对应城市声望达到2级） 对话蒙德和璃月的铁匠可得知刷新地点。（每天6点时刷新。在蒙德刷新6个点位，璃月刷新10个点位。） |
| 实装版本 | 1.0 |
| 相关武器 | 无 |
| 同类素材 | 铁块 白铁块 水晶块 星银矿石 紫晶块 萃凝晶 虹滴晶 魔晶块 |
